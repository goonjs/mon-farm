# Epic E06: บัญชีปุ๋ย

สถานะ: Draft
PRD: FERT

> **ขอบเขตกว้างขึ้น (D-54, 2026-10-03):** E06 ครอบคลุม **หนี้ของคนงานทุกประเภท** (ค่าปุ๋ย เงินยืม/เบิกล่วงหน้า อื่น ๆ) ไม่ใช่แค่ค่าปุ๋ย — ยอดค้างก้อนเดียว + แผนผ่อนเดียวต่อคน (D-59); E06-S03/S04 อยู่ลำดับแรก (D-55)

## เป้าหมาย
- รู้ว่าคนกรีดแต่ละคนค้างหนี้ (ค่าปุ๋ยและหนี้อื่น) เท่าไหร่ และหักอย่างเป็นธรรม

## ขอบเขต
- การซื้อ: ชนิด, จำนวนกระสอบ, ราคา, ร้าน, ใครสั่ง, ใครจ่าย, ใบเสร็จ
- แผนปุ๋ย ไม่บังคับ (→ ค่าใช้จ่ายแบบวางแผน)
- แบ่งตามจำนวนกระสอบต่อคนกรีด
- คนกรีดรับ 50%; เจ้าของ 50% = ค่าใช้จ่ายสวน
- บัญชีหนี้ต่อคนงาน (ทุกประเภท): ยอดค้าง, แผนผ่อน (งวดละการขาย), ประวัติ, ผู้ให้ยืม (D-59)
- หักหนี้ตอนสรุปเงิน (หน้า 17 "หักเงินคืนหนี้" แล้วค่อยปัดเศษ — D-60) ไม่เกินส่วนแบ่ง ที่เหลือยกไป; หักเกินหลังแก้การขาย → ธง (D-61)
- เลิกใช้การหักต่อการขายแบบ S29 — ไม่ย้ายข้อมูลเดิม (E06-S05 ยกเลิก, โค้ดถูกลบใน E06-S07 — D-65)

## เปลี่ยน 2026-11-06 (D-89)
- การแบ่งกระสอบให้คนกรีดย้ายไปอยู่ **การใส่ปุ๋ย** (E16-S03) ไม่อยู่บนใบซื้อแล้ว · **ใส่ปุ๋ย 1 ครั้ง = หนี้ 1 ก้อน** (รายการในประวัติ) ยอดค้างรวมและแผนผ่อนยังเป็นชุดเดียวต่อคน (D-59)
- E06-S01 และ E06-S02 (ร่าง) ถูกแทนที่: การซื้อ → E11-S11/S16, การแบ่ง → E16-S03
