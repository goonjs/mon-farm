- **สำคัญ:** ราคาที่ตกลงกัน
- **สำคัญ:** ผู้ซื้อที่ติดต่อไว้

## เพิ่มเติมจากเจ้าของ (2026-10-03, PR #44 comment)
- ช่วยเตรียมข้อความแจ้งนัดหมายคนรับซื้อ มี **template ที่บันทึกไว้ได้** โดยมีตัวแปร: ชื่อคนที่คุยด้วย, วัน, วันที่, เวลา
- มีรายการคนรับซื้อในระบบให้เลือกติดต่อ; วิธีติดต่อกดได้เลย เช่น โทร หรือเปิด LINE
- บันทึกข้อความการคุย เหมือน note

## ร่างเดิมจากหน้าแรก (D-45 — ยังไม่ยืนยันว่าอยู่ใน E15 ทั้งหมด)
- ช่วยร่างข้อความนัดผู้ซื้อ; เลือกผู้ซื้อจากในระบบแล้วติดต่อในแตะเดียว (โทร / เปิด LINE)

## ไม่รวม
- ยังไม่ระบุ

## เช็คลิสต์ (เจ้าของ 2026-11-06, D-91)
1. นัดคนรับซื้อ
2. ลงวันที่ (และเวลา)
3. ใส่ราคาที่ตกลงกัน — เติมให้ตอนเริ่มขาย แก้ได้ (ไม่ขัด SALE-3)
4. จัดสรรปุ๋ยที่ยังไม่ได้แบ่งให้คนกรีด — แอปเตือนเมื่อมีการใส่ปุ๋ยที่ยังไม่แบ่ง ให้แบ่งก่อนวันขายเพื่อหักหนี้ได้ **ไม่มีการตั้งงวดผ่อนใหม่ในขั้นนี้**
