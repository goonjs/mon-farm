## เพิ่มเติมจากเจ้าของ (2026-10-03, PR #44 comment)
- ช่วยเตรียมข้อความแจ้งนัดหมายคนรับซื้อ มี **template ที่บันทึกไว้ได้** โดยมีตัวแปร: ชื่อคนที่คุยด้วย, วัน, วันที่, เวลา
- มีรายการคนรับซื้อในระบบให้เลือกติดต่อ; วิธีติดต่อกดได้เลย เช่น โทร หรือเปิด LINE
- บันทึกข้อความการคุย เหมือน note
