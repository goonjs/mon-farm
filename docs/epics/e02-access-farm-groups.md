# Epic E02: การเข้าใช้ & กลุ่มฟาร์ม

สถานะ: Draft
PRD: ACC

## เป้าหมาย
- เจ้าของ 3 คน login แล้วใช้ข้อมูลฟาร์มชุดเดียวกัน

## ขอบเขต
- Google Login (เว็บ + Android) — ต้อง login และมีกลุ่มก่อนบันทึก; ออฟไลน์แล้วยังอยู่ในระบบ
- 1 user ผูกได้หลายบัญชี login (พร้อมสำหรับ LINE)
- สร้างกลุ่มฟาร์ม; เชิญด้วยรหัส 6 หลัก (7 วัน, ใช้ครั้งเดียว) → ตอบรับ; ออกจากกลุ่ม (ข้อมูลยังอยู่; คนสุดท้ายออกไม่ได้)
- อยู่กลุ่มเดียว → เข้าเลย; หลายกลุ่ม → ให้เลือก
- สมาชิกมีช่อง `role` (V1 เป็น owner ทั้งหมด)

## ไม่รวม
- LINE Login (ขึ้นกับการเชื่อมต่อ ทำหลังทดสอบในสวนครั้งแรก)
- หน้าจัดการสิทธิ์, ลบกลุ่มฟาร์ม, ปุ่มออกจากระบบ (logout)
