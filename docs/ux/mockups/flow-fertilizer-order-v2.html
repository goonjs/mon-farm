ทำไมเปลี่ยน

ที่เจอตอนรันแอปเดิมที่เปลี่ยน
6 ขั้นต่อปุ๋ย 1 อย่าง ทั้งที่ของจริงสั่งทีเดียวหลายอย่าง ต้องเริ่มใหม่ทุกอย่างใบซื้อ 1 ใบ มีหลายรายการ จดจบในหน้าเดียว
ต้องตอบเรื่องเหตุผล ใครรับ กี่กระสอบ ก่อนบันทึกได้ ทั้งที่ของยังไม่มาถึงบันทึกใบซื้อก่อน ใส่ทำไม / ที่ไหน / คนกรีด บอกทีหลังรายการละเรื่อง
ซื้อกับรับของเป็นคนละเวลา แต่แอปให้ตอบทุกอย่างพร้อมกัน"สั่งไว้ ยังไม่ได้ของ" เป็นค่าเริ่มต้น กด "ของมาแล้ว" ทีหลัง หนี้คนกรีดนับเมื่อของมา
วันที่เป็นช่องพิมพ์ 2026-10-27ปฏิทินแตะเลือก + ปุ่มลัด วันนี้ / เมื่อวาน
แถวคนกรีดอัดชื่อ ปุ่มเอาออก ข้อความเติมให้ ปุ่ม − + ในแถวเดียว ตัวเลขกับหน่วยหลุดบรรทัดหนึ่งแถวทำอย่างเดียว: ชื่อ − จำนวน + ในบรรทัดเดียว รายละเอียดเงินอยู่บรรทัดล่าง หน่วยอยู่ในกรอบตัวเลข
หน้าตาเป็นฟอร์มขาวล้วน ไม่เหมือนหน้าแรกการ์ดโค้ง ไอคอน FarmMate สีสดใส ปุ่มใหญ่ ตามหน้าแรก
