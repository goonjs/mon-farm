เทียบวิธีกรอกตัวเลข: กระสอบและจำนวนเงิน

เจ้าของไม่ชอบ "กด + − ทีละ 1" และ "แตะ-เลือก-ลบ-พิมพ์" · เทียบกับวิธีของหน้าเข่งไม่เต็ม (พิมพ์ / หน้าปัด) ที่มีอยู่ในแอป · งานเดียวกันทุกจอ: ใส่ 20 กระสอบ แล้วใส่ราคา 1,150

เทียบจำนวนการกด

ใส่เลขN0 ตอนนี้N1 ช่องใหญ่+แป้นN2 หน้าปัดN3 แป้น+ปุ่มลัด

ผิดพลาดง่ายไหมสูง: แป้นบังจอ ลืมลบเลขเก่าต่ำปานกลาง: ลากแล้วเลขไม่ตรงต่ำ
ใช้ซ้ำทั้งแอปได้ได้ได้เฉพาะค่าช่วงแคบที่ตรงกับของจริง (น้ำหนักตาชั่ง)ได้ทั้งจำนวนนับและเงิน

ชื่อเรียกและโครงที่เสนอ (คอมโพเนนต์กลาง)

  • คอมโพเนนต์ (component) = ชิ้น UI ที่ใช้ซ้ำ · แพตเทิร์น (pattern) = วิธีทำแบบเดียวกันทั้งแอป · แป้นตัวเลขเรียก numeric keypad / NumPad · ปุ่ม − + เรียก stepper · ไม้บรรทัดลาก เรียก ruler / slider picker
  • NumberPad — แป้นตัวเลขในแอป (sheet) ใช้ร่วมกัน: เลขแรกแทนที่ค่าเดิม · ⌫ · ล้าง · จำกัดหลัก · ปุ่มใหญ่ ≥ 56 · รับแป้นพิมพ์จริงบนเว็บ
  • QuantityField — จำนวนนับ (กระสอบ ลิตร ขวด ชิ้น): หน่วยอยู่ในกรอบ, min/max, ปุ่มลัด (ครั้งก่อน + ที่ใช้บ่อย), ± เล็กเป็นรอง
  • MoneyField — จำนวนเงินบาท: ทศนิยม 2 ตำแหน่ง, ลูกน้ำพันขณะพิมพ์, ปุ่มลัดราคาครั้งก่อน, ยอดคำนวณใต้ช่อง; ใช้ทุกที่ที่มีเงิน (ค่าใช้จ่าย ใบซื้อ ส่วนลด ชำระหนี้)
  • WeightField (ของเดิม หน้าเข่งไม่เต็ม — พิมพ์/หน้าปัด) ยังเก็บไว้ เพราะตรงกับหน้าปัดตาชั่งจริง; โหมดพิมพ์ย้ายไปใช้ NumberPad ภายหลัง

ตัดสินใจแล้ว (เจ้าของ 2026-10-27)

  • เลือก N1 (ช่องตัวเลขใหญ่ + แป้นตัวเลขในแอป) เป็นแพตเทิร์นกลางของจำนวนนับ — ไม่เอา N0 (± + แป้นเครื่อง), N2 (หน้าปัดสำหรับกระสอบ), N3 (ปุ่มลัด) · ช่องกรอกตัวเลขทุกที่ที่เป็นจำนวนมากใช้ QuantityField + NumberPad
  • ช่องจำนวนเงิน ออกแบบใหม่ (M1–M3) ตามโครง N1: การ์ดใหญ่ ป้าย "กำลังกรอก" เลขชิดขวา สตางค์เล็กและจางจนพิมพ์ ตัวหนังสือไทยบอกจำนวนเงินใต้เลข ตัวอักษรย่อเป็นขั้นเมื่อเลขยาว (52 → 44 → 36) ไม่ล้น ไม่ตัดด้วย "…" แป้นมี . / 00 / 000 · MoneyField ใช้ทุกที่ที่มีเงิน
  • หน้าเข่งไม่เต็มเดิมเก็บไว้ ไม่แตะ
