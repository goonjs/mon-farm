D-65 ข้อตัดสิน/คำตอบเจ้าของที่หน้าจอใช้ ?F1 คำถามเปิดของไฟล์นี้ (ท้ายหน้า) รอส่ง 2 ตัวบอก sync ภาพรวม · ต่อแถวมีแค่ ขัดกัน ไม่ทราบ ไม่ได้บันทึก ป้ายข้อมูลรายฟิลด์ (E01-S15) เกิดจริง ผูกพันแล้ว วางแผน 1 ต.ค. 2569 วันที่ — แตะสลับ พ.ศ./ค.ศ.
Definition of Done ของ mockup นี้
  1. ทุกหัวข้อที่ได้รับมอบ (เมนู · คน · ผู้ซื้อ · สวน · จุดชั่ง · ส่วนแบ่ง · ค่าใช้จ่าย · ค้างใคร · บัญชีหนี้ · หน้าแรก · กติกาทั่วไป) มีหน้าจอ + ลูกศร flow + caption + รหัส AC/D-NN
  2. ไม่มีความต้องการที่แต่งเอง — ที่ไม่ชัดใช้ทางเลือกที่ปลอดภัยที่สุดและอยู่ใน "คำถามที่ยังเปิด"; ตารางหน้าจอ → story/AC ครบทุกหน้า
  3. ใช้ CSS/token/ไอคอน/กรอบโทรศัพท์แบบ v4 ไม่มีสี literal นอก token; ไม่แก้ flow-v1.html
  4. ตรวจใน Chromium: มือถือ 390 px + เดสก์ท็อป 1280 px + โหมดมืด ไม่มี scroll แนวนอน; screenshot อยู่ใน docs/ux/screenshots/v1.1.0/farm/
  5. ผ่านการทบทวนอิสระโดย subagent แยก (ตรง AC/D-NN) และแก้ตามผลแล้ว
  6. คำ "หักหนี้" และตัวเลขแดง/นัด ตรงกับ flow การขาย; PR draft CI เขียว

คำถามที่ยังเปิด

ไม่แต่งความต้องการเอง — ที่ไม่ชัดใช้ทางเลือกที่ปลอดภัยที่สุดในหน้าจอ แล้วจดไว้ที่นี่

  1. ?F1ช่อง "โหมดเลขเข่ง" (ค่าเริ่มต้นของกลุ่ม — D-53) อยู่ในหน้าตั้งค่าวันขายด้วยไหม — E03-S07 ยัง Draft (หน้า 3)
  2. ?F2โครงสร้างตั้งต้น: ยังไม่มีคนกรีดชื่อ "แดง"/"นัด" หรือมีชื่อซ้ำ — เลือก/เพิ่มคนในหน้านั้นได้ในขั้นเดียวใช่ไหม (หน้า 13)
  3. ?F3แผนเปลี่ยนคนกรีดที่ตั้งล่วงหน้า แก้หรือยกเลิกได้ก่อนถึงวันไหม (หน้า 15)
  4. ?F4ตัวกรองรายการค่าใช้จ่าย: วงจร · หมวด · สวน · เดือน ใช้ชุดนี้ไหม (หน้า 19)
  5. ?F5ทางเข้า "ค่าใช้จ่ายทั้งหมด" — วาดไว้ใต้ "รายการที่ต้องจ่าย"; ควรอยู่ที่เมนู ☰ หรือที่อื่นด้วยไหม (หน้า 19, 27)
  6. ?F6ยอดยกมา ต้องเลือกประเภทหนี้ด้วยไหม — วาดเป็นติ๊ก "เป็นยอดยกมา" ในฟอร์มเพิ่มหนี้ (หน้า 23)
  7. ?F7ค่าใช้จ่ายส่วนเจ้าของที่สร้างจากหนี้ค่าปุ๋ย: ผู้จ่ายคือใคร — วาดเป็น "ไม่ได้บันทึก" จึงยังไม่สร้างเงินที่ต้องคืน (หน้า 23)
  8. ?F8% ที่คนงานรับในหนี้ค่าปุ๋ยแบบกำหนดเอง เป็นจำนวนเต็มเหมือนส่วนแบ่งไหม (หน้า 23)
  9. ?F9หนี้ประเภท "อื่น ๆ" มีผู้ให้ยืมไหม — วาดเป็นหนี้ที่ติดสวนเสมอ ไม่มีช่องผู้ให้ (หน้า 23)
  10. ?F10จ่ายคืนเกินยอดค้าง: AC ว่า "เตือนก่อนบันทึก" — ให้บันทึกต่อได้ (ยอดติดลบ = สวนติดเงินคนงาน) หรือห้าม; วาดเป็นเตือน + เลือกแก้/บันทึกต่อ (หน้า 24)
  11. ?F11การ์ด "รายการที่ต้องจ่าย" บนหน้าแรก แสดงสองยอดแยก (ต้องคืน · ผูกพัน) ใช่ไหม (หน้า 25)
  12. ?F12"รายชื่อคนงาน" จากการ์ดข้อมูลพนักงาน แสดงเฉพาะคนกรีด หรือทุกคน (หน้า 26)
  13. ?F13บันทึกเก่าที่อ้างถึงสิ่งที่ลบแล้ว ต่อท้ายชื่อด้วย "(ลบแล้ว)" ไหม (หน้า 28)
  14. ?F14แตะสลับ พ.ศ./ค.ศ. — สลับทุกวันที่ทั้งแอปและจำไว้ หรือเฉพาะหน้าจอนั้นชั่วคราว (หน้า 28)
  15. ?F15หลังบันทึกจุดชั่งใหม่ แสดงทางลัด "มอบหมายคนกรีดให้จุดนี้" ไหม — ไม่อยู่ใน AC จึงไม่วาด (หน้า 14)
  16. ?F16ไฟล์สัญญาก่อนอัปโหลด: เครื่องอื่นในกลุ่มเห็นชื่อไฟล์ "รอส่ง" หรือไม่เห็นเลย (หน้า 10)
  17. ?F17วันที่มีผลของส่วนแบ่ง = วันเดียวกับการขายที่ปิดแล้ว ได้ไหม — วาดเป็นไม่ได้ เริ่มวันถัดไป (หน้า 17)
  18. ?19(ค้างจาก D-65) ทศนิยมของน้ำหนักเข่ง/ตะกร้าในตั้งค่า — เจ้าของขอตอบทีหลัง (หน้า 3)
