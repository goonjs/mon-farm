Flow การขาย · v1.2.0 (ร่าง) · หนี้แยกจากยอดขาย · 2026-10-14

แก้ส่วนที่ 4 ของ Flow การขาย v1.1.0 เฉพาะหน้า 17, 17a และ 18a ตามที่เจ้าของสั่ง (2026-10-14): เงินที่คืนกันเพราะหนี้ (คนกรีดยาง → สวน และ สวน → คนกรีดยาง) ไม่ใช่ยอดขาย (น้ำหนัก × ราคา) — แยกออกมาตามหลักบัญชี ใช้สีและสัญลักษณ์ต่างกันต่อทิศ และให้เห็นชัดว่าวันนี้ขายได้เท่าไหร่ ราคาเท่าไหร่ · ทุกกองยังรวมกันเท่ายอดขาย (D-72) · หน้าอื่นเหมือน v1.1.0

ร่าง v1.2.0 · ตัวเลขและชื่อเป็นตัวอย่างเดียวกับ v1.1.0 (แดง 1,520 กก. · นัด 735 กก. · 48.50 ฿/กก.) · รีวิวโดย agent นักบัญชี และ persona เจ้าของสวน · รอเจ้าของยืนยัน

↘ คนกรีดยาง → สวน · จ่ายหนี้ (สีน้ำเงิน) ↗ สวน → คนกรีดยาง · สวนจ่ายคืน (สีส้ม) ⇄ หักกลบ · ไม่มีเงินสด (สีเทา เส้นประ)

สี + ลูกศร + คำ เสมอ ไม่ใช้สีอย่างเดียว · ไม่ใช้เขียว/แดง (เขียว = ตรงกัน/ซิงก์, แดง = ผิด) และไม่ใช้เหลือง (= เตือน) กับเรื่องหนี้ · ตัวเลขหนี้ในกล่อง "เรื่องหนี้" ไม่มีเครื่องหมาย + / − ลูกศรบอกทิศ

4 · สรุปยอดส่วนแบ่ง (หน้า 17) — ยอดขาย · เรื่องหนี้ · เงินแต่ละคน

ลำดับหน้าเรียงตามที่เจ้าของพูดกับคนกรีดยาง: ขายได้เท่าไหร่ → แบ่งกันเท่าไหร่ → เรื่องหนี้ (แยก) → วันนี้รับเท่าไหร่ · แดงจ่ายงวดผ่อน 2,000 เป็นเงินสด · นัดติดสวน 1,500 สวนติดนัด 640 หักกลบแล้ว เหลือจ่ายหนี้ 860 มากับยอดโอน (ทาง 3)

กล่องข นัด: แตะ หักเงินคืนหนี้
ปัดเศษ (หน้า 18 เหมือนเดิม) → เทียบยอด

บันทึกการรีวิว (2026-10-14)

  1. รอบ 1 นักบัญชี: หนี้ปนในการ์ดยอดขาย, "+" สีเขียวใช้กับสองทิศ, เงินสดคืนหนี้อยู่ใต้หัวข้อส่วนแบ่งเจ้าของสวน, หน้า 17 ไม่บอกยอดขาย → เสนอโครง ก/ข/ค และหน้า 18a แบบสะพาน (คอลัมน์หนี้รวม = 0) · persona เจ้าของสวน: หา "วันนี้ขายได้เท่าไหร่" ไม่เจอ, สับสนสองทิศ, ตัวเลขนัด 1,500 กับ 860 ไม่ตรงกัน
  2. รอบ 2 นักบัญชี: "พร้อมสร้าง" — แก้คำ 3 จุด · persona: "ใช้ได้" — แก้เล็ก 5 จุด · แก้ในหน้านี้แล้ว: ป้าย "ยังไม่ปัดเศษ" ที่ยอดโอนด้วย, บรรทัดละตัวเลขเดียว, ป้ายหักกลบเปลี่ยนตามสถานะ, ไอคอนทิศใหญ่ขึ้น, ใช้คำ "นัด → สวน" แทน −/+, เอา "D-60", "ทาง 3", "กอง" ออกจากจอ, ย้ายหักกลบออกจากใต้ "วันนี้นัดรับ", เงินสดคืนหนี้บอกว่านัด 860 มากับโอน
  3. ยังไม่ทำ (ทีหลัง): หน้า 18a แบบคอลัมน์ (ตอนนี้เป็นบรรทัดย่อยต่อก้อน อ่านบนจอ 360 ได้ดีกว่า) · ตัวอย่างสีส้ม ↗ จะใส่เมื่อเขียน E11-S09

ต้องให้เจ้าของตัดสินใจ

  1. โครงหน้า 17 ก/ข/ค แบบนี้ใช่ไหม (แยกยอดขาย / เรื่องหนี้ / เงินแต่ละคน) — แทนการ์ดต่อคนที่มีหนี้ปนอยู่ (v1.1.0 และที่เพิ่ง merge ใน #107)
  2. ตัวเลขในกอง ใช้ 860 (เงินที่ย้ายจริง) ส่วน 1,500 = 640 + 860 อยู่ในกล่องเรื่องหนี้ — เปลี่ยนจากที่ตกลงเมื่อเช้า (−1,500 / +640 ในการ์ด) เพราะนักบัญชีและ persona ชี้ว่า +640 อ่านเหมือนการขายจ่ายนัดเพิ่ม
  3. สี/สัญลักษณ์: ↘ น้ำเงิน คนกรีดยาง → สวน · ↗ ส้ม สวน → คนกรีดยาง · ⇄ เทาเส้นประ หักกลบ ไม่มีเงินสด
  4. คำ: "จ่ายหนี้สวน", "สวนจ่ายคืน", "หักกลบ: หักหนี้กับเงินที่สวนติดนัด", "เงินของนัด" แทน "กองนัด" — persona บอกว่า "หักกลบ" และ "กอง" ไม่เข้าใจ
  5. เตือนก่อนบันทึก เมื่อสวนยังติดเงินคนกรีดยางแต่ยังไม่ได้หักกลบ (persona อยากให้เปิดหักกลบเป็นค่าเริ่มต้น — ขัดกับ D-60 "ไม่ใช้อัตโนมัติ" จึงเสนอแค่เตือน)
  6. ข้อเสนอของ persona ที่ไม่ได้ใส่ เพราะขัดกับที่ตกลงไว้: ซ่อน 3 ทางเลือกรับเงิน (D-71), เอารายการแบงค์ในกองออก (ตกลงวันนี้), เอาป้ายซิงก์ออก — ต้องการเปลี่ยนข้อไหนไหม
  7. E11-S09 สวนจ่ายคืนคนที่ไม่มีหนี้ตอนขาย: ทำไหม เงินมาจากส่วนของสวน หรือจ่ายนอกการขาย (กรอบเส้นประใต้หน้า 18a)
