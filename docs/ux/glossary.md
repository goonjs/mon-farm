# พจนานุกรมคำ (glossary) — FarmMate

สถานะ: ตกลงแล้ว · 2026-10-05 · ที่มา: D-76 (หนึ่งสิ่ง = หนึ่งคำทั้งแอป) ต่อจาก D-70 (หนึ่งข้อมูลต่อบรรทัด) · คำที่เคยใช้ปนกันตัดสินใน D-77

เอกสารนี้เป็น **แหล่งเดียว** ของคำบนจอที่ story, mockup และโค้ดต้องอ้าง (D-76)
คำในตารางมาจาก PRD decision log, story และคำตอบเจ้าของเท่านั้น — ไม่ได้คิดคำใหม่ขึ้นเอง
ข้อความที่ผู้ใช้เห็นเป็นภาษาไทยทั้งหมด (D-20); identifier ในโค้ดเป็นภาษาอังกฤษ (คอลัมน์ "ในโค้ด" เป็นแนวทาง ไม่บังคับ)

## วิธีใช้

- เจอสิ่งที่อยู่ในตาราง → ใช้ **คำที่ใช้** เท่านั้น; คำในคอลัมน์ **ห้ามใช้** ห้ามขึ้นบนจอ
- ต้องการคำใหม่ที่ยังไม่มี → เพิ่มแถวในไฟล์นี้ใน PR เดียวกัน พร้อมอ้าง D-xx หรือคำตอบเจ้าของ; ไม่มีที่มา → ถาม lead/เจ้าของก่อน
- คำในวงเล็บ `⟨…⟩` ในตาราง = ส่วนที่แอปเติมค่า
