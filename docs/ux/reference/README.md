# ตัวอย่าง UI จากเจ้าของ (FarmMate)

เจ้าของส่งให้ 2026-10-03 — **เป็นตัวอย่างด้าน visual เท่านั้น ไม่ใช่การออกแบบ UX**

- `farmmate-example-overview.jpg` — โลโก้ สี การ์ด ไอคอน และหน้าจอตัวอย่าง (หน้าหลัก, สวน, การขาย, งานสวน)
- `farmmate-example-weighing.jpg` — ตัวอย่างหน้าจอการชั่งยาง (นับเข่ง) 5 ขั้น

ใช้เป็นแนวทางเรื่อง: สี, ตัวอักษร, รูปแบบการ์ด/ปุ่ม/แถบนำทาง, สไตล์ไอคอน, น้ำเสียงของข้อความ
(ดู `docs/ux/design-system.md` §12.10 ที่รับ FarmMate มาแล้ว)

**เจ้าของตัดสิน 2026-10-03 (U1 b):** รับเฉพาะ **การ์ดและไอคอน** (พื้นการ์ดพร้อมช่องไอคอน และสไตล์ไอคอน)
— แถบนำทางล่าง ปุ่ม FAB หน้าแดชบอร์ด และการชั่งแบบเป็นขั้น ๆ ในรูป **ไม่ใช่ requirement**
ใช้ทำ mockup วาง flow ก่อน (U2 b: mockup ก่อน แล้วค่อยเขียน story) → `docs/ux/mockups/flow-v1.html`

**ห้ามถือเป็น requirement**: flow, ลำดับหน้าจอ, ฟิลด์ และตัวเลขในรูป (เช่น ราคาตลาดโลก USD/kg,
ส่วนของเจ้าของ 50%, การนับเข่งแบบ "เข่งเต็ม/เข่งไม่เต็ม" ในหน้าเดียว) ไม่ผูกพัน — UX มาจาก PRD,
story (`docs/prd.md`, `docs/stories/`) และ mockup flow `docs/ux/mockups/flow-v1.html` เท่านั้น ถ้ารูปขัดกับ PRD ให้ยึด PRD
