## 2. ไม่เปลี่ยน / เปลี่ยนกติกาเดิม

**ไม่เปลี่ยน:** สูตร ส่วนแบ่ง → หักหนี้ → ปัดเศษ → เงินสด (D-60) · หักไม่เกินส่วนแบ่ง เงินสดไม่ติดลบ (D-18) · Σ ทุกก้อน = ยอดขายถึงสตางค์ (D-72) · ทั้ง 3 ทางรับเงินคืน (D-71) · หักเฉพาะหนี้ที่ติดสวน (D-69) · หักกลบเจ้าของกดเอง · ธง/Conflict ห้ามปิด · event ที่บันทึกทั้งหมด. รูปแบบ event เท่าเดิม แต่จังหวะเขียนเปลี่ยน (ตอนกดยืนยัน).

**เปลี่ยนกติกาที่ตกลงไว้ — ต้องแก้ PRD/AC ถ้าเจ้าของเห็นด้วย (ยังไม่ได้ถามเจ้าของ):**
- **D-85** หนี้แยกจากยอดขาย (ก/ข/ค + ↘↗ สองสี + ตรวจ 3 ข้อ): แบบ A รวมหนี้ไว้ในการ์ดคน เหลือ ↘ น้ำเงินที่แถวหนี้ · รีวิวนักบัญชี/persona ของ D-85 ไม่ได้ทำกับแบบนี้
- **D-72** ต้องมีหน้าเทียบยอด: ยุบเป็นแถบ "ตรงถึงสตางค์" + ดูที่มา (Q4)
- **D-60 / E06-S04** ปุ่ม "หักเงินคืนหนี้" ต่อคน: เสนอไว้ก่อน บันทึกตอนยืนยัน (Q1)
- **epic E05** ปัดเศษ "ถามทุกครั้ง": ใช้ค่าล่าสุด (Q3) — ค่านี้ตัดสินว่าใครได้สตางค์ ต้องให้เจ้าของเลือก. การจำค่าข้ามการขายต้องมีที่เก็บ (วันนี้ `sale_rounding_set` ต่อการขาย) — ต้องถาม architect ก่อนสร้าง.

## 3. ทางเลือก

- **A การ์ดต่อคน (แนะนำ):** หน้าสรุปจ่ายหน้าเดียว เงินสดที่ต้องจ่ายใหญ่สุด · แอปเสนอยอดหักไว้ แตะแถวหนี้เพื่อแก้ (ปุ่มลัด หักเต็ม/ครึ่ง/ไม่หัก + แป้นเลขในแอป) · ปัดเศษ/บัญชี/วิธีรับเงินคืน/หักกลบเป็นลิงก์รอง · เทียบยอดเป็นแถบเขียว. 3 ขั้น, ~7 แตะ (ประมาณการ ยังไม่วัด).
- **B ถามทีละเรื่อง:** ขั้นหักหนี้ → ขั้นสรุป → จ่ายเงิน. ~8 แตะ, +1 จอ, ไม่ลดความคิด.
- **C ใบเดียว แถวเดียวต่อคน:** กระชับที่สุด พอดีจอแม้ 5 คน แต่ซ่อนส่วนแบ่ง/หนี้หลังแตะ.

## 4. แนะนำ

**A** — ตรงกับสิ่งที่เจ้าของมาหา (จ่ายเงินสดใครเท่าไหร่), น่าจะเร็วสุด (ประมาณการ) โดยไม่ลดความเป๊ะ (เงินไม่ตรงปุ่มยืนยันกดไม่ได้), หักไม่เต็มก็ง่าย. ใช้แถวย่อแบบ C กับคนที่ไม่มีหนี้และเมื่อมีคนเกิน 4.

## 5. คำถามเปิด (ค่าเริ่มต้น)

Q1 เสนอยอดหักไว้ให้เลย (บันทึกตอนยืนยัน) vs กดทีละคน → **เสนอไว้ให้** · Q2 เตือนเมื่อเงินสด 0 → **แถบเหลือง ไม่ขวาง** · Q3 ปัดเศษใช้ค่าล่าสุดเลย (epic เดิม "ถามทุกครั้ง") → **ใช่** · Q4 ยุบเทียบยอดเป็นแถบ → **ยอม** · Q5 ซ่อนช่องติ๊กเงินสด 0 → **ซ่อน** · Q6 ปกติกี่คนกรีด/กี่คนติดหนี้ → **≤4 / ≤2** · Q7 แผนผ่อน → **คงเดิม** · Q8 ต้องตรวจหนี้ทุกครั้งก่อนยืนยัน → **ใช่** · Q9 ทางรับเงินคืนหนี้+ปัดเศษหน้าเดียว แยกหัวข้อ → **ใช่ (ขอยืนยัน)** · Q10 ครั้งแรกบังคับเลือกทางรับเงินคืน → **ใช่**.
