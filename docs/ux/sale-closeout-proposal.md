## 2. ไม่เปลี่ยน

สูตร ส่วนแบ่ง → หักหนี้ → ปัดเศษ → เงินสด (D-60) · หักไม่เกินส่วนแบ่ง เงินสดไม่ติดลบ (D-18) · Σ ทุกก้อน = ยอดขายถึงสตางค์ (D-72) · ทั้ง 3 ทางรับเงินคืน (D-71) · หักเฉพาะหนี้ที่ติดสวน (D-69) · หักกลบเจ้าของกดเอง · ธง/Conflict ห้ามปิด · event ที่บันทึกทั้งหมด. เปลี่ยนแค่หน้าตา ลำดับ ค่าเริ่มต้น และเครื่องมือกรอกเลข.

## 3. ทางเลือก

- **A การ์ดต่อคน (แนะนำ):** หน้าสรุปจ่ายหน้าเดียว เงินสดที่ต้องจ่ายใหญ่สุด · แอปเสนอยอดหักไว้ แตะแถวหนี้เพื่อแก้ (ปุ่มลัด หักเต็ม/ครึ่ง/ไม่หัก + แป้นเลขในแอป) · ปัดเศษ/บัญชี/วิธีรับเงินคืน/หักกลบเป็นลิงก์รอง · เทียบยอดเป็นแถบเขียว. 3 ขั้น, ~7 แตะ.
- **B ถามทีละเรื่อง:** ขั้นหักหนี้ → ขั้นสรุป → จ่ายเงิน. ~8 แตะ, +1 จอ, ไม่ลดความคิด.
- **C ใบเดียว แถวเดียวต่อคน:** กระชับที่สุด พอดีจอแม้ 5 คน แต่ซ่อนส่วนแบ่ง/หนี้หลังแตะ.

## 4. แนะนำ

**A** — ตรงกับสิ่งที่เจ้าของมาหา (จ่ายเงินสดใครเท่าไหร่), เร็วสุดโดยไม่ลดความเป๊ะ (เงินไม่ตรงปุ่มยืนยันกดไม่ได้), หักไม่เต็มก็ง่าย. ใช้แถวย่อแบบ C กับคนที่ไม่มีหนี้และเมื่อมีคนเกิน 4.

## 5. คำถามเปิด (ค่าเริ่มต้น)
