# ไอคอนร่วม (UX v1.1.0)

ไอคอนเส้น 24 px สีตาม `currentColor` เส้นหนา 2 ปลายมน — แนวเดียวกับ sprite ใน mockup (`docs/ux/mockups/flow-*.html`) · พื้นจาง `.fillsoft` = currentColor 16%

| ไฟล์ | id ใน sprite | ใช้หน้า |
|---|---|---|
| `scale-reading.svg` | `i-scaleread` | ค่าที่อ่านจากตาชั่ง (เช่น "39 กก.") — ค่าที่อ่านจากตาชั่งต้องเน้นชัด |
| `rubber-weight.svg` | `i-rubber` | น้ำหนักยาง (เช่น "35 กก.", "น้ำหนักสะสม") |
| `tapper.svg` | `i-tapper` | ชื่อคนกรีดยางที่ขึ้นต้นแถว/ประโยค (ไม่ใช่กลางประโยค) |
| `save.svg` | `i-save` | ปุ่มบันทึก |

ที่มา: คำสั่งเจ้าของผ่าน lead 2026-10-05 (ใช้ร่วมกับทีมข้อมูลฟาร์มและเงิน)
