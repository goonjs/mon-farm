## 0. วิธีอ่าน

สัญลักษณ์เหมือน E03/E04: `[ปุ่ม]` · `( )/(•)` · `▸` · `____` · `*` บังคับ · `⟨…⟩` ค่าที่แอปเติม
คำไทยของ "Conflict" ในเอกสารนี้ใช้ `ขัดกัน` ตามข้อแนะนำ E03 Q21 (ยังรอเจ้าของ — เปลี่ยนคำเดียวทั้งชุด)

## 1. ลำดับการเปิดแอป (ตัดสินแล้ว: ACC-1, ACC-3, ACC-6, D-23, D-24)

```
เปิดแอป
 ├─ ยังไม่เคย login บนเครื่องนี้ ──→ หน้าเข้าสู่ระบบ (§2) — ออฟไลน์: ข้อความต้องต่อเน็ต
 ├─ เพิ่ง login ครั้งแรกบนเครื่องนี้ ──→ ดึงรายการกลุ่มจากเซิร์ฟเวอร์ก่อน (§1.1) แล้วแยกตามจำนวนกลุ่ม
 └─ login แล้ว (เคยดึงรายการกลุ่มแล้ว)
     ├─ 0 กลุ่ม ──→ หน้า "เริ่มใช้งาน": สร้างกลุ่ม / เข้าร่วมด้วยรหัส (§3) — บันทึกข้อมูลไม่ได้
     ├─ 1 กลุ่ม ──→ เข้ากลุ่มนั้นเลย ไม่มีหน้าเลือก
     └─ ≥ 2 กลุ่ม ─→ หน้าเลือกกลุ่ม (§5)
```
- ทุกขั้นหลัง login ครั้งแรกทำงานออฟไลน์ได้ (รายการกลุ่มเก็บในเครื่อง — E02-S02 AC5)
- เปิดแอปครั้งต่อ ๆ ไป: splash ค้างจนรู้ว่าจะไปหน้าไหน (อ่านจากเครื่อง ไม่รอเน็ต)

### 1.1 login ครั้งแรกบนเครื่องใหม่
รายการกลุ่มในเครื่องยังว่าง — ถ้าตัดสินจากในเครื่อง สมาชิกเดิมจะตกไปหน้า "เริ่มใช้งาน" และอาจสร้างกลุ่มซ้ำ จึงรอรายการจากเซิร์ฟเวอร์ก่อน
(login เพิ่งสำเร็จ จึงมีเน็ตอยู่แล้ว):
- กำลังทำ: `กำลังดึงรายการกลุ่มฟาร์มของคุณ…`
- เน็ตหลุดกลางทาง / error: `ดึงรายการกลุ่มไม่สำเร็จ — ต่อเน็ตแล้วลองอีกครั้ง` `[ลองอีกครั้ง]` — **ไม่**แสดงปุ่มสร้างกลุ่มจนกว่าจะรู้ผล
- ได้รายการแล้ว → แยก 0 / 1 / ≥ 2 กลุ่ม; มีกลุ่ม → `กำลังดึงข้อมูลกลุ่มครั้งแรก…` (ชุดสถานะกลาง) ใช้งานได้ระหว่างนั้น

## 2. E02-S01 เข้าสู่ระบบด้วย Google

### 2.1 หน้าจอ
```
⟨ชื่อแอป⟩
บันทึกการขายยางและงานสวน ใช้ได้แม้ไม่มีเน็ต
[เข้าสู่ระบบด้วย Google]
ครั้งแรกต้องต่ออินเทอร์เน็ต หลังจากนั้นใช้ได้แม้ไม่มีเน็ต
```

### 2.2 Flow
1. `[เข้าสู่ระบบด้วย Google]` → หน้าต่างของ Google (Android: ตัวเลือกบัญชี; เว็บ: popup/redirect)
2. สำเร็จ → ลำดับ §1 (0 / 1 / ≥ 2 กลุ่ม)
3. สถานะ:
   - ออฟไลน์ (ยังไม่เคย login): ปุ่มกดได้ แต่แสดงทันที `ต้องต่ออินเทอร์เน็ตเพื่อเข้าสู่ระบบครั้งแรก — ต่อเน็ตแล้วกดอีกครั้ง` (AC3)
   - กำลังทำ: ปุ่มเปลี่ยนเป็น `กำลังเข้าสู่ระบบ…` (กดซ้ำไม่ได้)
   - ผู้ใช้ปิดหน้าต่าง Google เอง: กลับหน้าเดิม ไม่มีข้อความ error
   - เว็บบล็อก popup: `เบราว์เซอร์บล็อกหน้าต่างเข้าสู่ระบบ — อนุญาตป๊อปอัปแล้วลองอีกครั้ง`
   - error อื่น: `เข้าสู่ระบบไม่สำเร็จ — ลองอีกครั้ง` `[ลองอีกครั้ง]`
     (ข้อตกลงของ UX ไม่ใช่ข้อกำหนด PRD: คำ `ลองใหม่` ใช้กับปุ่ม sync เท่านั้น; การกระทำอื่นใช้ `ลองอีกครั้ง`)
- ยังไม่ login → ไม่มีทางไปหน้าใดที่บันทึกข้อมูลได้ (AC2)
- **ไม่มีปุ่มออกจากระบบ** ที่ใดในแอป (AC8, D-23)

### 2.3 หลัง login (ไม่มีหน้าจอ — พฤติกรรม)
- ปิด-เปิดแอปในโหมดเครื่องบิน → เข้าได้เลย ไม่ถาม login (AC5)
- token หมดอายุระหว่างออฟไลน์ → **ไม่มีอะไรให้เห็น** บันทึกต่อได้; กลับมาออนไลน์แล้ว refresh เอง (AC7) — ระหว่างรอนับเป็น `ค้างส่ง` ไม่ใช่ error
- refresh ไม่ได้ถาวรเมื่อออนไลน์ (เช่น บัญชีถูกเพิกถอน) → ช่องว่าง: ไม่มี logout ใน MVP แล้วผู้ใช้ทำอะไรต่อ → Q1

## 3. E02-S02 เริ่มใช้งาน: สร้างกลุ่มฟาร์ม

### 3.1 หน้า "เริ่มใช้งาน" (login แล้ว 0 กลุ่ม — AC3)
```
ยินดีต้อนรับ ⟨ชื่อจากบัญชี Google⟩
ต้องมีกลุ่มฟาร์มก่อนจึงจะบันทึกข้อมูลได้
[สร้างกลุ่มฟาร์มใหม่]
[เข้าร่วมด้วยรหัสเชิญ]
```
- ไม่มีทางอื่น (ไม่มีหน้าหลัก ไม่มีการบันทึก) จนกว่าจะมีกลุ่ม (D-24)

### 3.2 Flow — สร้างกลุ่ม
```
‹ กลับ                    สร้างกลุ่มฟาร์ม
ชื่อกลุ่มฟาร์ม*   ____         เช่น ชื่อสวนหรือชื่อครอบครัว
คุณจะเป็นเจ้าของ และเชิญคนอื่นเข้ามาได้ทีหลัง
[สร้าง]
```
1. ตรวจ: ชื่อว่าง → `ใส่ชื่อกลุ่มฟาร์ม`
2. `[สร้าง]` → สร้างในเครื่องทันที **ทำได้ออฟไลน์** (id สร้างในเครื่อง) → เข้ากลุ่มเลย
3. ออฟไลน์: ตัวบอกภาพรวมแสดง `รอส่ง N` จนกลุ่มถูกส่งขึ้นเซิร์ฟเวอร์ — ใช้งานได้ปกติ
4. สร้างแล้วยังเชิญคนอื่นไม่ได้จนกว่ากลุ่มส่งขึ้นแล้ว (การเชิญต้องมีเน็ตอยู่แล้ว) → §4.2 สถานะ
- ไม่มี UI จัดการสิทธิ์ ไม่มีการเลือกบทบาท (ACC-4)

## 4. E02-S03 เชิญและตอบรับด้วยรหัส 6 หลัก

### 4.1 จุดเข้า
ตั้งค่า ▸ `กลุ่มฟาร์ม` ▸ ⟨ชื่อกลุ่ม⟩:
```
‹ ตั้งค่า                  ⟨ชื่อกลุ่ม⟩
สมาชิก ⟨3⟩ คน · ทุกคนเป็นเจ้าของ สิทธิ์เท่ากัน
[เชิญเจ้าของเพิ่ม]
[สลับกลุ่ม ▸]                ← §5 (แสดงเมื่อมี ≥ 2 กลุ่ม)
[เข้าร่วมกลุ่มอื่นด้วยรหัส]
[สร้างกลุ่มฟาร์มใหม่]
—
[ออกจากกลุ่มนี้]              ← แยกห่าง (§6)
```

### 4.2 Flow — สร้างรหัสเชิญ (ต้องมีเน็ต — D-31)
1. `[เชิญเจ้าของเพิ่ม]` → `กำลังสร้างรหัส…`
2. สำเร็จ:
```
รหัสเชิญ
⟨123 456⟩
ใช้ได้ครั้งเดียว หมดอายุ ⟨วันที่ เวลา⟩ (7 วัน)
ส่งรหัสนี้ให้คนที่จะเชิญ แล้วให้เขากด "เข้าร่วมด้วยรหัสเชิญ" ในแอป
[คัดลอกรหัส]   [แชร์รหัส]
```
   - `[แชร์รหัส]` เปิดตัวแชร์ของระบบ (เช่น ส่งทาง LINE) ข้อความ: `รหัสเข้าร่วมกลุ่มฟาร์ม "⟨ชื่อกลุ่ม⟩" ใน ⟨ชื่อแอป⟩: ⟨123456⟩ (ใช้ได้ถึง ⟨วันที่⟩)` + ลิงก์แอป → P4
   - `[คัดลอกรหัส]` → `คัดลอกแล้ว`
3. สถานะ:
   - ออฟไลน์: `สร้างรหัสเชิญต้องต่ออินเทอร์เน็ต` (ไม่สร้างคิวไว้ทำทีหลัง)
   - กลุ่มยังไม่ถูกส่งขึ้นเซิร์ฟเวอร์ (สร้างตอนออฟไลน์): `กลุ่มนี้ยังส่งขึ้นไม่เสร็จ — ต่อเน็ตรอสักครู่แล้วลองอีกครั้ง`
   - error: `สร้างรหัสไม่สำเร็จ — ลองอีกครั้ง` `[ลองอีกครั้ง]`
- ดูรหัสที่สร้างไว้แล้ว / ยกเลิกรหัส → ไม่อยู่ใน AC (Q2)

### 4.3 Flow — เข้าร่วมด้วยรหัส (ต้องมีเน็ต)
```
‹ กลับ                    เข้าร่วมกลุ่มฟาร์ม
รหัสเชิญ 6 หลัก*   ____ ____     ← แป้นตัวเลข; วางรหัสที่คัดลอกมาได้ (ตัดช่องว่าง/ขีดออกเอง)
[เข้าร่วม]
```
1. `[เข้าร่วม]` → `กำลังตรวจรหัส…`
2. สำเร็จ → `เข้าร่วม "⟨ชื่อกลุ่ม⟩" แล้ว` → ดาวน์โหลดข้อมูลกลุ่ม → เข้ากลุ่ม (สถานะ "ครั้งแรกหลังเข้ากลุ่ม" ตามชุดกลาง: `กำลังดึงข้อมูลกลุ่มครั้งแรก…` ใช้งานได้ระหว่างนั้น)
3. ข้อความไทยต่อเหตุ (AC4):

| เหตุ | ข้อความ |
|---|---|
| ไม่ครบ 6 หลัก (ก่อนส่ง) | `ใส่รหัส 6 หลัก` |
| รหัสไม่ถูกต้อง | `ไม่พบรหัสนี้ — ตรวจตัวเลขอีกครั้ง` |
| หมดอายุ | `รหัสนี้หมดอายุแล้ว — ขอรหัสใหม่จากผู้เชิญ` |
| ใช้แล้ว | `รหัสนี้ถูกใช้ไปแล้ว — ขอรหัสใหม่จากผู้เชิญ` |
| เป็นสมาชิกอยู่แล้ว | `คุณอยู่ในกลุ่ม "⟨ชื่อกลุ่ม⟩" แล้ว` `[ไปที่กลุ่มนี้]` |
| ลองผิดเกิน 5 ครั้ง/ชั่วโมง (หรือเพดานรวมของระบบ) | `ลองผิดหลายครั้งเกินไป — รอสักพักแล้วลองอีกครั้ง` (ฟังก์ชันไม่คืนเวลารอ) |
| ออฟไลน์ | `เข้าร่วมกลุ่มต้องต่ออินเทอร์เน็ต` |
| error อื่น | `เข้าร่วมไม่สำเร็จ — ลองอีกครั้ง` `[ลองอีกครั้ง]` |

- ไม่จำกัดจำนวนเจ้าของ (ACC-4) — ไม่มีข้อความ "กลุ่มเต็ม"

## 5. E02-S04 เลือก / สลับกลุ่ม

### 5.1 หน้าเลือกกลุ่ม (≥ 2 กลุ่ม — เปิดแอปทุกครั้ง, ACC-3)
```
เลือกกลุ่มฟาร์ม
⟨ชื่อกลุ่ม⟩  สมาชิก ⟨3⟩ คน  ⟨สถานะ sync: ซิงก์แล้ว / รอส่ง N / ส่งไม่สำเร็จ · ลองใหม่ / ขัดกัน N⟩   ▸
⟨ชื่อกลุ่ม⟩  สมาชิก ⟨2⟩ คน                                        ▸
[สร้างกลุ่มฟาร์มใหม่]   [เข้าร่วมด้วยรหัสเชิญ]
```
- ทำงานออฟไลน์จากรายการในเครื่อง
- กลุ่มที่เพิ่งเข้าร่วมจากเครื่องอื่นของผู้ใช้เดียวกัน: โผล่เมื่อเครื่องนี้ออนไลน์และรีเฟรชรายการแล้ว (architecture) — ออฟไลน์ไม่เห็น ไม่มีข้อความ
- กลุ่มที่กำลังออก (`leaving`) ไม่แสดง (§6)

### 5.2 สลับกลุ่ม
ตั้งค่า ▸ กลุ่มฟาร์ม ▸ `[สลับกลุ่ม ▸]` → รายการเดียวกับ §5.1 → เลือก → `ใช้กลุ่ม "⟨ชื่อ⟩" แล้ว` → หน้าหลักของกลุ่มนั้น
- ทุกหน้าแสดงเฉพาะข้อมูลของกลุ่มที่เลือก (AC2) — ชื่อกลุ่มที่ใช้อยู่แสดงที่หัวหน้าตั้งค่าและหน้าหลัก เพื่อไม่บันทึกผิดกลุ่ม
- สลับขณะมีการขาย Draft เปิดอยู่: การขายนั้นยังอยู่ในกลุ่มเดิม ไม่ย้ายตาม (ไม่มีข้อความ — แค่ไม่แสดง)

## 6. E02-S04 ออกจากกลุ่ม

### 6.1 Flow
1. ตั้งค่า ▸ กลุ่มฟาร์ม ▸ `[ออกจากกลุ่มนี้]`
   - สมาชิกคนสุดท้าย: ปุ่มกดไม่ได้ + `คุณเป็นสมาชิกคนสุดท้าย — ออกไม่ได้ เพราะกลุ่มต้องมีเจ้าของอย่างน้อย 1 คน` (AC7, D-26)
2. หน้ายืนยัน (ยืนยัน 1 ครั้ง — AC3; คำเตือนชัด — AC4, D-33):
```
ออกจากกลุ่ม "⟨ชื่อกลุ่ม⟩"
• กลุ่มและข้อมูลยังอยู่กับสมาชิกคนอื่น
• เครื่องนี้จะส่งข้อมูลที่ค้างอยู่ให้ครบก่อน แล้วลบสำเนาของกลุ่มนี้ออกจากเครื่อง
⟨ไอคอนเตือน⟩ ถ้าคุณใช้บัญชีนี้บนโทรศัพท์หรือคอมพิวเตอร์เครื่องอื่นด้วย
   ข้อมูลที่ยังไม่ได้ส่งจากเครื่องนั้นในกลุ่มนี้จะหาย — ให้เครื่องนั้นต่อเน็ตและส่งให้เสร็จก่อนออก
ค้างส่งจากเครื่องนี้: ⟨N⟩ รายการ
[ออกจากกลุ่ม]                         [ไม่ออก]
```
3. `[ออกจากกลุ่ม]` → กลุ่มหายจากรายการทันที (สถานะ `leaving` — บันทึกเพิ่มไม่ได้) → ไปกลุ่มอื่น / หน้าเลือก / หน้าเริ่มใช้งาน ตามจำนวนกลุ่มที่เหลือ
4. แถบสถานะ `กำลังออกจาก "⟨ชื่อ⟩" — ส่งข้อมูลที่ค้าง ⟨N⟩ รายการ` (ออฟไลน์: `…รอเน็ต`) แสดงที่ตั้งค่า ▸ กลุ่มฟาร์ม,
   หน้าเลือกกลุ่ม และหน้าเริ่มใช้งาน (ถ้าออกจากกลุ่มเดียวที่มี หน้านั้นไม่มีตั้งค่า)
5. เสร็จ → `ออกจาก "⟨ชื่อ⟩" แล้ว` และลบสำเนา (AC8)

### 6.2 สถานะ
- error ถาวรระหว่างส่ง → กลุ่มกลับมาในรายการ ใช้งานได้ + `ออกจากกลุ่มไม่สำเร็จ — ข้อมูลยังอยู่ครบ` `[ลองใหม่]` (architecture)
- สองคนกดออกพร้อมกันแล้วเหลือคนเดียวจริง → กลุ่มกลับมา + `ออกไม่ได้ — คุณเป็นสมาชิกคนสุดท้ายแล้ว`
- แอปถูกปิดกลางทาง / ack หาย → เปิดใหม่ทำต่อเอง ไม่ถามอีก (AC6)
- **เครื่องอื่นของผู้ใช้เดียวกัน** รู้ว่าออกแล้ว (AC5):
```
คุณออกจากกลุ่ม "⟨ชื่อ⟩" จากเครื่องอื่นแล้ว
ข้อมูลของกลุ่มนี้จะถูกลบออกจากเครื่องนี้ ⟨รวมรายการที่ยังไม่ได้ส่ง N รายการ⟩
[ตกลง]
```
  - เป็นการแจ้ง ไม่ใช่การถาม (ตัดสินแล้ว D-33) — ปุ่มเดียว
  - ถ้ากำลังเปิดกลุ่มนั้นอยู่ → ไปกลุ่มอื่น / หน้าเลือก / หน้าเริ่มใช้งาน
- ไม่มีปุ่มลบกลุ่มฟาร์ม (AC10)

## 7. E01-S10 / S11 สถานะ sync และ Conflict

### 7.1 ตัวบอกภาพรวม (ส่วนหัวแอป — S10 AC1)

| สถานะ | คำ (+ ไอคอนตาม design-system §12.10 ข้อ 10) | แตะแล้ว |
|---|---|---|
| Synced | `ซิงก์แล้ว` | แผงรายละเอียด §7.3 |
| Pending Sync (รวมออฟไลน์) | `รอส่ง ⟨N⟩` | แผงรายละเอียด §7.3 |
| error ถาวร | `ส่งไม่สำเร็จ · ลองใหม่` (`ลองใหม่` = ปุ่ม) | แผงรายละเอียด |
| Conflict | `ขัดกัน ⟨N⟩` + `[ลองใหม่]` | แตะคำ → รายการ Conflict §7.4; `[ลองใหม่]` เป็นเป้าแตะแยก → ส่งทันที (S10 AC5/AC6) |

- ลำดับเมื่อมีหลายอย่าง: ขัดกัน → ส่งไม่สำเร็จ → รอส่ง → ซิงก์แล้ว (S10 AC2)
- คำของตัวบอกภาพรวมตามคำตอบเจ้าของ 2026-10-03 (design-system §7) — คำต่อการขาย §7.2 ยังเป็นคำถามเปิดใน E01-S10
- นับเฉพาะ **กลุ่มที่เปิดอยู่**; กลุ่มที่กำลังออกแสดงในแผงรายละเอียดเป็นบรรทัดแยก `กำลังออกจาก "⟨ชื่อ⟩" รอส่ง ⟨N⟩` (push ทำทุกกลุ่ม — architecture §Push)
- ออฟไลน์ = `รอส่ง N` **ไม่ใช่ error** (S10 §Offline)
- เปลี่ยนเองเมื่อ online/offline ไม่ต้อง reload (S10 AC7)
- ใช้งานปกติไม่มีปุ่ม Sync; `[ลองใหม่]` มีเฉพาะ error/Conflict และกดแล้วส่งทันที (S10 AC5, D-3)
- ตำแหน่ง: ทุกหน้าที่มีส่วนหัวแอป; หน้าชั่งใช้แถบบนของตัวเอง (E04 §7) ด้วยคำครบทุกสถานะ: `รอส่ง N` / `ส่งไม่สำเร็จ · ลองใหม่` / `ขัดกัน N` — ไม่ขวางการนับ (design-system §7)

### 7.2 สถานะต่อการขาย (S10 AC2/AC3, D-28)
- แต่ละแถวในรายการการขาย: `ส่งแล้ว` / `ค้างส่ง` / `ขัดกัน` / `ส่งไม่สำเร็จ [ลองใหม่]` — ต่อการขาย ไม่ใช่ต่อเข่ง
- เข่งที่อยู่ใน Conflict มีธง `ขัดกัน` ของตัวเองในรายการเข่ง (S10 AC4)
- ข้อมูลอื่นที่ไม่ใช่การขาย (ข้อมูลหลัก ฯลฯ) → ตาม E03 Q20

### 7.3 แผงรายละเอียด sync (แตะตัวบอกภาพรวม)
```
สถานะการส่งข้อมูล
ค้างส่ง ⟨N⟩ รายการ จากเครื่องนี้ (รวมรูป ⟨M⟩ ไฟล์)
⟨ออฟไลน์: ไม่มีเน็ต — จะส่งเองเมื่อต่อได้⟩ / ⟨กำลังส่ง…⟩
⟨ถ้า error:⟩ ส่งไม่สำเร็จ: ⟨เหตุเป็นภาษาไทย⟩ · ข้อมูลในเครื่องยังอยู่ครบ   [ลองใหม่]
⟨ถ้า Conflict:⟩ ข้อมูลขัดกัน ⟨N⟩ รายการ ▸
ส่งสำเร็จล่าสุด ⟨เวลา⟩
```
- เหตุ error ต่อชนิด (architecture §Push ข้อ 4–5):
  - ถูกปฏิเสธเพราะไม่ได้เป็นสมาชิกแล้ว → **ไม่ใช่ error และไม่มี `[ลองใหม่]`** — ไปข้อความแจ้งของ §6.2 (เครื่องอื่น) ตรง ๆ (architecture §การดำเนินการด้านสมาชิกภาพ)
  - เนื้อหาไม่ตรงกับที่เซิร์ฟเวอร์มี → `ข้อมูลบางรายการไม่ตรงกับที่ส่งไปก่อนหน้า — ไม่ได้เขียนทับ`
  - อื่น ๆ → `ส่งไม่สำเร็จ — ข้อมูลในเครื่องยังอยู่ครบ`
- "ส่งสำเร็จล่าสุด" เป็นข้อเสนอ (P1)

### 7.4 รายการ Conflict (S10 AC6)
```
‹ กลับ                    ข้อมูลขัดกัน (⟨N⟩)
การขาย ⟨วันที่⟩ · เข่ง ⟨12⟩ — น้ำหนัก                       ▸
การขาย ⟨วันที่⟩ — ราคา                                     ▸
คน: ⟨ชื่อ⟩ — ชื่อ                                           ▸
ส่วนแบ่ง: ⟨ชื่อ⟩                                            ▸
```
- เรียงตามการขาย/รายการ; แต่ละแถวบอก "อะไร" และ "ฟิลด์ไหน" ด้วยคำ ไม่ใช่ id
- ว่าง (เพิ่งตัดสินหมด): `ไม่มีข้อมูลขัดกันแล้ว` + กลับอัตโนมัติ

### 7.5 หน้าตัดสิน (S11 AC6)
```
‹ รายการ                  เลือกค่าที่ถูก
การขาย ⟨วันที่⟩ · เข่ง ⟨12⟩ · น้ำหนัก
ตอนนี้ใช้ค่าก่อนแก้: ⟨50⟩ กก.            ← D-29
( ) ⟨45⟩ กก.   แก้โดย ⟨ชื่อ⟩ · ⟨เครื่อง — Q3⟩ · ⟨เวลา⟩
( ) ⟨48⟩ กก.   แก้โดย ⟨ชื่อ⟩ · ⟨เครื่อง — Q3⟩ · ⟨เวลา⟩
( ) ใช้ค่าก่อนแก้ ⟨50⟩ กก.                 ← Q4
[ใช้ค่านี้]
```
- สามเครื่องแก้ต่างกัน → แสดงทุกค่า (SYNC-4 สูงสุด 3 เครื่อง)
- **ลบ vs แก้** (S11 AC8):
```
⟨ชื่อ⟩ ลบรายการนี้ · ⟨เครื่อง⟩ · ⟨เวลา⟩
⟨ชื่อ⟩ แก้เป็น ⟨ค่า⟩ · ⟨เครื่อง⟩ · ⟨เวลา⟩
ตอนนี้: ยังไม่ลบ ใช้ค่าก่อนแก้
( ) ลบ   ( ) เก็บไว้และใช้ค่าที่แก้   ( ) เก็บไว้และใช้ค่าก่อนแก้ (ตาม Q4)
```
- `[ใช้ค่านี้]` → บันทึกเป็นรายการใหม่ ทำได้ออฟไลน์ (S11 AC7) → `เลือกแล้ว — เครื่องอื่นจะเห็นหลังส่งข้อมูล` → รายการถัดไป
- สองเครื่องเลือกต่างกันตอนออฟไลน์ → กลับมาเป็นรายการขัดกันใหม่ (S11 §Offline) — ข้อความเดียวกัน ไม่มีกรณีพิเศษ
- เวลาในแถวใช้แสดงผลเท่านั้น (นาฬิกาเครื่องไม่น่าเชื่อ) — ถ้าเครื่องติดธง `เวลาผิด` แสดงคำนั้นต่อท้ายเวลา

### 7.6 ปิดกั้นการปิด/จ่าย (S11 AC5)
กด `[จบการขาย]` (E04 §13.2) หรือบันทึกการจ่าย (E05) ขณะการขายมี Conflict ใดก็ได้ (รวมหมายเหตุ):
```
ยังจบการขายไม่ได้
มีข้อมูลขัดกัน ⟨N⟩ รายการในการขายนี้ — เลือกค่าที่ถูกก่อน
ระหว่างนี้ยอดคำนวณจากค่าก่อนแก้
[ไปเลือกค่า]                   [ไว้ทีหลัง]
```
- ข้อความจ่ายเงิน: `ยังบันทึกการจ่ายไม่ได้ — มีข้อมูลขัดกันในการขายนี้` `[ไปเลือกค่า]` `[ไว้ทีหลัง]` (หน้าจ่ายอยู่ E05; S11 AC5 พาไปหน้าตัดสิน)
