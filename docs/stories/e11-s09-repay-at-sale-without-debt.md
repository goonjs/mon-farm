## คำอธิบาย

ที่หน้าสรุปยอดส่วนแบ่ง เจ้าของคืนเงินที่สวนต้องคืนให้คนกรีดยางที่**ไม่มีหนี้ให้หัก**ได้ในการขายนั้นเลย
เงินคืนเป็นเรื่องหนี้ ไม่ใช่ยอดขาย (น้ำหนัก × ราคา): แสดงแยกจากยอดขาย ด้วยสีและสัญลักษณ์ของทิศ "สวน → คนกรีดยาง"
และหน้าเทียบยอดยังรวมทุกกองได้เท่ายอดขาย

## เรื่องที่ต้องตัดสินใจ (ยังไม่ตกลง)

1. **ทำไหม** — หรือให้คืนนอกการขายต่อไป (E11-S03) แล้วหน้าสรุปเงินแค่**เตือน**ว่า "สวนยังต้องคืนนัด 640"
2. **เงินมาจากไหน** ถ้าทำ:
   - (ก) คนรับซื้อยางย้ายจากส่วนเจ้าของสวนไปใส่กองเงินสดของคนกรีดยาง → ยอดโอนเจ้าของลดเท่ายอดคืน; กองยังรวมเท่ายอดขาย
   - (ข) เจ้าของจ่ายจากเงินสดในมือเอง (ไม่ใช่เงินจากการขาย) → ไม่อยู่ในกองของการขาย แค่บันทึกการคืนอ้างถึงการขาย
   - (ค) อื่น ๆ
3. ถ้าคนกรีดยางมีทั้งหนี้และเงินที่สวนต้องคืน: บังคับหักกลบก่อน หรือให้เลือกคืนเป็นเงินสดได้

## Acceptance criteria (ร่าง — ใช้เมื่อตัดสินใจแล้ว)

- [ ] การ์ดคนกรีดยางที่สวนต้องคืนเงิน (แต่ไม่มีหนี้) มีปุ่ม "คืนเงินให้{ชื่อ}" แสดงยอดที่สวนต้องคืน
- [ ] คืนบางส่วนได้ 0 ถึงยอดที่ต้องคืน; ตัดรายการเก่าสุดก่อน (E11-S03)
- [ ] บันทึกเป็นการคืน (E11-S03) อ้างถึงการขาย; การขายถูกยกเลิก/ลบ → การคืนยกเลิกตาม (กู้คืน → กลับมานับ)
- [ ] แสดงในส่วน "เรื่องหนี้ (ไม่ใช่ยอดขาย)" ด้วยสี/สัญลักษณ์ทิศ สวน → คนกรีดยาง ไม่ปนกับยอดขาย
- [ ] หน้าเทียบยอด: Σ กอง = ยอดขาย ตรงถึงสตางค์ (D-72) ทุกทางเลือกของข้อ 2
- [ ] ยอดขายรวม และส่วนแบ่งคนกรีดยาง ไม่เปลี่ยนเพราะการคืน
