## คำอธิบาย

หน้าแรกตอบคำถาม "ตอนนี้มีอะไรที่ฉันควรรู้หรือควรจัดการ?" เป็นรายการเดียว
เรียงตามความสำคัญ กดแต่ละรายการแล้วไปที่บันทึกต้นทาง

## Acceptance criteria

- [ ] รายการเรียงลำดับ: ปัญหาเร่งด่วน, งานถึงกำหนด, เอกสารใกล้หมด, เหตุการณ์ที่เปิดอยู่, แจ้งเตือนอากาศ, การขายล่าสุด, เงินที่ต้องคืน/ค่าใช้จ่ายที่จะมาถึง, สต็อกใกล้หมด (ANA-1)
- [ ] แต่ละแหล่งเป็น "ตัวป้อนรายการ" แยกกัน เพิ่มแหล่งใหม่ได้โดยไม่แก้หน้าจอ (ANA-1)
- [ ] กดรายการ → เปิดบันทึกต้นทาง (ANA-1, ANA-3)
- [ ] ไม่มีรายการ → ข้อความ "ไม่มีอะไรต้องจัดการ"; แสดงสถานะ sync ภาพรวมบนหน้านี้ (SYNC-3)
- [ ] ใช้มือเดียวได้บนมือถือแนวตั้ง ปุ่มสูง ≥ 48 (NFR-4)

## Offline / sync

- รายการคำนวณจากข้อมูลในเครื่องทั้งหมด → ใช้ได้ออฟไลน์; อากาศ/AI ที่ต้องเน็ตแสดงข้อมูลล่าสุด + ป้าย "ข้อมูลเก่า"
