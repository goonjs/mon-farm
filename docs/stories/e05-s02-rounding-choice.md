## คำอธิบาย

เมื่อการแบ่งเกิดเศษสตางค์ แอปถามก่อนสรุปเงิน 3 ทาง ค่าเริ่มต้นคือตัวเลือกล่าสุด
ส่วนปรับจากการปัดเศษแสดงและเก็บเป็นบรรทัดของตัวเอง

## Acceptance criteria

- [ ] ปัดเศษ **หลังหักหนี้** (E06-S04): ลำดับ = ส่วนแบ่ง → หักหนี้ → ปัดเศษ → เงินสดที่ต้องจ่าย (D-60)
- [ ] มีเศษสตางค์ → ถามก่อนสรุปเงิน: *ปัดเป็นบาทเต็มให้คนกรีดได้ประโยชน์* · *ให้เจ้าของได้ประโยชน์* · *ไม่ปัด (เก็บสตางค์)* (SET-5)
- [ ] ไม่มีเศษ → ไม่ถาม
- [ ] ตัวเลือกที่เลือกถูกเก็บเป็น event ของการขาย และเป็นค่าเริ่มต้นของการขายครั้งถัดไป
- [ ] ส่วนปรับจากการปัดเศษเป็นบรรทัดแยกต่อคนกรีด (บวก/ลบ สตางค์) เจ้าของ + คนกรีด + ส่วนปรับ = ยอดการขายพอดี (NFR-3)
- [ ] เปลี่ยนตัวเลือกหลังสรุปแล้วได้ ยอดคำนวณใหม่จาก log (ไม่เขียนทับ)
- [ ] ไม่มีการปัดเศษแบบ hard-code เหลือใน `settle.ts`

## Offline / sync

- ตัวเลือกเป็น event ออฟไลน์ได้; sync เหมือน event อื่น
