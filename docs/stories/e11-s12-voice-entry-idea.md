# Story E11-S12: พูดเพื่อบันทึกใบซื้อปุ๋ย (ไอเดีย — ยังไม่เริ่ม)

Status: Draft (ไอเดียจากเจ้าของ 2026-10-27 — เก็บไว้ ยังไม่ทำจนกว่า E11-S11 เสร็จ)

## Context

- ต่อยอดจาก `docs/stories/e11-s11-fertilizer-order.md` (ใบซื้อปุ๋ย + รายละเอียดทีหลัง) — เสียงเป็น**ทางลัดกรอกฟอร์มเดิม** ไม่ใช่หน้าใหม่ทางการเงิน
- ของที่มีแล้ว: `expo-speech` (พูดออก) ใน `src/speech/` (`speaker.native.ts` / `speaker.web.ts`) และ `docs/stories/e04-s08-thai-voice-basket-number.md` (อ่านเลขตะกร้าเป็นเสียงไทย) — ฝั่ง**ฟัง** (speech-to-text) ยังไม่มี

## ทำไม (เจ้าของ)

มือเปื้อน อยู่กลางแดด อยากพูดว่า "สั่งปุ๋ยสิบห้าสิบห้าสิบห้า ยี่สิบกระสอบ ..." แล้วแอปเติมช่องให้ ทวนให้ฟัง และให้ยืนยัน

## หลักออกแบบ (ร่าง)

1. **พูดแล้วไม่บันทึกเอง** เติมลงหน้าใบซื้อเดิม (จอ a5) ช่องที่ได้ยินขึ้นไฮไลต์ ผู้ใช้ตรวจแล้วกดบันทึก (หรือพูด "ยืนยัน")
2. **ทวนเป็นเสียง + ตัวเลข**: "15-15-15 ยี่สิบกระสอบ กระสอบละหนึ่งพันหนึ่งร้อยห้าสิบ รวมสองหมื่นสามพันบาท ถูกไหม" พร้อมปุ่มใหญ่ ✓ / ✗ ใช้ตัวเลขใหญ่บนจอด้วย ไม่พึ่งเสียงอย่างเดียว
3. **แก้ด้วยเสียงได้**: "แก้กระสอบเป็นสามสิบ", "ลบรายการสอง", "ร้านลดห้าร้อย"
4. **พูดตามรูปแบบที่แตกช่องง่าย** (ให้ตัวแยกคำเป็นกฎล้วน ไม่ต้องพึ่ง AI): ลำดับ ร้าน → (ชื่อปุ๋ย → จำนวน "กระสอบ" → ราคา "กระสอบละ"/"รวม") ซ้ำต่อรายการ → "ลด …" → จบด้วย "เสร็จ" ตัวอย่าง
   - "ร้านเจริญ ปุ๋ยสิบห้าสิบห้าสิบห้า ยี่สิบกระสอบ กระสอบละพันร้อยห้าสิบ ยูเรีย สิบกระสอบ กระสอบละเก้าร้อยห้าสิบ เสร็จ"
   - ทีหลัง (รายละเอียด): "สิบห้า ใส่แปลงหน้าแปดกระสอบ แปลงหลังบ้านสี่กระสอบ" · "แดงรับหกกระสอบ นัดสี่กระสอบ"
5. **จับคู่ชื่อกับของที่รู้จัก** (สูตร/ร้าน/คน/โซนที่บันทึกไว้) แบบใกล้เคียง ถ้าความมั่นใจต่ำให้ถามกลับ "หมายถึงสิบห้าสิบห้าสิบห้าตราใบไม้ทองใช่ไหม" ไม่เดา
6. **เลขไทยพูด → ตัวเลข**: คำนวณจากคำ (หนึ่งพัน, สองหมื่น, ร้อยห้าสิบ, จุดห้า) มีชุดทดสอบเฉพาะ

## ทางเทคนิคที่ต้องตัดสินใจ

- **ไลบรารีฟังเสียงแบบ native**: Android `SpeechRecognizer` (th-TH, ถ้าเครื่องโหลดโมเดลออฟไลน์ไว้จะไม่ใช้เน็ต), iOS `SFSpeechRecognizer`; ตัวห่อสำหรับ Expo เป็นแพ็กเกจเพิ่ม (เช่น `expo-speech-recognition` ของชุมชน) → **ต้องขออนุญาตและแสดงผลตรวจความปลอดภัยก่อนติดตั้ง** ตาม AGENTS.md; ยังไม่ได้ติดตั้งอะไร
- **เว็บ**: Web Speech API (เฉพาะ Chrome/Edge, ต้องออนไลน์) เป็นแค่ทางเลือกเสริม; Android มือถือเป็นหลัก
- **ออฟไลน์-first**: ถ้าฟังไม่ได้ (ไม่มีโมเดล/ไม่มีเน็ต) ปุ่มไมค์ซ่อนหรือบอกชัดว่าใช้ไม่ได้ ฟอร์มปกติใช้ได้เสมอ
- **ความเป็นส่วนตัว**: ไม่เก็บเสียงไว้ ไม่ส่งไปเซิร์ฟเวอร์เรา (ถ้า OS ส่งไปบริการของระบบเอง ต้องบอกผู้ใช้ตอนขอสิทธิ์ไมค์)
- ตัวแยกคำเป็นฟังก์ชันล้วนใน `src/core` (ข้อความ → ช่องของใบซื้อ + ความมั่นใจต่อช่อง) ทดสอบ TDD ด้วยประโยคจริงที่เจ้าของพูด; AI (E14) เป็นตัวเลือกภายหลังเมื่อกฎไม่พอ

## Acceptance criteria (ร่าง)

- [ ] ปุ่มไมค์บนหน้าใบซื้อ: แตะเพื่อพูด แสดงข้อความที่ได้ยินสด ๆ
- [ ] พูดตามรูปแบบข้อ 4 ได้ผลเท่ากับกรอกมือ (ชุดทดสอบประโยค ≥ 30 แบบ รวมเลขสตางค์/จุดทศนิยม/สำเนียงเลขพูด)
- [ ] ทวนเป็นเสียงไทยพร้อมสรุปบนจอ; ✓ = บันทึก, ✗ = กลับไปแก้; ไม่เคยบันทึกเองเมื่อไม่ได้ยืนยัน
- [ ] ช่องมั่นใจต่ำถูกไฮไลต์และถามกลับ ไม่เดา
- [ ] ใช้พูดเติมรายละเอียดทีหลังได้ (โซน คนกรีด เหตุผล)
- [ ] ไม่มีสิทธิ์ไมค์ / ไม่รองรับ / ออฟไลน์ → ฟอร์มมือใช้ได้ปกติ ไม่ error
- [ ] ผ่านการทดสอบกลางแดด/เสียงรบกวน (QA ภาคสนาม) และข้อมูลเสียงไม่ถูกเก็บ

## คำถามเปิดสำหรับเจ้าของ

1. พูดภาษากลางอย่างเดียวพอไหม หรือต้องรองรับสำเนียงใต้/คำท้องถิ่น (กี่ "ถุง" แทน "กระสอบ")?
2. ใช้ในรถ/กลางสวนที่ไม่มีสัญญาณบ่อยไหม (ถ้าบ่อย ต้องดูโมเดลออฟไลน์เป็นข้อบังคับ)
3. อยากให้พูดได้กับหน้าอื่นต่อไปไหม (ค่าใช้จ่ายทั่วไป, การขาย) หรือเฉพาะใบซื้อปุ๋ย
