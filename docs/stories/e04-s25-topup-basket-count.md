## อาการ

1. การ์ดบนหน้าตรวจยอดเขียน "เข่งไม่เต็ม (4 เข่ง) 101 กก." แต่รายการใต้มีแค่ 2 แถว
2. "จำนวนเข่ง 155" แต่การ์ดคนกรีดรวมกันได้ 157
- น้ำหนักและยอดเงินถูกทุกที่ ผิดแค่จำนวนเข่ง

## สาเหตุ

| ที่ | ไฟล์ | ทำอะไรตอนนี้ |
|---|---|---|
| การ์ดบน (จำนวนเข่ง, เข่งไม่เต็ม) | `tally()` ใน `src/core/totals.ts` | นับเข่งเป็น "ไม่เต็ม" ตามชนิดของส่วนแรก แม้เติมจนเต็มแล้ว · ไม่นับส่วนเติม (`partOf`) เป็นเข่ง |
| รายการเข่งไม่เต็มใต้การ์ดบน | `basketList()` ใน `src/core/sale-points.ts` | ถือว่าเข่งที่เติมจนเต็มเป็นเข่งเต็ม (ถูกตามกฎใหม่) |
| การ์ดคนกรีด (เต็ม N / ไม่เต็ม N ต่อจุด) | `saleRollup` → `one()` ใน `src/core/sale-points.ts` | นับทุก event เป็น 1 เข่ง รวมส่วนเติมด้วย → เข่งเกิน |

## Acceptance criteria

- [ ] **TB-1** เข่งที่เริ่มเป็นไม่เต็มแล้วเติมจนเต็ม (ที่จุดเดิมหรือจุดอื่น) นับเป็น **1 เข่งเต็ม** ในทุกที่ที่แสดงจำนวนเข่ง: การ์ดบนหน้าตรวจยอด, การ์ดคนกรีด, รายการเข่งไม่เต็ม
- [ ] **TB-2** ส่วนที่เติม ไม่นับเป็นเข่งใหม่ ไม่ว่าที่ไหน
- [ ] **TB-3** เข่งที่ยังไม่เต็มจริง (ไม่ได้เติม หรือเติมแล้วยังไม่เต็ม) ยังนับเป็นไม่เต็มเหมือนเดิม
- [ ] **TB-4** น้ำหนักรวมและยอดเงินไม่เปลี่ยน (น้ำหนักย้ายจาก "ไม่เต็ม" ไป "เต็ม" ตามจำนวนเข่ง) · กก. ของ "เข่งไม่เต็ม" บนการ์ดบนเท่ากับผลรวมของแถวเข่งไม่เต็มในรายการใต้ (ภาพเจ้าของ: "เข่งไม่เต็ม (4 เข่ง) 101 กก." → "(2 เข่ง) 44 กก.")
- [ ] **TB-5** ตัวเลขในภาพของเจ้าของต้องตรงกัน: การ์ดบน "เข่งไม่เต็ม (N เข่ง)" มีจำนวนเท่ากับจำนวนแถวในรายการใต้ และจำนวนเข่งบนการ์ดบนเท่ากับผลรวมของการ์ดคนกรีด
