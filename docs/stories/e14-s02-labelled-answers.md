## คำอธิบาย

ทุกคำตอบของ AI แยกเป็นข้อ ๆ ติดป้ายชนิด และอ้างบันทึกต้นทางที่กดดูได้
ถ้าข้อมูลไม่พอ ตอบว่าไม่รู้พร้อมบอกว่าขาดอะไร

## Acceptance criteria

- [ ] ทุกข้อติดป้าย: ข้อเท็จจริง · รูปแบบ/ความสัมพันธ์ · การตีความ · ข้อแนะนำ · ไม่รู้ (AI-1)
- [ ] ข้อเท็จจริงอ้าง id บันทึกต้นทาง กดแล้วเปิดบันทึกนั้นได้; server ตรวจว่า id มีอยู่จริงในกลุ่ม (AI-1)
- [ ] ข้อมูลไม่พอ → "ไม่รู้ / ข้อมูลไม่เพียงพอ" + ขาดอะไร + อะไรจะช่วยได้ (AI-2)
- [ ] รูปแบบ/ความสัมพันธ์ ไม่ถูกเขียนเป็นเหตุและผล (ANA-9)
- [ ] ผลลัพธ์ AI แสดง chip "AI แนะนำ" ไม่ใช้สีฟ้า/เขียว (design-system §12.9 ข้อ 9)

## Offline / sync

- คำตอบที่ได้มาแล้วในหน้าจอยังอ่านได้เมื่อเน็ตหลุด; ลิงก์อ้างอิงเปิดได้ออฟไลน์เพราะบันทึกอยู่ในเครื่อง

## Test plan

- [ ] Unit: แปลงผลลัพธ์โมเดล (schema) → ข้อที่มีป้าย; ผลลัพธ์ผิด schema → แสดง "ตอบไม่ได้" ไม่เดา
- [ ] Unit: อ้าง id ที่ไม่มีจริง → ตัดออกและลดเป็น "ไม่รู้"
- [ ] Eval: ชุดคำถามตัวอย่างที่ข้อมูลไม่พอ ต้องได้ "ไม่รู้" (fake + โมเดลจริงแบบ manual)
