# Story E14-S06: AI จัดประเภทการตรวจสวน

Status: Draft

## Context

- Epic: `docs/epics/e14-ai-assistance.md`
- PRD: OPS-3, SYNC-11, SYNC-12, AI-1
- ขึ้นกับ: E14-S01, E07 (การตรวจสวน: โน้ต/เสียง/รูป, เช็กลิสต์สุขภาพต้นยาง)
- ใช้ป้ายจาก E01-S15 (สถานะข้อมูลรายฟิลด์ SYNC-12)

## คำอธิบาย

เมื่อออนไลน์ AI อ่านโน้ตการตรวจสวน แล้วเสนอประเภทและฟิลด์แบบมีโครงสร้าง
ผลยังเป็น "AI แนะนำ / รอตรวจ" จนเจ้าของยืนยันหรือแก้

## Acceptance criteria

- [ ] AI เสนอประเภทการสังเกตและฟิลด์ (เช่น หัวข้อในเช็กลิสต์สุขภาพ) จากโน้ต (OPS-3)
- [ ] ค่าที่ AI เสนอติด "AI แนะนำ / รอตรวจ" และไม่นับเป็นข้อเท็จจริงในกราฟ/AI จนกว่ายืนยัน (OPS-3, SYNC-12)
- [ ] เจ้าของ ยืนยัน · แก้ · ปฏิเสธ ได้ทีละรายการ; โน้ต/เสียงต้นฉบับไม่ถูกแก้ (OPS-1, SYNC-11)
- [ ] รายการ "รอตรวจ" แสดงในหน้าวันนี้ (ANA-1)

## Offline / sync

- บันทึกการตรวจสวนออฟไลน์ได้ตามปกติ (E07); การจัดประเภทเกิดเมื่อออนไลน์เท่านั้น ระหว่างนั้นแสดง "ยังไม่ได้จัดประเภท"
- ยืนยัน/แก้ เป็น event → ทำได้ออฟไลน์เมื่อมีคำแนะนำอยู่ในเครื่องแล้ว

## Test plan

- [ ] Offline: ตรวจสวนออฟไลน์ → ต่อเน็ต → ได้คำแนะนำ

- จัดประเภทอัตโนมัติทุกครั้งที่ sync (มีค่าโมเดลทุกบันทึก) หรือเฉพาะเมื่อกดปุ่ม "ให้ AI จัดประเภท"?
- ถอดเสียงพูด (เสียง → ข้อความ) อยู่ใน story นี้ไหม หรือ AI อ่านเฉพาะโน้ตที่พิมพ์?
