## คำอธิบาย

เข่งไม่เต็มเปิดค้างไว้ ต่อได้ที่จุดชั่งอื่นของคนกรีดคนเดิม (เป็นเข่งเชื่อม) หรือปิดเป็นเศษ

## Acceptance criteria

- [ ] พิมพ์ค่าที่ตาชั่งอ่าน → สุทธิ = ค่าที่อ่าน − tare; เก็บและแสดงทั้งสองค่า (SALE-9)
- [ ] เข่งไม่เต็มเปิดค้างเป็นค่าเริ่มต้น (SALE-11)
- [ ] ย้ายไปจุดของคนกรีดคนเดิม → ถาม "เติมเข่ง N ต่อ" หรือ "เริ่มเข่งใหม่" (เข่งเดิมปิดเป็นเศษ) (SALE-11) — ป้ายตามคำตอบเจ้าของ 2026-10-03: "เติมเข่งต่อ" / "เริ่มเข่งเต็มใหม่"; หน้าถามบอก กก. ที่ต้องเติม และค่าที่ตาชั่งควรอ่าน; ตัวเลือกครบตาม D-42 ในข้อถัดไป
- [ ] ตัวเลือกที่จุดถัดไปของคนกรีดคนเดิม (D-42, คำตอบ ?17):
  - (1) เติมเข่ง N จนเต็ม — ตาชั่งควรอ่าน = น้ำหนักเต็มเข่ง + tare (เช่น 52) → กดค้างนับเป็นเข่ง N
  - (2) ชั่งส่วนที่เติมแยก — ตาชั่งควรอ่าน = ส่วนที่ต้องเติม + tare (เช่น ต้องเติม 15 กก. → ตาชั่ง 17 เมื่อ tare 2) → กดค้างนับ รวมเป็นเข่ง N
  - (3) เริ่มเข่งเต็มใหม่ เลขต่อเนื่อง (N+1) — เข่ง N ปิดเป็นเข่งไม่เต็ม
  - (4) เริ่มเข่งเต็มใหม่ และนับใหม่จากเข่ง 1 — **ยังไม่ทำ** รอคำตอบ ?20 (ขัดกับ SALE-10 / E04-S01) — SALE-10 ไม่เปลี่ยน
- [ ] การ์ดเข่งไม่เต็มแสดง กก. ที่ยังขาดจนเต็มเข่ง (น้ำหนักสุทธิมาตรฐาน − ส่วนที่มีแล้ว)
- [ ] ย้ายไปจุดของคนกรีดคนอื่น → เข่งเดิมปิดเป็นเศษก่อนเสมอ ไม่ถาม (SALE-12)
- [ ] ปุ่ม "จบเข่งแล้ว / เป็นเศษ" ปิดเข่งเป็นเศษ ไม่เสนอต่ออีก เลขถัดไปพร้อม (SALE-13)
- [ ] แสดง "เข่ง 11 — (20 + 30) กก. = 50 กก."; ยอดของแต่ละจุดรวมเฉพาะส่วนของตัวเอง (SALE-11)

## คำถามเจ้าของ

- เข่งเชื่อมที่รวมครบน้ำหนักมาตรฐาน (20 + 30 = 50): (a) ปิดเป็นเข่งเต็มอัตโนมัติ · (b) ผู้บันทึกกดปิดเอง · (c) ยังนับเป็นเข่งไม่เต็มเสมอ

**คำตอบเจ้าของ (2026-10-03):**
- เข่งเชื่อมรวมครบน้ำหนักมาตรฐาน → **ปิดเป็นเข่งเต็มอัตโนมัติ** ยังแสดง (20 + 30)

**คำตอบเจ้าของ (2026-10-03) — จาก mockup `docs/ux/mockups/flow-v1.html`:**
- หน้าจอใหม่: การ์ดเข่งไม่เต็มแสดง **กก. ที่ยังขาดจนเต็มเข่ง**
- หน้าจอใหม่: ย้ายไปจุดถัดไปของคนกรีดคนเดิม → ตัวเลือก **"เติมเข่งต่อ"** กับ **"เริ่มเข่งเต็มใหม่"** และบอก **กก. ที่ต้องเติม + ค่าที่ตาชั่งควรอ่าน**

**คำตอบเจ้าของ (2026-10-03) — ?17 เติมเข่งที่จุดถัดไปของคนกรีดคนเดิม (D-42):** มี 4 ตัวเลือก
1. เติมเข่ง N จนเต็ม — ตาชั่งอ่านเต็ม + tare (เช่น 52) — กดค้างเพื่อนับ
2. ชั่งส่วนที่เติมแยก (เช่น 15 กก. → ตาชั่ง 17 เมื่อ tare 2) นับรวมเป็นเข่ง N — กดค้างเพื่อนับ
3. เริ่มเข่งเต็มใหม่ เลขต่อเนื่อง (N+1) — เข่ง N ปิดเป็นเข่งไม่เต็ม
4. เริ่มเข่งเต็มใหม่ และเริ่มนับใหม่จากเข่ง 1

- คำถามเปิดเดิม "ค่าที่ตาชั่งควรอ่านตอนเติมเข่งต่อ (a) หรือ (b)" ปิดแล้ว — มีทั้งสองแบบ: ข้อ 2 = (a), ข้อ 1 = (b)
- ข้อ 4 **ขัด** กับ SALE-10 / E04-S01 (เลขเข่งต่อเนื่องตลอดทั้งการขาย ไม่เริ่มใหม่ต่อจุด) — ยังไม่แก้ SALE-10 และยังไม่ทำข้อ 4 จนกว่าจะได้คำตอบ ?20

คำถามเปิด (ยังไม่ได้ถาม):
- **?20** ตัวเลือกที่ 4 "เริ่มนับใหม่จากเข่ง 1" หมายถึงอะไร: (a) เลขเข่งเริ่มใหม่ต่อจุดชั่ง/ต่อคนกรีด (ต้องแก้ SALE-10 ซึ่งตอนนี้ห้ามเริ่มใหม่ต่อจุด) · (b) แค่ตัวนับบนหน้าจอของจุดนี้เริ่มที่ 1 ส่วนเลขเข่งของการขายยังต่อเนื่องตาม SALE-10?
- ข้อ 1 / ข้อ 2 "กดค้างเพื่อนับ": ถ้าตาชั่งอ่านไม่ตรงค่าที่ควรอ่าน (ขาดหรือเกิน) ทำอย่างไร — ใช้ช่องพิมพ์ค่าที่ตาชั่งอ่านแทนไหม? (เกินน้ำหนักเข่งเต็มยังเป็น Q10 ใน `docs/ux/flows/e04-weighing-sale.md`)
