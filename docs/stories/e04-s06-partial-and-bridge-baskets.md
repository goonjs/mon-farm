- [ ] ตัวเลือกที่จุดถัดไปของคนกรีดคนเดิม (D-42, คำตอบ ?17):
  - (1) เติมเข่ง N จนเต็ม — ตาชั่งควรอ่าน = น้ำหนักเต็มเข่ง + tare (เช่น 52) → กดค้างนับเป็นเข่ง N
  - (2) ชั่งส่วนที่เติมแยก — ตาชั่งควรอ่าน = ส่วนที่ต้องเติม + tare (เช่น ต้องเติม 15 กก. → ตาชั่ง 17 เมื่อ tare 2) → กดค้างนับ รวมเป็นเข่ง N

  - (4) เริ่มเข่งเต็มใหม่ และนับใหม่จากเข่ง 1 — ?20 ตอบแล้ว: นับใหม่ **ต่อจุดชั่ง** = ใช้โหมดเลขเข่ง (b) ของ SALE-10 (D-46); ข้อ 4 ไม่ถูกบล็อกแล้ว
- [ ] โหมด (b) นับแยกต่อจุดชั่ง (D-46): แต่ละจุดชั่งเริ่มที่เข่ง 1 และมีเข่งไม่เต็มของตัวเองได้; ยอดของแต่ละจุดและยอดรวมการขายยังถูก (สรุปเงินใช้น้ำหนักรวม)
- [x] การ์ดเข่งไม่เต็มแสดง กก. ที่ยังขาดจนเต็มเข่ง (น้ำหนักสุทธิมาตรฐาน − ส่วนที่มีแล้ว)
- [x] ย้ายไปจุดของคนกรีดคนอื่น → เข่งเดิมปิดเป็นเศษก่อนเสมอ ไม่ถาม (SALE-12)
- [x] ปุ่ม "จบเข่งแล้ว / เป็นเศษ" ปิดเข่งเป็นเศษ ไม่เสนอต่ออีก เลขถัดไปพร้อม (SALE-13)
