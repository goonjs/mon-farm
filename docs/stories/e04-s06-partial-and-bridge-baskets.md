# Story E04-S06: เข่งไม่เต็ม เข่งเชื่อม และ "จบเข่งแล้ว / เป็นเศษ"

- ขึ้นกับ: E04-S05, E03-S05 (คนกรีดของจุดชั่ง)

## คำอธิบาย

เข่งไม่เต็มเปิดค้างไว้ ต่อได้ที่จุดชั่งอื่นของคนกรีดคนเดิม (เป็นเข่งเชื่อม) หรือปิดเป็นเศษ

## Acceptance criteria

- [ ] พิมพ์ค่าที่ตาชั่งอ่าน → สุทธิ = ค่าที่อ่าน − tare; เก็บและแสดงทั้งสองค่า (SALE-9)
- [ ] เข่งไม่เต็มเปิดค้างเป็นค่าเริ่มต้น (SALE-11)
- [ ] ย้ายไปจุดของคนกรีดคนเดิม → ถาม "เติมเข่ง N ต่อ" หรือ "เริ่มเข่งใหม่" (เข่งเดิมปิดเป็นเศษ) (SALE-11) — ป้ายตามคำตอบเจ้าของ 2026-10-03: "เติมเข่งต่อ" / "เริ่มเข่งเต็มใหม่"; หน้าถามบอก กก. ที่ต้องเติม และค่าที่ตาชั่งควรอ่าน
- [ ] การ์ดเข่งไม่เต็มแสดง กก. ที่ยังขาดจนเต็มเข่ง (น้ำหนักสุทธิมาตรฐาน − ส่วนที่มีแล้ว)
- [ ] ย้ายไปจุดของคนกรีดคนอื่น → เข่งเดิมปิดเป็นเศษก่อนเสมอ ไม่ถาม (SALE-12)
- [ ] ปุ่ม "จบเข่งแล้ว / เป็นเศษ" ปิดเข่งเป็นเศษ ไม่เสนอต่ออีก เลขถัดไปพร้อม (SALE-13)
- [ ] แสดง "เข่ง 11 — (20 + 30) กก. = 50 กก."; ยอดของแต่ละจุดรวมเฉพาะส่วนของตัวเอง (SALE-11)

## คำถามเจ้าของ

- เข่งเชื่อมที่รวมครบน้ำหนักมาตรฐาน (20 + 30 = 50): (a) ปิดเป็นเข่งเต็มอัตโนมัติ · (b) ผู้บันทึกกดปิดเอง · (c) ยังนับเป็นเข่งไม่เต็มเสมอ

**คำตอบเจ้าของ (2026-10-03):**
- เข่งเชื่อมรวมครบน้ำหนักมาตรฐาน → **ปิดเป็นเข่งเต็มอัตโนมัติ** ยังแสดง (20 + 30)

**คำตอบเจ้าของ (2026-10-03) — จาก mockup `docs/ux/mockups/flow-v1.html`:**
- หน้าจอใหม่: การ์ดเข่งไม่เต็มแสดง **กก. ที่ยังขาดจนเต็มเข่ง**
- หน้าจอใหม่: ย้ายไปจุดถัดไปของคนกรีดคนเดิม → ตัวเลือก **"เติมเข่งต่อ"** กับ **"เริ่มเข่งเต็มใหม่"** และบอก **กก. ที่ต้องเติม + ค่าที่ตาชั่งควรอ่าน**

คำถามเปิด (ยังไม่ได้ถาม):
- ค่าที่ตาชั่งควรอ่านตอนเติมเข่งต่อ: (a) ส่วนที่ต้องเติม + tare (ชั่งเฉพาะส่วนใหม่) · (b) น้ำหนักเต็มเข่ง + tare (ชั่งทั้งเข่งที่มีของเดิมอยู่)?
