## คำอธิบาย

เข่งไม่เต็มเปิดค้างไว้ ต่อได้ที่จุดชั่งอื่นของคนกรีดคนเดิม (เป็นเข่งเชื่อม) หรือปิดเป็นเศษ

## Acceptance criteria

- [ ] พิมพ์ค่าที่ตาชั่งอ่าน → สุทธิ = ค่าที่อ่าน − tare; เก็บและแสดงทั้งสองค่า (SALE-9)
- [ ] เข่งไม่เต็มเปิดค้างเป็นค่าเริ่มต้น (SALE-11)
- [ ] ย้ายไปจุดของคนกรีดคนเดิม → ถาม "เติมเข่ง N ต่อ" หรือ "เริ่มเข่งใหม่" (เข่งเดิมปิดเป็นเศษ) (SALE-11) — ป้ายตามคำตอบเจ้าของ 2026-10-03: "เติมเข่งต่อ" / "เริ่มเข่งเต็มใหม่"; หน้าถามบอก กก. ที่ต้องเติม และค่าที่ตาชั่งควรอ่าน; ตัวเลือกครบตาม D-42 ในข้อถัดไป
- [ ] ตัวเลือกที่จุดถัดไปของคนกรีดคนเดิม (D-42, คำตอบ ?17):
  - (1) เติมเข่ง N จนเต็ม — ตาชั่งควรอ่าน = น้ำหนักเต็มเข่ง + tare (เช่น 52) → กดค้างนับเป็นเข่ง N
  - (2) ชั่งส่วนที่เติมแยก — ตาชั่งควรอ่าน = ส่วนที่ต้องเติม + tare (เช่น ต้องเติม 15 กก. → ตาชั่ง 17 เมื่อ tare 2) → กดค้างนับ รวมเป็นเข่ง N
  - (3) เริ่มเข่งเต็มใหม่ เลขต่อเนื่อง (N+1) — เข่ง N ปิดเป็นเข่งไม่เต็ม
  - (4) เริ่มเข่งเต็มใหม่ และนับใหม่จากเข่ง 1 — ?20 ตอบแล้ว: นับใหม่ **ต่อจุดชั่ง** = ใช้โหมดเลขเข่ง (b) ของ SALE-10 (D-46); ข้อ 4 ไม่ถูกบล็อกแล้ว
- [ ] โหมด (b) นับแยกต่อจุดชั่ง (D-46): แต่ละจุดชั่งเริ่มที่เข่ง 1 และมีเข่งไม่เต็มของตัวเองได้; ยอดของแต่ละจุดและยอดรวมการขายยังถูก (สรุปเงินใช้น้ำหนักรวม)
- [ ] การ์ดเข่งไม่เต็มแสดง กก. ที่ยังขาดจนเต็มเข่ง (น้ำหนักสุทธิมาตรฐาน − ส่วนที่มีแล้ว)
- [ ] ย้ายไปจุดของคนกรีดคนอื่น → เข่งเดิมปิดเป็นเศษก่อนเสมอ ไม่ถาม (SALE-12)
- [ ] ปุ่ม "จบเข่งแล้ว / เป็นเศษ" ปิดเข่งเป็นเศษ ไม่เสนอต่ออีก เลขถัดไปพร้อม (SALE-13)
- [ ] แสดง "เข่ง 11 — (20 + 30) กก. = 50 กก."; ยอดของแต่ละจุดรวมเฉพาะส่วนของตัวเอง (SALE-11)
