# Story E04-S06: เข่งไม่เต็ม เข่งเชื่อม และ "จบเข่งแล้ว / เป็นเศษ"

Status: Draft

## Context

- Epic: `docs/epics/e04-sale-weighing.md`
- PRD: SALE-9, SALE-11, SALE-12, SALE-13, D-13
- ต่อจาก: S11 (`ShortBasketPanel`, `WeightInput`, event `short`) — เดิมเข่งขาดปิดในกองเดียว → ตอนนี้เปิดค้างและต่อข้ามจุดชั่งได้
- ขึ้นกับ: E04-S05, E03-S05 (คนกรีดของจุดชั่ง)

## คำอธิบาย

เข่งไม่เต็มเปิดค้างไว้ ต่อได้ที่จุดชั่งอื่นของคนกรีดคนเดิม (เป็นเข่งเชื่อม) หรือปิดเป็นเศษ

## Acceptance criteria

- [ ] พิมพ์ค่าที่ตาชั่งอ่าน → สุทธิ = ค่าที่อ่าน − tare; เก็บและแสดงทั้งสองค่า (SALE-9)
- [ ] เข่งไม่เต็มเปิดค้างเป็นค่าเริ่มต้น (SALE-11)
- [ ] ย้ายไปจุดของคนกรีดคนเดิม → ถาม "เติมเข่ง N ต่อ" หรือ "เริ่มเข่งใหม่" (เข่งเดิมปิดเป็นเศษ) (SALE-11)
- [ ] ย้ายไปจุดของคนกรีดคนอื่น → เข่งเดิมปิดเป็นเศษก่อนเสมอ ไม่ถาม (SALE-12)
- [ ] ปุ่ม "จบเข่งแล้ว / เป็นเศษ" ปิดเข่งเป็นเศษ ไม่เสนอต่ออีก เลขถัดไปพร้อม (SALE-13)
- [ ] แสดง "เข่ง 11 — (20 + 30) กก. = 50 กก."; ยอดของแต่ละจุดรวมเฉพาะส่วนของตัวเอง (SALE-11)
