## คำอธิบาย

การขายมีสามสถานะทางธุรกิจ Completed แล้วยังแก้ได้ตรง ๆ ขอเหตุผลสั้น ๆ เฉพาะเมื่อตัวเลขเงินเปลี่ยน

## Acceptance criteria

- [x] Draft → Completed หรือ Draft → Cancelled; Cancelled เก็บเข่งไว้แต่ไม่นับในยอดใด ๆ (SALE-20)
- [x] Completed แก้ได้โดยเจ้าของคนใดก็ได้ ไม่ต้อง "เปิดใหม่" (SALE-21, D-16)
- [x] การแก้ที่เปลี่ยนเงิน (ยอดคนกรีด ส่วนแบ่งเจ้าของ ยอดรวม) → ขอเหตุผลสั้น ๆ (เลือกหรือพิมพ์) และติดธงสถานะการจ่ายเงินที่กระทบให้ตรวจใหม่ (SALE-21)
- [x] การแก้ที่ไม่เปลี่ยนเงิน (เช่น หมายเหตุ) ไม่ถามเหตุผล
- [ ] ลบแบบกู้คืนได้ / กู้คืน การขายได้ ต่างจาก Cancelled (SYNC-10)
- [ ] เอาการปิด/เปิดกองและโซน และ `ReopenPrompt` ออก
