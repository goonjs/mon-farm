## Description

สำรวจทั้งแอป v2 (2026-11-15) แล้วพบ 4 จุดที่แตะเพื่อเลือกได้ แต่หน้าตาเหมือนช่องพิมพ์หรือข้อความธรรมดา สตอรี่นี้ทำให้ทั้ง 4 จุดดูออกว่าเป็นตัวเลือก ด้วยรูปแบบที่แอปใช้อยู่แล้ว: แถวทั้งแถวแตะได้ มีป้ายชื่อเล็ก ค่าตัวหนา และ › ท้ายแถว · ชิปและปุ่มแบ่งส่วน (segmented) ดูออกอยู่แล้ว ไม่แตะ

## Acceptance criteria

- [ ] **PK-1 หน้าบันทึกการคืน "ใครคืนให้ใคร"**: กล่อง ผู้คืน และ ผู้รับ เป็นแถวเลือกเต็มความกว้าง เรียงบนลงล่าง แต่ละแถวมีป้าย "ผู้คืน"/"ผู้รับ" ให้เห็น ชื่อตัวหนา และ › · หน้าตาไม่เหมือนช่องพิมพ์วันที่ข้างล่าง · ชื่อยาวขึ้นบรรทัดใหม่ ไม่ถูกตัดด้วย "…" · แตะแล้วเปิดชีตเลือกคนเหมือนเดิม
- [ ] **PK-2 หน้าใบซื้อ การ์ด "ร้านปุ๋ย" และ "วันที่ซื้อ"**: มี › ให้เห็นว่าแตะเปลี่ยนได้ ไม่มีอะไรถูกตัด
- [ ] **PK-3 หน้าเริ่มการขาย แถว "น้ำหนักยางสุทธิ" และ "ราคา"**: มี › เหมือนแถว "คนรับซื้อยาง"
- [ ] **PK-4 ฟอร์มจุดกรีด ช่อง "สวน" ตอนล็อก**: เป็นข้อความธรรมดา ไม่มีกรอบแบบช่องพิมพ์ (แตะไม่ได้ จึงไม่ควรดูเหมือนแตะได้)
- [ ] **PK-5 ทุกจุด**: แตะได้อย่างน้อย 48 · ไม่มีอะไรถูกตัดหรือเกินขอบที่ 320 และ 360 px ตัวอักษรขนาดกลางและใหญ่ · ไม่มีปุ่มคำสั้นในวงกลมขอบเส้น (กฎเจ้าของ 2026-11-06)
- [ ] **PK-6** `docs/ux/design-system.md` มีหัวข้อสั้น "ช่องเลือก": แถวเลือก = ป้ายเล็ก + ค่าตัวหนา + › · dropdown ▾ ใช้เมื่อรายการเปิดใต้ช่อง (เช่น หน่วยในใบซื้อ) · ช่องที่แตะไม่ได้ไม่มีกรอบแบบช่องพิมพ์
