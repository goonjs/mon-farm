## Description

ตอนย้ายไปจุดถัดไปของคนกรีดยางคนเดิมแล้วมีเข่งไม่เต็มค้าง หน้าถามและหน้านับเข่งบอกให้ชัดว่า ต้องเทยางเพิ่มเท่าไหร่ ตราชั่งต้องอ่านเท่าไหร่ และจะได้อะไร โดย logic เดิมไม่เปลี่ยน

## Acceptance criteria

กฎทั้งหน้า:
- [x] **FS-1** เลขตราชั่งทุกตัวมีไอคอนตราชั่งนำหน้า · น้ำหนักยางทุกตัวมีไอคอนใบไม้ + สีเน้น · คำ "ตราชั่งต้องอ่าน" เหมือนกันทั้งหน้าเติมเข่ง

- [x] **FS-3** เลือกก่อนแล้วกดยืนยัน (แตะแล้วยังไม่ไป) · เริ่มที่ "เติมให้เต็มเข่ง" · ทุกทางแสดงตราชั่งต้องอ่านทางขวา (52 / 17 / —)
- [x] **FS-4** ทางที่เลือกแสดงขั้นตอน: 1 เทยางเพิ่ม 15 กก. ลงเข่ง N ใบเดิม (เน้นสี) · 2 ตราชั่งต้องอ่าน 52 พร้อมสมการ (50 + เข่ง 2 + เบี้ยว) · ไม่มีขั้น "กดค้าง" ในแผ่น
- [x] **FS-5** ทาง 2 บอก "เข่งเปล่าใบใหม่ เติมยาง 15 กก." · ทาง 3 บอกเข่ง N ไม่เต็ม และเลขเข่งเต็มถัดไป (การปิดเข่งยังเป็นตาม E04-S17: ปิดเมื่อนับเข่งเต็มถัดไป)
- [x] **FS-6** ปุ่มยืนยันบอกสิ่งที่จะทำ + ตราชั่งต้องอ่าน (ทาง 3: "ปล่อยไว้ · ไปเข่ง N+1")

หน้านับเข่งหลังเลือกเติม:
- [x] **FS-7** แทนการ์ด "เติมเข่ง N" เดิม ด้วยแถบเข่ง + 3 ขั้น (เท/ชั่งยาง → อ่านตราชั่ง → กดค้าง) และกล่องตราชั่งต้องอ่านเลขใหญ่กับปุ่มกดค้าง อยู่ในจอเดียว
- [x] **FS-8** ทาง 2: แถบแสดง 35 สีเทา "อยู่ในเข่งที่ <จุดเดิม>" แยกจาก 15 "ชั่งตอนนี้" · ตราชั่งต้องอ่าน 17
- [x] **FS-9** บรรทัดล่างบอกผล "เข่ง N เต็ม 35 + 15 = 50 กก. · ต่อไปเข่ง N+1"
