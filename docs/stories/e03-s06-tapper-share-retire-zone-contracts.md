## คำอธิบาย

ส่วนแบ่ง เจ้าของ/คนกรีด ตั้งรายคนกรีดแบบมีช่วงเวลา ค่าเริ่มต้น 50/50 คิดจากมูลค่าขายรวม (gross)
และเอาสัญญาต่อโซนกับช่อง `basis` ที่ไม่ได้ใช้ออกจากโค้ด

## Acceptance criteria

- [ ] ตั้งส่วนแบ่งต่อคนกรีด มีวันที่มีผล; ไม่ได้ตั้ง = 50/50 (MD-8)
- [ ] เลือกส่วนแบ่งด้วยปุ่มสำเร็จรูป 50/50, 60/40, 70/30 หรือกำหนดเองเป็น % จำนวนเต็ม; ค่าเริ่มต้น 50/50 (MD-8)
- [ ] กำหนดเอง: **พิมพ์ฝั่งคนกรีด** (ตัวเลขที่ตกลงกับคนกรีด) รับเฉพาะ % จำนวนเต็ม 0–100; ฝั่งเจ้าของ = 100 − ค่าที่ใส่; ค่าไม่ใช่จำนวนเต็มหรือนอกช่วง → ข้อความไทยบอกเหตุ ไม่บันทึก (D-63)
- [ ] วันที่มีผล **ย้อนไปก่อนการขายที่ Completed ล่าสุดของคนกรีดนั้นไม่ได้** — ข้อความไทยบอกวันที่เร็วที่สุดที่ใช้ได้ (D-63)
- [ ] ฟังก์ชัน "ส่วนแบ่งของคนกรีด X ณ วันที่ Y" คืนค่าที่มีผลวันนั้น; เปลี่ยนส่วนแบ่งไม่กระทบการขายก่อนวันที่มีผล
- [ ] คิดจาก gross เสมอ; ไม่มีตัวเลือก `basis` ทั้งใน event, state และ UI (D-12)
- [ ] ลบ `zone_contract_set` / `zone_contract_cleared` / `Zone.contract` และ test ที่เกี่ยวข้อง; `delete-guard.ts` และเทสต์ D-44 ถูกเอาออกแล้วใน E06-S07 (ลบสวน/จุดได้เสมอ — D-58)
- [ ] หน้า setup ไม่มีการ์ด split และสัญญาต่อโซนอีก
- [ ] หน้าคนงาน (E03-S01) แสดงส่วนแบ่งปัจจุบันและประวัติ
- [ ] วันที่มีผลของส่วนแบ่ง **ต้องหลังวันของการขายที่ปิดแล้ว** (วันเดียวกันไม่ได้ — ต้องเคลียร์กับคนกรีดเก่ายุ่ง) เริ่มได้วันถัดไป (F17) (D-74)

- ส่วนแบ่งเป็นตัวเลขเงิน: แก้ซ้อนจากสองเครื่อง → Conflict เสมอ ห้าม last-write-wins (SYNC-4, D-30); ระหว่าง Conflict ปิดการขาย/สรุปเงินที่ได้รับผลไม่ได้ (D-29)
