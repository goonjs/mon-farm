## Description

ให้เจ้าของร่วมที่เปิดแอปครั้งแรก (และเจ้าของเองเมื่อลืม) ใช้งานหลักของแอปได้โดยไม่ต้องโทรถามเจ้าของ
รูปแบบ (ทัวร์ครั้งแรก / หน้าวิธีใช้ / ทั้งสอง), งานที่ครอบ, ข้อมูลที่ใช้ และสื่อ **ยังไม่ตัดสิน** — อยู่ในคำถามเจ้าของด้านล่าง
ไฟล์นี้เป็นร่าง: AC ด้านล่างแบ่งเป็นข้อที่ใช้ได้ทุกคำตอบ กับข้อที่รอคำตอบ

## Offline / sync behavior

- tutorial ทั้งหมดทำงานออฟไลน์ (TU-1) — คนใช้จะเปิดที่สวนซึ่งไม่มีเน็ต
- ไม่มีข้อมูลของ tutorial ใน event log หรือ outbox (TU-3) จึงไม่มี conflict และไม่มีผลกับ sync
- ค่า "ดูแล้ว / ข้ามแล้ว" เก็บตาม T-Q6: ถ้า ก = ค่าตั้งของเครื่อง ไม่ sync (ใช้ทางเดียวกับ E01-S19) · ถ้า ข = ต้องมีข้อมูลระดับผู้ใช้ที่ sync ซึ่งยังไม่มีใน architecture — ต้องเขียน architecture ก่อน
- ถ้า T-Q4 = ก (สวนตัวอย่าง): ข้อมูลตัวอย่างต้องอยู่นอก event log จริง — ยังไม่มีการออกแบบใน architecture ต้องเขียนเพิ่มและให้เจ้าของตกลงก่อน Ready

## คำถามเจ้าของ

ทุกข้อเป็นเรื่องที่ยังไม่มีใน PRD ★ = ทีมแนะนำ คำตอบจะบันทึกเป็น D-xx ใน PRD (ถัดไปคือ D-97)

**T-Q1 — tutorial เป็นแบบไหน** ❓

- ก. ทัวร์ครั้งแรก: เปิดเองครั้งเดียวหลังเข้ากลุ่ม ข้ามได้ ดูซ้ำไม่ได้
- ข. หน้า "วิธีใช้" ที่เปิดได้ตลอด (เช่น แถวใน "ไปที่" บนหน้าแรก) ไม่เปิดเองเลย
- ★ ค. ทั้งสอง: ครั้งแรกถามสั้น ๆ ว่า "ดูวิธีใช้ไหม" (ข้ามได้) และเปิดซ้ำได้จากหน้า "วิธีใช้" — เพราะไม่มี logout (D-23) ถ้าข้ามครั้งแรกไปแล้วจะไม่มีทางกลับมาดู

**T-Q2 — ถ้ามีการเปิดเอง เปิดเมื่อไร** ❓

- ก. ครั้งเดียวบนหน้าแรก หลังเข้ากลุ่มฟาร์มครั้งแรกบนเครื่องนั้น
- ★ ข. ตามจังหวะ: ครั้งแรกที่เข้าแต่ละงาน (เช่น ครั้งแรกที่เปิดหน้านับเข่ง) ขึ้นคำแนะนำสั้น ๆ ของงานนั้น — แบบเดียวกับคู่มือเติมเต็มที่มีแล้ว (E04-S21)
- ค. ไม่เปิดเอง (ถ้า T-Q1 = ข)

**T-Q3 — สอนงานไหนบ้าง (รอบแรก)** ❓

- ★ ก. การขายอย่างเดียว: เริ่มการขาย → นับเข่ง (กดค้าง, เข่งไม่เต็ม, ย้อนกลับ) → ปิดการขาย/จ่ายเงิน — เป็นงานที่ทำที่สวน มีคนรอ และพลาดแล้วแก้ยากสุด
- ข. การขาย + ตั้งค่าสวนครั้งแรก (สวน คนกรีด จุดชั่ง ด้วยตัวช่วยตั้งค่าจุดชั่ง)
- ค. ทุกงานบนหน้าแรก (การขาย เตรียมขาย ใส่ปุ๋ย ค่าใช้จ่าย หนี้ สต็อก)

**T-Q4 — สอนด้วยข้อมูลอะไร** ❓

- ★ ก. สวนตัวอย่าง: ฝึกนับเข่งในการขายสมมติที่ไม่บันทึกและไม่ sync — ลองกดค้างได้จริงโดยไม่ทำให้ข้อมูลฟาร์มเลอะ (ต้องเขียน architecture เพิ่มว่าข้อมูลตัวอย่างอยู่ที่ไหน)
- ข. หน้าจริงของฟาร์มจริง: tutorial ชี้ปุ่มบนหน้าจริง ผู้ใช้กดเองเป็นการบันทึกจริง
- ค. ไม่มีข้อมูล: ดูภาพ/อ่านอย่างเดียว ไม่มีการกด

**T-Q5 — สอนด้วยอะไร** ❓

- ★ ก. ข้อความสั้น + ภาพหน้าจอจริงของแอป (ทำจาก e2e เหมือนภาพใน `docs/ux/screenshots/`) — ตรงกับปุ่มที่เห็นจริง ขนาดเล็ก ใช้ออฟไลน์ได้
- ข. ข้อความสั้น + ภาพวาดแบบเดียวกับภาพปก/ไอคอน FarmMate
- ค. วิดีโอสั้น — เห็นการกดค้างชัดที่สุด แต่ไฟล์ใหญ่ ทำให้แอปหนัก และต้องทำใหม่ทุกครั้งที่หน้าจอเปลี่ยน

**T-Q6 — จำว่าดูแล้ว/ข้ามแล้วไว้ที่ไหน** ❓

- ★ ก. ในเครื่องนั้น (ค่าตั้งของเครื่อง ไม่ sync เหมือนขนาดตัวอักษร) — เครื่องใหม่จะถามอีกครั้ง ไม่ต้องเพิ่มข้อมูลที่ sync
- ข. ต่อผู้ใช้ sync ข้ามเครื่อง — ต้องเพิ่มข้อมูลระดับผู้ใช้ใน architecture ซึ่งยังไม่มี
- ค. ไม่จำ: ทุกครั้งที่เปิดแอปถามใหม่จนกว่าจะกด "ไม่ต้องถามอีก"
