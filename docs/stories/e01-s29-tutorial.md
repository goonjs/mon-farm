### ผู้ใช้ที่ต้องคิดถึง

- ผู้ที่จะเห็น tutorial มีแค่ **เจ้าของ น้อง และเพื่อน** (สิทธิ์เท่ากัน, PRD §2) — เจ้าของร่วม 2 คนจะเปิดแอปครั้งแรกบนเครื่องตัวเอง (หลัง E02-S03)
- เจ้าของและเบราว์เซอร์ทดสอบ 2–3 ตัวของ E01-S27 ใช้แอปอยู่แล้ว — ตอนที่ tutorial มาถึงในการอัปเดต จะถามคนกลุ่มนี้ด้วยไหม ดู T-Q7
- **อ.สมหวัง ไม่ใช้แอป** (ไม่ login) หลักการข้อ 8 แปลว่า tutorial ต้องไม่สร้างขั้นตอนใดที่ อ.สมหวัง ต้องทำหรือต้องเรียน (เช่น ให้ท่านดูหน้าจอ/ยืนยันอะไร)
- ไม่มี logout (D-23) → "เปิดครั้งแรก" เกิดครั้งเดียวต่อเครื่องต่อบัญชี ถ้าพลาดไปแล้วจะไม่มีโอกาสเห็นอีก นอกจากมีทางเปิดซ้ำ (T-Q1)

## Description

**เป้าหมายยังไม่ได้ตกลง — ที่มามีแค่ลำดับงาน (E01-S27)** ข้อเสนอของทีม (รอเจ้าของยืนยันพร้อม T-Q1): ให้เจ้าของร่วมที่เปิดแอปครั้งแรก
ใช้งานหลักของแอปได้โดยไม่ต้องถามเจ้าของ และเจ้าของเปิดดูซ้ำได้เมื่อลืม
รูปแบบ (ทัวร์ / หน้า "วิธีใช้" / ทั้งสอง), อะไรเปิดเอง, งานที่ครอบ, ข้อมูลที่ใช้ และสื่อ **ยังไม่ตัดสิน** — อยู่ในคำถามเจ้าของด้านล่าง
ไฟล์นี้เป็นร่าง: AC ด้านล่างแบ่งเป็นข้อที่ใช้ได้ทุกคำตอบ กับข้อที่รอคำตอบ

## Offline / sync behavior

- tutorial ทั้งหมดทำงานออฟไลน์ (TU-1) — คนใช้จะเปิดที่สวนซึ่งไม่มีเน็ต · Android: ไฟล์อยู่ในแอป · เว็บ: ต้องให้ service worker ของ PWA (E01-S23) เก็บรูปของ tutorial ด้วย
- tutorial เองไม่มีข้อมูลใน event log หรือ outbox (TU-3) จึงไม่มี conflict และไม่มีผลกับ sync
- ค่า "ตอบแล้ว" เก็บตาม T-Q6: ถ้า ก = ค่าใน "เครื่องนี้" ไม่ sync (ทางเดียวกับ E01-S19; เว็บล้างข้อมูลเว็บไซต์ = ค่าหาย) ·
  ถ้า ข = ต้องมีข้อมูลระดับผู้ใช้ที่ sync ซึ่งยังไม่มีใน architecture — ต้องเขียน architecture ก่อน
- ถ้า T-Q4 = ก (สวนตัวอย่าง): ข้อมูลตัวอย่างต้องอยู่นอก event log จริง — ยังไม่มีการออกแบบใน architecture ต้องเขียนเพิ่มและให้เจ้าของตกลงก่อน Ready

## คำถามเจ้าของ

ทุกข้อเป็นเรื่องที่ยังไม่มีใน PRD ★ = ทีมแนะนำ คำตอบจะบันทึกเป็น D-xx ใน PRD (ถัดไปคือ D-97)

**ถ้าเลือก ★ ทุกข้อ เจ้าของจะได้:** หน้า "วิธีใช้" หน้าเดียว เปิดได้จากหน้าแรกตลอด อธิบายการขายเป็นข้อความพร้อมภาพจากแอปจริง
ครั้งแรกที่เข้ากลุ่มฟาร์มบนเครื่องใหม่ หน้าแรกถามครั้งเดียวว่า "ดูวิธีใช้ไหม" (ไม่ถามระหว่างการขาย) เครื่องที่ใช้อยู่แล้วไม่ถาม

**T-Q1 — มีอะไรให้ดู** ❓

- ก. ทัวร์: ขั้นตอนทีละหน้า กดถัดไปจนจบ ดูได้ครั้งเดียว ไม่มีที่เปิดดูซ้ำ
- ★ ข. หน้า "วิธีใช้": หน้าเดียวที่เปิดได้ตลอดจากหน้าแรก มีหัวข้อให้แตะดูทีละเรื่อง — เพราะไม่มีปุ่มออกจากระบบ ถ้ามีแค่ทัวร์แล้วข้ามไป จะไม่มีทางกลับมาดู
- ค. ทั้งสอง: ทัวร์ทีละหน้า และหน้า "วิธีใช้" ที่เปิดทัวร์ซ้ำได้ — ทำมากกว่า ข โดยเนื้อหาเหมือนกัน

**T-Q2 — อะไรเปิดขึ้นมาเอง** ❓

- ก. ไม่มีอะไรเปิดเอง: ต้องรู้เองว่ามีหน้า "วิธีใช้"
- ★ ข. ถามครั้งเดียวบนหน้าแรก หลังเข้ากลุ่มฟาร์มครั้งแรกบนเครื่องนั้น: "ดูวิธีใช้ไหม" มีปุ่ม ดู / ไม่ดู (เข้ากลุ่มที่สองบนเครื่องเดิมไม่ถามอีก) —
  ขึ้นตอนว่าง ไม่ใช่ตอนคนรับซื้อยางรอ
- ค. คำแนะนำสั้น ๆ ครั้งแรกที่เปิดแต่ละงาน (เช่น ครั้งแรกที่เปิดหน้านับเข่ง) — ตรงจังหวะที่สุด แต่ครั้งแรกที่เปิดหน้านับเข่งคือตอนคนรับซื้อยางยืนรอ
  และแอปยังไม่มีแบบนี้เลย ต้องทำใหม่ทั้งหมด

**T-Q3 — สอนงานไหนบ้าง (รอบแรก)** ❓

- ★ ก. การขายอย่างเดียว: เริ่มการขาย → นับเข่ง (กดค้างนับเข่ง, เข่งไม่เต็ม, ย้อนกลับ) → ปิดการขาย/จ่ายเงิน — ทำที่สวน มีคนรอ และพลาดแล้วแก้ยากสุด
- ข. การขาย + ตั้งสวนครั้งแรก (สวน คนกรีดยาง จุดชั่ง ด้วย "ตัวช่วยตั้งค่าจุดชั่ง")
- ค. ทุกอย่างบนหน้าแรก: 3 ปุ่ม (เตรียมขาย · เริ่มการขาย · บันทึกค่าใช้จ่าย) + ทุกช่องใน "ไปที่" (รายงานการขายย้อนหลัง · พยากรณ์อากาศ ·
  รายการที่ต้องจ่าย · การดูแลสวน · ค่าใช้จ่ายทั้งหมด · ซื้อของร้าน · รายการ stock · ข้อมูลคนงาน) — ใหญ่ที่สุด ต้องแก้ทุกครั้งที่หน้าเหล่านี้เปลี่ยน

**T-Q4 — สอนด้วยข้อมูลอะไร** ❓

- ก. สวนตัวอย่าง: ลองกดค้างนับเข่งในการขายสมมติที่ไม่บันทึก ไม่ส่งไปเครื่องอื่น — ได้ลองมือจริง แต่ต้องออกแบบเพิ่มก่อน ใช้เวลานานขึ้น
- ข. หน้าจริงของฟาร์มจริง: tutorial ชี้ปุ่มบนหน้าจริง ผู้ใช้กดเองเป็นการบันทึกจริง (ส่งไปเครื่องอื่นด้วย)
- ★ ค. ดูและอ่านอย่างเดียว ไม่มีการกด — ไม่มีทางทำข้อมูลจริงของกลุ่มฟาร์มผิด ทำได้เร็วที่สุด (ถ้าอยากให้ลองมือ ค่อยเพิ่ม ก ภายหลัง)

**T-Q5 — สอนด้วยอะไร** ❓

- ★ ก. ข้อความ + ภาพจากแอปจริง: ข้อความใหญ่ตามขนาดตัวอักษรที่ตั้งไว้ ภาพช่วยให้เห็นว่าปุ่มอยู่ตรงไหน — แต่ตัวหนังสือในภาพไม่ขยายตาม
  ไม่เปลี่ยนตามโหมดมืด อ่านยากบนจอเล็ก และต้องถ่ายใหม่ทุกครั้งที่หน้าจอเปลี่ยน
- ข. ข้อความ + ภาพวาดแบบภาพปก/ไอคอน FarmMate — สวยและเข้ากับแอป แต่ไม่ตรงกับหน้าจริงทุกจุด ต้องวาดใหม่เมื่อหน้าเปลี่ยนมาก
- ค. ข้อความ + ไฮไลต์ปุ่มบนหน้าจริง (ไม่ใช้รูป) — ขยายตามขนาดตัวอักษรและโหมดมืดเอง ไม่ต้องถ่ายภาพใหม่ แต่ต้องพาไปหน้าจริง (คู่กับ T-Q4 ข)
- ง. วิดีโอสั้น — เห็นการกดค้างชัดที่สุด แต่ไฟล์ใหญ่ แอปหนักขึ้น และต้องถ่ายใหม่ทุกครั้งที่หน้าจอเปลี่ยน

**T-Q6 — จำไว้ที่ไหนว่าตอบ "ดูวิธีใช้ไหม" แล้ว** ❓

- ★ ก. ในเครื่องนั้น (เก็บใน "เครื่องนี้" ไม่ส่งไปเครื่องอื่น เหมือนขนาดตัวอักษร) — โทรศัพท์หรือเบราว์เซอร์ใหม่จะถามอีกครั้งเดียว
  บนเว็บ ถ้าล้างข้อมูลเว็บไซต์จะถามอีก
- ข. ตามตัวคน ใช้ได้ทุกเครื่อง — ต้องออกแบบเพิ่มก่อน ใช้เวลานานขึ้น
- ค. ไม่ต้องจำ — ใช้ได้เฉพาะถ้า T-Q2 = ก (ไม่มีอะไรเปิดเอง)

**T-Q7 — คนที่ใช้แอปอยู่แล้วให้ถามด้วยไหม** ❓
(โทรศัพท์/เบราว์เซอร์ที่ login แล้วตอนที่ tutorial มาถึงในการอัปเดต — เช่น เครื่องของเจ้าของ และเบราว์เซอร์ทดสอบ 2–3 ตัว)

- ก. ถาม: เปิดแอปครั้งถัดไปหลังอัปเดต ถาม "ดูวิธีใช้ไหม" ครั้งเดียว (ถ้า T-Q6 = ก จะถามทุกเครื่อง/เบราว์เซอร์ที่ใช้อยู่)
- ★ ข. ไม่ถาม: คนที่ใช้อยู่แล้วรู้จักแอป ถ้าอยากดูเปิดจากหน้า "วิธีใช้" เอง
- ค. ไม่ถาม แต่แสดงจุดเล็ก ๆ ที่ทางเข้า "วิธีใช้" จนกว่าจะเปิดดูครั้งแรก
