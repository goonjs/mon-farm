# Story E12-S02: เก็บอากาศจริงรายวันต่อสวน

Status: Draft

## Context

- Epic: `docs/epics/e12-weather.md`
- PRD: WX-3, WX-4, NFR-6
- ขึ้นกับ: E12-S01, E01 (sync ลงเครื่อง)

## คำอธิบาย

งานตามเวลาฝั่ง server ดึงอากาศจริงของเมื่อวานต่อสวน เก็บในฐานข้อมูลของแอปเอง
แยกจากพยากรณ์ เพื่อใช้วิเคราะห์ภายหลัง

## Acceptance criteria

- [ ] วันละครั้ง เก็บค่าจริงต่อสวน: ปริมาณฝน, อุณหภูมิ, ความชื้น, ลม (WX-4)
- [ ] คำนวณจากค่าที่เก็บ: ฝนสะสม, จำนวนวันฝนตก, ฝนหนัก/พายุ, ช่วงแล้ง (WX-4)
- [ ] ข้อมูลจริงเก็บแยกจากพยากรณ์ ไม่ปนกันเด็ดขาด และติดแหล่งที่มา (ผู้ให้บริการ, เวลาดึง) (WX-3, SYNC-11)
- [ ] วันที่ดึงไม่สำเร็จ แสดงเป็น "ไม่มีข้อมูล" และลองใหม่รอบถัดไป ไม่เดาค่า (SYNC-12)
- [ ] เก็บเท่าที่สัญญาผู้ให้บริการอนุญาต (WX-3)

## Offline / sync

- เครื่องดึงข้อมูลอากาศจริงลงมาเก็บตอน sync → ดูประวัติอากาศได้ออฟไลน์
- ข้อมูลอากาศเขียนโดย server เท่านั้น เครื่องอ่านอย่างเดียว

## Test plan

- [ ] Unit: คำนวณฝนสะสม/วันฝนตก/ช่วงแล้ง จากชุดข้อมูลตัวอย่าง
- [ ] Integration: งานตามเวลาใน emulator + fake provider เขียนข้อมูลวันเดียวครั้งเดียว (รันซ้ำไม่ซ้ำ)
- [ ] Unit: provider ล้มเหลว → "ไม่มีข้อมูล" ไม่ใช่ 0

## คำถามเจ้าของ

- ต้องการข้อมูลย้อนหลังกี่ปีตอนเริ่มใช้ (เช่น ตั้งแต่ปลูก / 3 ปี / ไม่ต้อง)? ขึ้นกับผู้ให้บริการที่เลือก
- ดึงด้วยงานตามเวลาฝั่ง server (ได้ข้อมูลครบแม้ไม่มีใครเปิดแอป, ใช้ Cloud Functions บน Blaze) ★ หรือดึงตอนมีคนเปิดแอป?
