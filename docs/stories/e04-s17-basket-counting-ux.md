## คำอธิบาย

1. **ตัวเลือก 3 ของชีต "เข่ง N ยังไม่เต็ม"** (ปล่อยเข่งไม่เต็มไว้ แล้วนับเข่งเต็มถัดไป) ตอนนี้ปิดเข่งทันทีที่กด จึงกลับมาเลือกใหม่ไม่ได้ ต่างจากตัวเลือก 1 และ 2 → ทำให้เหมือนกัน: เลือก 3 ยังไม่ปิดเข่ง แค่พาไปนับเข่งเต็มถัดไป เข่งไม่เต็มถูกปิดตอนนับเข่งเต็มแรกสำเร็จ; ถ้าย้อนกลับมาที่ชีตก่อนนับ ยังเลือก 1/2/3 ได้ครบ
2. **ลบปุ่ม "จบเข่งนี้"** (การ์ดเข่งรอเติม) — การเลือกทำที่ขั้นถัดไป (ชีตเลือก 1/2/3) เท่านั้น
3. **การ์ดเข่งปัจจุบัน**: เลข **นับแล้ว** เป็นตัวใหญ่ และ **เข่งถัดไป N** เป็นตัวเล็ก (สลับกับเดิม)
4. **ปุ่มกดค้าง**: ข้อความ "กดค้างเพื่อนับเข่งเต็ม" ตามด้วยเลขเข่ง
5. **ตั้งค่า**: เพิ่มตัวเลือก "วิธีนับเข่ง" = กดค้าง / แตะ (ของเครื่อง ไม่ซิงก์ เหมือนเวลากดค้าง); โหมดแตะ นับเมื่อแตะครั้งเดียว ซ่อนช่องตั้งเวลากดค้าง; ปุ่มย้อนกลับยังต้องกดค้างเสมอ (E04-S15)

**ตัดสินใจของเจ้าของ 2026-10-17 (เข่งไม่เต็มที่จุดเดิม ไม่มีชีตเลือก):** ไม่มีปุ่มจบเข่ง และไม่ให้เติมเข่งที่จุดเดิม — กดค้างที่จุดเดิม = นับเข่งเต็มใหม่ (ปิดเข่งไม่เต็มให้เอง เลข N+1) การ์ดแสดงข้อความบอกชัดว่ากดค้างทำอะไร ถ้าต้องการเติมเข่งไม่เต็มให้ **ย้อนกลับเข่งไม่เต็มก่อน แล้วนับเต็ม แล้วค่อยบันทึกเข่งไม่เต็มใหม่** (ใช้กับโหมดสาธารณะด้วย)

## Acceptance criteria

- [x] เข่งไม่เต็มเปิดอยู่ที่จุดนี้: ปุ่มกดค้างใช้ได้; นับแล้วได้เข่งเต็มเลข N+1 (ไม่มี event ปิดแยก: เข่งใหม่ปิดเข่งไม่เต็มเอง จึงย้อนกลับเข่งใหม่แล้วเข่งไม่เต็มกลับมาเปิด); การ์ดมี `open-hint` บอกว่ากดค้างทำอะไรและวิธีเติม (ย้อนกลับก่อน); โหมดสาธารณะทำเหมือนกัน

- [x] เลือกตัวเลือก 3 แล้วเปิดหน้านับ: ยังไม่มี event `basket_closed`; เลขเข่งถัดไป = เลขเข่งไม่เต็ม + 1
- [x] นับเข่งเต็มแรกหลังเลือก 3: เขียนเข่งเต็มเลข N+1 (เข่งไม่เต็มถูกปิดโดยเข่งใหม่ ไม่มี event ปิดแยก); เข่งไม่เต็มไม่ถูกเติม
- [x] ย้อนกลับไปหน้าเลือกจุดแล้วเลือกจุดเดิมอีกครั้ง (หลังเลือก 3 ก่อนนับ) ชีต 1/2/3 ขึ้นอีก และเลือก 1 หรือ 2 ได้
- [x] ไม่มีปุ่ม `close-open` บนการ์ดเข่งรอเติม; ข้อความคำแนะนำไม่อ้างปุ่มที่หายไป
- [x] การ์ดเข่งปัจจุบัน: เลข `current-done` (นับแล้ว) ใหญ่ ป้าย "นับแล้ว"; `current-no` ตัวเล็ก "เข่งถัดไป N"
- [x] ปุ่มนับ: label "กดค้างเพื่อนับเข่งเต็ม N" (ทั้งหน้านับและโหมดสาธารณะ); โหมดแตะ "แตะเพื่อนับเข่งเต็ม N"
- [x] ตั้งค่าเครื่อง (`/v2/device`) และตั้งค่าการขาย มีตัวเลือก กดค้าง/แตะ; ค่าเริ่มต้น กดค้าง; เก็บในเครื่อง (localStorage) ไม่ซิงก์
- [x] โหมดแตะ: แตะครั้งเดียวนับ 1 เข่ง; ไม่นับซ้ำจากการกดค้าง; ปุ่มย้อนกลับยังต้องกดค้าง
- [x] โหมดกดค้าง: พฤติกรรมเดิมทุกอย่าง (ปล่อยก่อนเวลา = ไม่นับ)
