## คำอธิบาย

1. **ตัวเลือก 3 ของชีต "เข่ง N ยังไม่เต็ม"** (ปล่อยเข่งไม่เต็มไว้ แล้วนับเข่งเต็มถัดไป) ตอนนี้ปิดเข่งทันทีที่กด จึงกลับมาเลือกใหม่ไม่ได้ ต่างจากตัวเลือก 1 และ 2 → ทำให้เหมือนกัน: เลือก 3 ยังไม่ปิดเข่ง แค่พาไปนับเข่งเต็มถัดไป เข่งไม่เต็มถูกปิดตอนนับเข่งเต็มแรกสำเร็จ; ถ้าย้อนกลับมาที่ชีตก่อนนับ ยังเลือก 1/2/3 ได้ครบ
2. **ลบปุ่ม "จบเข่งนี้"** (การ์ดเข่งรอเติม) — การเลือกทำที่ขั้นถัดไป (ชีตเลือก 1/2/3) เท่านั้น
3. **การ์ดเข่งปัจจุบัน**: เลข **นับแล้ว** เป็นตัวใหญ่ และ **เข่งถัดไป N** เป็นตัวเล็ก (สลับกับเดิม)
4. **ปุ่มกดค้าง**: ข้อความ "กดค้างเพื่อนับเข่งเต็ม" ตามด้วยเลขเข่ง
5. **ตั้งค่า**: เพิ่มตัวเลือก "วิธีนับเข่ง" = กดค้าง / แตะ (ของเครื่อง ไม่ซิงก์ เหมือนเวลากดค้าง); โหมดแตะ นับเมื่อแตะครั้งเดียว ซ่อนช่องตั้งเวลากดค้าง; ปุ่มย้อนกลับยังต้องกดค้างเสมอ (E04-S15)

**ตัดสินใจของเจ้าของ 2026-10-17 (เข่งไม่เต็มเปิดอยู่ที่จุดนี้):** เข่งไม่เต็มเปิดอยู่ = **จุดนี้จบแล้ว** ไม่มีการกดค้างที่จุดนี้เลย ทั้งเติมเข่งนั้นและนับเข่งถัดไป (ตัวอย่าง: นับเต็ม 13 เข่ง แล้วบันทึกเข่งที่ 14 ไม่เต็ม 22 กก. จุดนี้จบ) ถ้าเจอยางเพิ่ม ทำได้อย่างเดียวคือ **ย้อนกลับ** แล้วบันทึกเป็นเข่งเต็ม (กดค้างใหม่) หรือเข่งไม่เต็มด้วยน้ำหนักใหม่ (เช่น 30 กก.) UI ส่วนนี้เหมือนเดิม (การ์ด "เข่ง N รอเติม" แทนพื้นที่กดค้าง) **ตัดเฉพาะปุ่ม "จบเข่งนี้"** ไม่มี ADR เพราะเป็นการเปลี่ยน UI ไม่ใช่สถาปัตยกรรม (บันทึกไว้ในสตอรี่นี้)

**คอมเมนต์เจ้าของบน mockup 2026-10-18 (อนุมัติแล้ว) — หน้านับเมื่อมีเข่งไม่เต็มเปิดอยู่ที่จุดนี้:**
1. การ์ดใหญ่: เลข "นับแล้ว" คงเดิม; บรรทัดเล็กใต้เลขเปลี่ยนจาก "เข่งถัดไป N" เป็น **+xx กก.** (น้ำหนักยางของเข่งไม่เต็ม เช่น +22 กก. — เจ้าของยืนยัน) และเน้นสีเตือนให้เห็นชัด
2. การ์ดเข่งที่เปิดอยู่: บรรทัดเดียวอ่านง่าย เป็น **แถบน้ำหนัก** แสดงยางที่มีกี่ % ของน้ำหนักเต็มเข่ง (เช่น 22 จาก 50 กก. = 44%) ความสูงพอดี สีจาก design system; "ตาชั่งอ่านเท่าไหร่" กำกับเล็กๆ ไม่รก
3. พื้นที่ "เข่ง N รอเติม" + ข้อความคำใบ้ **ตัดออก** แทนด้วย **ปุ่มสี่เหลี่ยม (ActionTile) อยู่กลาง** "ไปจุดถัดไป" พร้อมไอคอน ไม่มีคำอธิบายอื่น (ผู้ใช้กดย้อนกลับเองเมื่อรู้ว่าเติมไม่ได้)
> **แก้โดย E04-S18 (เจ้าของ 2026-10-18):** ข้อ 3 ปุ่ม "ไปจุดถัดไป" (`next-point`) **ถูกลบ** เพราะมีปุ่ม "เปลี่ยนจุด" ด้านบนอยู่แล้ว; ข้อ 4 ปุ่มตรวจยอดเปลี่ยนเป็นปุ่มเต็มความกว้าง (ดู S18)

4. ถ้านี่คือจุดชั่งสุดท้าย (จุดอื่นที่มองเห็นทั้งหมดชั่งแล้ว) เพิ่มปุ่มสี่เหลี่ยมอีกอัน **เด่นกว่า** (`main`) ใช้คำเดียวกับเมนู ("ชั่งครบแล้ว → ตรวจยอด" เจ้าของยืนยัน 2026-10-18) ไปหน้าตรวจยอดเดียวกัน

- [x] นับเข่งเต็มแรกหลังเลือก 3: เขียนเข่งเต็มเลข N+1 (เข่งไม่เต็มถูกปิดโดยเข่งใหม่ ไม่มี event ปิดแยก); เข่งไม่เต็มไม่ถูกเติม
- [x] ย้อนกลับไปหน้าเลือกจุดแล้วเลือกจุดเดิมอีกครั้ง (หลังเลือก 3 ก่อนนับ) ชีต 1/2/3 ขึ้นอีก และเลือก 1 หรือ 2 ได้
- [x] ไม่มีปุ่ม `close-open` บนการ์ดเข่งรอเติม; ข้อความคำแนะนำไม่อ้างปุ่มที่หายไป
