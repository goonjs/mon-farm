## คำอธิบาย

1. **ข้อ 11 การ์ดเล็กไม่กระโดด** — เฉพาะ "การ์ดเล็ก" แถวตัวเลข (เงิน/จำนวนเข่ง · กก. · ขาด) บน **หน้านับเข่ง** (เจ้าของยืนยัน 2026-10-17: ไม่แตะหน้าเลือกจุด/รายการ) ความสูงคงที่ ตัวเลขยาวหดฟอนต์ให้พอดี 1 บรรทัด ไม่ดันเนื้อหาข้างล่าง การ์ดขาด (มีเข่งไม่เต็ม) สูงเท่าการ์ดอื่น
2. **ข้อ 12 เมนู ⋮ แบ่งกลุ่ม สี ไอคอน** (ตามร่างที่เจ้าของเห็น): ปิดการขาย (เขียว ใหญ่สุด: "ชั่งครบแล้ว → ตรวจยอด") · บันทึก (บันทึกย้อนหลัง, โหมดสาธารณะ) · ราคาและข้อมูล (ปรับราคารับซื้อ แสดงราคาปัจจุบัน, ข้อมูลการขาย) · ไปที่ (หน้าแรก, บัญชีหนี้, การขายทั้งหมด) · เส้นกั้น + "ลบการขายนี้" สีแดงล่างสุด (ยังมีหน้ายืนยันเดิม) ทุกแถวสูง ≥ 48 px มีข้อความกำกับ ใช้ร่วมกับเมนูหน้าเลือกจุด (กลุ่มที่ไม่เกี่ยวไม่แสดง)
3. **ข้อ 14 ไปหน้าแรก/หนี้ได้ง่าย** (เจ้าของเลือก "ทั้งสองแบบ" 2026-10-18): (ก) ปุ่มไอคอนบ้านบนแถบบนของหน้านับ ไปหน้าแรก (ข) ในเมนู กลุ่ม "ไปที่" เพิ่ม **หน้าแรก 1 แถว และ บัญชีหนี้ 1 แถว แยกกัน** (ไม่รวมกัน)

## Acceptance criteria

- [x] การ์ดเล็ก 3 ใบ (`card-first`, `card-kg`, `card-short`) สูงเท่ากันเสมอ ไม่ว่ามีเข่งไม่เต็มหรือตัวเลขยาว; ตัวเลขใน `fig-*` ใช้ 1 บรรทัด หดพอดี
- [x] หน่วย (฿ / กก. / เข่ง) อยู่ในบรรทัดป้ายด้านบน (เจ้าของ 2026-10-18); ตัวเลขในการ์ดเป็นตัวเลขล้วน ลดขนาดตามความยาว (`figSize`) ไม่ตัดด้วย … (`adjustsFontSizeToFit` ไม่ทำงานบนเว็บ)
- [x] เมนูมีกลุ่มตามลำดับ: `menu-finish` (main) → `บันทึก` (`menu-backfill`, `menu-public`) → `ราคาและข้อมูล` (`menu-price`, `menu-info`) → `ไปที่` (`menu-home`, `menu-debts`, `menu-sales`) → `menu-delete` ล่างสุด
- [x] `menu-home` ไป `/v2`; `menu-debts` ไป `/v2/debts`; แยกเป็นสองแถว
- [x] ปุ่ม `counter-home` บนแถบบนหน้านับ ไป `/v2`
- [x] ทุกแถวเมนูมีไอคอนและป้ายข้อความ, `minHeight` ≥ target ขั้นต่ำ; `menu-delete` ยังเปิดหน้ายืนยันลบเหมือนเดิม
- [x] เมนูหน้าเลือกจุด (`pick-menu-sheet`) ใช้แถวแบบเดียวกัน (ราคา/ข้อมูล/ไปที่/ลบ) ไม่มีกลุ่มปิดการขาย/บันทึกถ้าไม่ใช่หน้านับ
