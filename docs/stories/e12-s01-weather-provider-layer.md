# Story E12-S01: พิกัดสวนและชั้นผู้ให้บริการอากาศ

Status: Draft

## Context

- Epic: `docs/epics/e12-weather.md`
- PRD: WX-1, WX-2, INT-4, NFR-5, NFR-6
- ขึ้นกับ: E03 (สวน + GPS ไม่บังคับ), E01 (Firebase dev/prod, server endpoint)
- ใช้ป้ายจาก E01-S15 (สถานะข้อมูลรายฟิลด์ SYNC-12)

## คำอธิบาย

เจ้าของใส่พิกัดของแต่ละสวน และสร้างชั้นกลาง (provider abstraction) ฝั่ง server
ที่แยกผู้ให้บริการ "ข้อมูลย้อนหลัง" กับ "พยากรณ์" เปลี่ยนแยกกันได้

## Acceptance criteria

- [ ] ใส่พิกัดต่อสวนได้ (พิมพ์ หรือใช้ GPS ตอนอยู่ที่สวน); ยังไม่ใส่ = "ไม่ทราบ" และไม่ดึงอากาศ (WX-1)
- [ ] interface ผู้ให้บริการ 2 ชนิด: ย้อนหลัง/อากาศจริง และ พยากรณ์ ตั้งค่าแยกกันได้ (WX-2)
- [ ] key ของผู้ให้บริการอยู่ฝั่ง server เท่านั้น ไม่อยู่ในแอป (NFR-5)
- [ ] มี provider ปลอม (fake) สำหรับ dev/CI ไม่เรียก API จริง (NFR-6)
- [ ] ไม่ถือว่า Windy Premium ให้สิทธิ์ API (WX-2, INT-4)

## Offline / sync

- ใส่พิกัดได้ออฟไลน์ (เป็นข้อมูลหลัก sync ตามปกติ); การเรียกผู้ให้บริการทำเฉพาะตอนออนไลน์ฝั่ง server

## Test plan

- [ ] Unit: contract test ของ interface กับ fake provider
- [ ] Unit: สวนไม่มีพิกัด → ไม่เรียก provider
- [ ] Security: ตรวจ bundle แอปไม่มี key ของผู้ให้บริการ

## คำถามเจ้าของ

- เลือกผู้ให้บริการ (ย้อนหลัง + พยากรณ์) และตรวจสิทธิ์การเก็บข้อมูล/ค่าใช้จ่าย — ต้องตัดสินก่อน E12-S02
- พิกัดของสวนจันทเขลม, สวนฝั่งคลองพลู, ทุเรียน คลองพลู, ตะเคียนทอง (ตอนนี้ไม่ทราบ)
