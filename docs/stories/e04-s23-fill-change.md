## คำอธิบาย

บนหน้านับตอนเติมเข่ง (ก่อนกดค้างครั้งแรก) การ์ดคำแนะนำมีแถว "เปลี่ยนวิธีเติม ›" แตะแล้วแผ่น 3 วิธีเดิมเปิดขึ้น
วิธีที่ใช้อยู่มีป้าย "✓ ใช้อยู่ตอนนี้" เลือกวิธีอื่นแล้วกลับหน้านับด้วยวิธีใหม่. ไม่มีอะไรบันทึกจนกว่าจะกดค้าง (เหมือนตอนนี้)

## Acceptance criteria (ร่าง — รอเจ้าของ)

- [ ] **FX-1** หน้านับในโหมดเติม (`?fill=full|part`) ก่อนกดค้างครั้งแรก: การ์ดคำแนะนำมีแถว "เปลี่ยนวิธีเติม ›" ทั้งแถวแตะได้ เป้ากด ≥ 48 (ไม่ใช่ปุ่มกลม)
- [ ] **FX-2** แตะแถวนี้ เปิดแผ่น 3 วิธีของเข่งเดิม วิธีที่ใช้อยู่มี "✓ ใช้อยู่ตอนนี้" และถูกเลือกไว้ก่อน; ปุ่มล่างบอกวิธีและตาชั่งต้องอ่าน
- [ ] **FX-3** เลือกวิธีอื่นแล้วกดปุ่ม: หน้านับเปลี่ยนเป็นวิธีใหม่ (ชั่งแยก → ตาชั่งต้องอ่าน 17; ปล่อยไว้ → หน้านับปกติ เข่งถัดไป 3) โดยไม่ต้องผ่านหน้าเลือกจุดหรือหน้าก่อนชั่งซ้ำ; ไม่มี event ใหม่จนกว่าจะกดค้าง
- [ ] **FX-4** หลังกดค้างครั้งแรก แถวหายไป; "ย้อนกลับ" (กดค้าง) ยังยกเลิกส่วนที่เติมได้เหมือนเดิม แล้วแถวกลับมา
- [ ] **FX-5** แผ่น 3 วิธี: หัวแผ่น "เข่ง N ยังไม่เต็ม — เลือก 1 ใน 3 วิธี" และเลข 1 2 3 หน้าแต่ละวิธี (Q2)
- [ ] **FX-6** หัวการ์ดคำแนะนำบอกวิธีที่เลือก "วิธีที่ 1 · เติมให้เต็มเข่ง 2" (Q3)
- [ ] **FX-7** ไม่มีอะไรถูกตัด ที่ 320/360/390 ตัวอักษรกลางและใหญ่; กดค้างยังอยู่ในจอเต็ม (E04-S21)
- [ ] **FX-8** ใช้ได้ offline

## คำถามถึงเจ้าของ

- **Q1** แถว "เปลี่ยนวิธีเติม ›" ท้ายการ์ดคำแนะนำ (แนะนำ) โอเคไหม?
- **Q2** หัวแผ่น "เลือก 1 ใน 3 วิธี" และเลข 1 2 3 หน้าวิธี ช่วยให้เห็นว่ามี 3 ทางไหม?
- **Q3** หัวการ์ดหน้านับ "วิธีที่ 1 · …" (แนะนำ) หรือคงหัวเดิม?

## Offline / sync behavior

ไม่มี event ใหม่ วิธีเติมยังอยู่ใน URL (`?fill=`) จนกว่าจะกดค้าง เหมือนตอนนี้. ใช้ได้ offline
