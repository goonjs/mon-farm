# Story E10-S01: รายการสต็อกและเกณฑ์ใกล้หมด

Status: Draft

## Context

- Epic: `docs/epics/e10-inventory.md`
- PRD: INV-1, INV-3
- ขึ้นกับ: E01 (event log + sync), E02 (กลุ่มฟาร์ม)

## คำอธิบาย

ตั้งรายการสต็อกของเจ้าของ เริ่มที่น้ำมันตัดหญ้าและยาฆ่าหญ้า เพิ่มรายการ/หมวดได้
แต่ละรายการมีหน่วยและเกณฑ์ใกล้หมดที่เจ้าของตั้งเอง

## Acceptance criteria

- [ ] มีรายการเริ่มต้น น้ำมันตัดหญ้า และ ยาฆ่าหญ้า; เพิ่ม/แก้/เลิกใช้รายการได้ (INV-1)
- [ ] รายการมี: ชื่อ, หมวด (เพิ่มได้), หน่วย, เกณฑ์ใกล้หมด (ไม่บังคับ) (INV-1, INV-3)
- [ ] ไม่มีรายการวัสดุกรีดที่คนงานจ่ายเอง (กรด/น้ำ) เป็นค่าเริ่มต้น (INV-1)
- [ ] รายการที่ไม่ตั้งเกณฑ์ ไม่ขึ้นธงใกล้หมด

## Offline / sync

- สร้าง/แก้รายการได้ออฟไลน์ → sync อัตโนมัติ; แก้รายการเดียวกันซ้อนกัน → Conflict

## Test plan

- [ ] Unit: projection รายการ + หมวด + เลิกใช้
- [ ] Offline: เพิ่มรายการตอนออฟไลน์ ปิด-เปิดแอป ยังอยู่ และขึ้น Pending Sync

## คำถามเจ้าของ

- หน่วยของน้ำมันตัดหญ้าและยาฆ่าหญ้าที่ใช้จริง (ลิตร / แกลลอน / ขวด)? ถ้ายังไม่ทราบ ให้เจ้าของเลือกตอนตั้งรายการ
