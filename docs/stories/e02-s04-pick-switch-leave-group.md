# Story E02-S04: เลือก/สลับกลุ่มฟาร์ม + ออกจากกลุ่ม

Status: Draft

- ขึ้นกับ: E02-S03

## คำอธิบาย

ผู้ใช้ที่อยู่หลายกลุ่มเลือกกลุ่มตอนเปิดแอปและสลับได้; สมาชิกออกจากกลุ่มได้ โดยกลุ่มและข้อมูลยังอยู่กับสมาชิกคนอื่น
ออกแล้วเครื่องลบสำเนาข้อมูลของกลุ่มนั้น (หลังส่ง outbox ครบ); สมาชิกคนสุดท้ายออกไม่ได้

## Acceptance criteria

- [ ] อยู่ ≥ 2 กลุ่ม → เปิดแอปแล้วขึ้นหน้าเลือกกลุ่ม (ACC-3)
- [ ] สลับกลุ่มได้จากหน้าตั้งค่า; หน้าจอแสดงเฉพาะข้อมูลของกลุ่มที่เลือก ไม่ปนกัน (ACC-5)
- [ ] ออกจากกลุ่ม (ยืนยัน 1 ครั้ง) → สมาชิกภาพถูกเอาออก; กลุ่มและข้อมูลยังอยู่ (ACC-2)
- [ ] หน้ายืนยันเตือนชัดเจนว่าข้อมูลที่ยังไม่ได้ส่งจากเครื่องอื่นของผู้ใช้ในกลุ่มนี้จะหาย (D-33)
- [ ] เครื่องอื่นของผู้ใช้เดียวกันที่รู้ว่าไม่เป็นสมาชิกแล้ว → แจ้งภาษาไทย แล้วลบสำเนากลุ่มนั้นรวมรายการค้างส่ง (D-33)
- [ ] ack หาย / แอปถูก kill หลังออกสำเร็จ → ลองใหม่แล้วรู้ว่าออกไปแล้ว (อ่าน doc สมาชิกของตัวเองจากเซิร์ฟเวอร์) และลบสำเนา ไม่กลับเป็นกลุ่มที่บันทึกได้ (architecture §การดำเนินการด้านสมาชิกภาพ)
- [ ] สมาชิกคนสุดท้ายออกไม่ได้ — ปุ่มออกปิดไว้ พร้อมข้อความไทยบอกเหตุ (กันกลุ่มไม่มีเจ้าของ; MVP ไม่มีการลบกลุ่ม) (ACC-2, D-26)
- [ ] หลังส่ง outbox ของกลุ่มนั้นครบ → ลบสำเนาข้อมูลกลุ่มนั้นออกจากเครื่อง; กลุ่มอื่นในเครื่องไม่ถูกแตะ (ACC-5, D-26)
- [ ] หลังออก ผู้ใช้อ่าน/เขียนกลุ่มนั้นที่เซิร์ฟเวอร์ไม่ได้ (rules) (ACC-5, NFR-5)
- [ ] ไม่มีปุ่มลบกลุ่มฟาร์ม (ACC-2)

## Offline / sync behavior

- เลือก/สลับกลุ่มทำออฟไลน์ได้จากรายการสมาชิกที่เก็บในเครื่อง
- ออกจากกลุ่มขณะออฟไลน์: ส่งเมื่อมีเน็ต; event ที่ค้างใน outbox ของกลุ่มนั้นต้องส่งก่อนการออก
- ลบสำเนาในเครื่องเฉพาะเมื่อ outbox ของกลุ่มนั้นว่างแล้วเท่านั้น — ยังส่งไม่ครบ ห้ามลบ (ข้อมูลต้องไม่หาย, NFR-2)
- เช็ก "สมาชิกคนสุดท้าย" ต้องบังคับที่ rules ด้วย ไม่ใช่แค่ใน UI (สองคนกดออกพร้อมกันขณะออฟไลน์ → อย่างน้อย 1 คนต้องถูกปฏิเสธ)

## Test plan

- [ ] Vitest: ตัดสินการเข้า (2 กลุ่ม → หน้าเลือก), กรองข้อมูลตามกลุ่ม; ลบสำเนาในเครื่องเฉพาะเมื่อ outbox ของกลุ่มนั้นว่าง
- [ ] rules test: หลังออกอ่าน/เขียนไม่ได้; สมาชิกคนอื่นยังใช้ได้; สมาชิกคนสุดท้ายออกไม่ได้
- [ ] Playwright: 2 กลุ่ม → เลือก → สลับ → ข้อมูลไม่ปน; ออกจากกลุ่ม (screenshot)

## คำถามเจ้าของ

- ออกจากกลุ่มแล้ว ข้อมูลกลุ่มนั้นในเครื่องทำอย่างไร
- สมาชิกคนสุดท้ายออกจากกลุ่มได้ไหม

**คำตอบเจ้าของ (2026-10-03):**
- หลังส่ง outbox ของกลุ่มนั้นครบ → ลบสำเนาข้อมูลกลุ่มนั้นออกจากเครื่อง (ACC-5)
- สมาชิกคนสุดท้ายออกไม่ได้ (กันกลุ่มไม่มีเจ้าของ; สอดคล้องกับ MVP ไม่มีการลบกลุ่ม)
