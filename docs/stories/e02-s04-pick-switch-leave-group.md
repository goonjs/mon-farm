## คำอธิบาย

ผู้ใช้ที่อยู่หลายกลุ่มเลือกกลุ่มตอนเปิดแอปและสลับได้; สมาชิกออกจากกลุ่มได้ โดยกลุ่มและข้อมูลยังอยู่กับสมาชิกคนอื่น

## Acceptance criteria

- [ ] อยู่ ≥ 2 กลุ่ม → เปิดแอปแล้วขึ้นหน้าเลือกกลุ่ม (ACC-3)
- [ ] สลับกลุ่มได้จากหน้าตั้งค่า; หน้าจอแสดงเฉพาะข้อมูลของกลุ่มที่เลือก ไม่ปนกัน (ACC-5)
- [ ] ออกจากกลุ่ม (ยืนยัน 1 ครั้ง) → สมาชิกภาพถูกเอาออก; กลุ่มและข้อมูลยังอยู่ (ACC-2)
- [ ] หลังออก ผู้ใช้อ่าน/เขียนกลุ่มนั้นที่เซิร์ฟเวอร์ไม่ได้ (rules) (ACC-5, NFR-5)
- [ ] ไม่มีปุ่มลบกลุ่มฟาร์ม (ACC-2)

## Offline / sync behavior

- เลือก/สลับกลุ่มทำออฟไลน์ได้จากรายการสมาชิกที่เก็บในเครื่อง
- ออกจากกลุ่มขณะออฟไลน์: ส่งเมื่อมีเน็ต; event ที่ค้างใน outbox ของกลุ่มนั้นต้องส่งก่อนการออก

## Test plan

- [ ] Vitest: ตัดสินการเข้า (2 กลุ่ม → หน้าเลือก), กรองข้อมูลตามกลุ่ม
- [ ] rules test: หลังออกอ่าน/เขียนไม่ได้; สมาชิกคนอื่นยังใช้ได้
- [ ] Playwright: 2 กลุ่ม → เลือก → สลับ → ข้อมูลไม่ปน; ออกจากกลุ่ม (screenshot)
