## คำอธิบาย

บัญชีต่อคนงานที่ข้ามการขาย บันทึก **หนี้ทุกประเภท** (ไม่ใช่แค่ค่าปุ๋ย): หนี้, การหัก, การจ่ายคืนอื่น ๆ,
ยอดค้างรวมก้อนเดียว และแผนผ่อนเดียว (ไม่บังคับ) ดูประวัติแยกประเภทได้

## Acceptance criteria

- [ ] เพิ่มรายการหนี้: ประเภท (**เงินยืม/เบิกล่วงหน้า** · **ค่าปุ๋ย** · **อื่น ๆ**), จำนวนเงิน, วันที่, หมายเหตุ (อื่น ๆ ต้องมีหมายเหตุ) (D-54, D-59)
- [ ] เงินยืม/เบิกล่วงหน้า **บันทึกผู้ให้** (เงินสวน หรือคนในรายชื่อ); ยืมใครก็คืนคนนั้น — หนี้กับคนอื่นแสดงในบัญชีเพื่อดู **ไม่นับในยอดที่หักได้** คนกรีดคืนเองแล้วบันทึกว่าคืนแล้ว; สวนไม่ได้เป็นหนี้ผู้ให้ยืม (D-69)
- [ ] หนี้ค่าปุ๋ย **ใส่เองได้**: ใส่ยอดค่าปุ๋ย + **เลือก % ที่คนงานรับ** (ค่าเริ่มต้น 50% ตาม FERT-4) → หนี้ = ยอด × % (ปัดเป็นสตางค์) (D-59)
- [ ] บันทึกหนี้ค่าปุ๋ยที่ใส่เอง → แอป **สร้างค่าใช้จ่ายสวน (E11 หมวดปุ๋ย) ส่วนที่เจ้าของรับให้อัตโนมัติ** ลบ/แก้หนี้แล้วค่าใช้จ่ายนั้นปรับตาม (D-67)
- [ ] **ยอดยกมา** (ยอดค้างก่อนเริ่มใช้แอป) บันทึกเป็นรายการหนี้ได้ พร้อมวันที่และหมายเหตุ
- [ ] **ยอดค้างรวมก้อนเดียวต่อคน** = Σ หนี้ − Σ การหัก (E06-S04) − Σ การจ่ายคืนอื่น ๆ คำนวณจาก log เสมอ; การหักของการขายที่ Cancelled/ลบแล้วไม่นับ (FERT-5, D-59)
- [ ] ประวัติเรียงตามวันที่ **แยกประเภทได้** แต่ละบรรทัดเจาะไปถึงต้นทาง (การขาย/การคืน) ได้ (D-59)
- [ ] บันทึก "การจ่ายคืนอื่น ๆ" (คนงานจ่ายคืนนอกการขาย): ยอด, วันที่, หมายเหตุ; **จ่ายเกินยอดค้าง → เตือนก่อนบันทึก**
- [ ] **แผนผ่อนเดียวต่อคน** (ไม่บังคับ): ยอดต่องวด โดย **งวด = ต่อการขาย**; แก้/ยกเลิกได้ (D-59)
- [ ] แก้ / ยกเลิก (void) รายการหนี้และการจ่ายคืนได้ **เก็บประวัติ** — ยอดค้างคำนวณใหม่จาก log ไม่เขียนทับ
- [ ] แต่ละคนงานมีบัญชีของตัวเอง (เช่น แดง และ นัด แยกกัน); เข้าจากหน้าคนงาน (E03-S01, การ์ด "ข้อมูลพนักงาน" — D-65)
- [ ] หนี้ค่าปุ๋ยที่ใส่เองมีหมายเหตุและ id ที่อ้างถึงได้ — เมื่อมีระบบปุ๋ย (E06-S01/S02) ผู้ใช้เทียบจากหมายเหตุแล้วเลือกว่าลงรายการไหน (การย้ายนั้นไม่อยู่ใน story นี้) (D-59)
- [ ] **สรุปเทียบยอด** ต่อคน (D-72): Σ หนี้ (แยกประเภท) − Σ หักตอนสรุปเงิน (แยกตามวิธีรับเงิน: ดึงเงินสด / คนซื้อแบ่งกอง / โอนรวมเจ้าของ) − Σ คืนอื่น = ยอดค้าง ตรงกับที่แสดง; แยกหนี้ที่ติดสวนกับหนี้กับคนอื่น (D-69)
- [ ] เงินเก็บเป็นสตางค์จำนวนเต็ม (NFR-3)
- [ ] **ยอดยกมาต้องเลือกประเภทหนี้** (เงินยืม / ค่าปุ๋ย / อื่น ๆ) (F6) (D-74)
- [ ] % ที่คนงานรับในหนี้ค่าปุ๋ยแบบกำหนดเอง เป็น **จำนวนเต็ม** (F8) (D-74)
- [ ] หนี้ประเภท "อื่น ๆ" ติดสวนเสมอ ไม่มีช่องผู้ให้ใน MVP — ใส่ชื่อผู้ให้และสร้างข้อมูลคนเก็บไว้เป็นไอเดียหลัง MVP (low priority) (F9) (D-74)
- [ ] จ่ายคืนเกินยอดค้าง → เตือน แล้วเลือก "แก้" หรือ "บันทึกต่อ" ได้ (ยอดติดลบ = สวนติดเงินคนงาน) (F10) (D-74)

## Offline / sync

- ยอดค้างคำนวณในเครื่องจาก event ทั้งหมด; ออฟไลน์ได้
- event จากต่างเครื่อง (หนี้/การหัก/การจ่ายคืน) รวมกันได้เพราะเป็นการเพิ่มบรรทัด

**คำตอบเจ้าของ (2026-10-03, PR #44) (D-54, D-55):**
- บัญชีคนงานบันทึก **หนี้ทุกประเภท** (ค่าปุ๋ย เงินยืม/เบิกล่วงหน้า อื่น ๆ) และผ่อนชำระได้ — ต้องปรับ AC ก่อน Ready
- story นี้ + E06-S04 อยู่ลำดับแรก

**คำตอบเจ้าของ (2026-10-03) (D-59, D-65):**
- **ยอดค้างรวมก้อนเดียวต่อคน + แผนผ่อนเดียวต่อคน**; ประวัติยังแยกประเภท
- ประเภท: เงินยืม/เบิกล่วงหน้า · ค่าปุ๋ย · อื่น ๆ (+หมายเหตุ)
- หนี้ค่าปุ๋ย **ใส่เองได้ เลือก %** ที่คนกรีดรับ; มีระบบปุ๋ยแล้วค่อยย้าย โดยเทียบจากหมายเหตุ
- **งวดผ่อนนับต่อการขาย**
- เงินยืม **บันทึกผู้ให้**; ผู้ให้ไม่ใช่เงินสวน → สวนต้องคืนผู้นั้น; ตอนคืนเลือกได้ว่าใครคืนให้ใคร (E11-S03)
- การ์ด "ข้อมูลพนักงาน" → รายชื่อคนงาน → บัญชีหนี้
