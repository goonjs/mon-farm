- [ ] แสดงเด่น 6 ค่า: เลขเข่งปัจจุบัน · จุดชั่งปัจจุบัน (+ คนกรีด) · น้ำหนักเข่งไม่เต็มที่เปิดอยู่ · กก. สะสม · จำนวนเข่งที่เสร็จ · เลขเข่งถัดไป (SALE-14 คงเดิม) — วางตามคำตอบเจ้าของ 2026-10-03 ด้านล่าง (D-40)
- [ ] การ์ดบนใหญ่: "เข่งปัจจุบัน" (เข่งที่กำลังชั่ง) ตัวใหญ่ + "ถัดไป" — ตามเลย์เอาต์ mockup v1 (D-40)
- [ ] พื้นที่กดค้าง: มีแค่ข้อความ "กดค้างเพื่อบันทึกเข่งเต็ม" — ไม่มีเลขเข่งในพื้นที่กดค้าง (D-40)
- [ ] ไม่มี ticker เลขเข่งที่เสร็จแล้ว; animation เฉพาะตอนตัวเลขเปลี่ยน (D-40)
- [ ] ชื่อจุดชั่ง + คนกรีด อยู่บนแถบบนของโหมดผู้บันทึกเท่านั้น
- [ ] การ์ด 3 ใบ: เสร็จแล้ว / สะสม กก. / เข่งไม่เต็ม — ถ้าใส่ราคา ฿/กก. ไว้ก่อนเริ่มการขาย การ์ดแรกแสดงยอดเงินรวม ฿ แบบย่อแทน; ใส่ราคาระหว่างการขาย → การ์ดแรกเปลี่ยนเป็นยอดเงินทันที (D-40)
- [ ] ยอดเงินแบบย่อ: เลขนัยสำคัญไม่เกิน 3 หลัก + หน่วย พัน / หมื่น / แสน / ล้าน — 2,450 → "2.45 พัน"; 53,350 → "5.34 หมื่น"; 134,250 → "1.34 แสน"; ต่ำกว่า 1,000 แสดงเต็ม (D-41)
- [ ] เมนู ⋯ มี "ชั่งครบแล้ว → ตรวจยอด" (ห่างจากพื้นที่กดค้าง §8) ไปหน้าตรวจยอด E05-S03; หน้าเปลี่ยนจุดชั่งแสดงปุ่มเดียวกันเมื่อทุกจุดชั่งมีบันทึกแล้ว
- [ ] แนวตั้งเป็นค่าเริ่มต้น; ใช้มือเดียวได้ ปุ่มหลัก ≥ 48 (NFR-1, NFR-4)
- [ ] สลับจุดชั่ง/สวน จากหน้าชั่งได้ใน ≤ 2 แตะ; เลขเข่งต่อเนื่อง (SALE-1, SALE-10)
- [ ] ดูรายการเข่งของการขาย (เลข, จุดชั่ง, กก.) ได้โดยไม่เสียตัวเลขหลัก
