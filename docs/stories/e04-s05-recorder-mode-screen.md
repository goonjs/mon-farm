## Acceptance criteria

- [ ] แสดงเด่น 6 ค่า: เลขเข่งปัจจุบัน · จุดชั่งปัจจุบัน (+ คนกรีด) · น้ำหนักเข่งไม่เต็มที่เปิดอยู่ · กก. สะสม · จำนวนเข่งที่เสร็จ · เลขเข่งถัดไป (SALE-14) — วางตามคำตอบเจ้าของ 2026-10-03 ด้านล่าง
- [ ] พื้นที่กดค้าง: เลขเข่งปัจจุบัน (เข่งที่กำลังชั่ง) ตัวใหญ่ สีจาง
- [ ] แถบบน: ticker เลขเข่งที่เสร็จแล้ว ตัวล่าสุดตัวหนา/สี accent; เลื่อน (slide animation) ทุกครั้งที่นับ; ชื่อจุดชั่ง + คนกรีด อยู่บนแถบบนของโหมดผู้บันทึกเท่านั้น
- [ ] การ์ด 3 ใบ: เสร็จแล้ว / สะสม กก. / เข่งไม่เต็ม — ยกเว้นเมื่อใส่ราคา ฿/กก. ไว้ก่อนเริ่มการขาย การ์ดแรกแสดงยอดเงินรวม ฿ แทน ในรูปแบบย่อแบบไทย เลขนัยสำคัญไม่เกิน 3 หลัก (เช่น "1.34 แสน")
- [ ] เมนู ⋯ มี "ชั่งครบแล้ว → ตรวจยอด" (ห่างจากพื้นที่กดค้าง §8) ไปหน้าตรวจยอด E05-S03; หน้าเปลี่ยนจุดชั่งแสดงปุ่มเดียวกันเมื่อทุกจุดชั่งมีบันทึกแล้ว

- [ ] สลับจุดชั่ง/สวน จากหน้าชั่งได้ใน ≤ 2 แตะ; เลขเข่งต่อเนื่อง (SALE-1, SALE-10)
- [ ] ดูรายการเข่งของการขาย (เลข, จุดชั่ง, กก.) ได้โดยไม่เสียตัวเลขหลัก
