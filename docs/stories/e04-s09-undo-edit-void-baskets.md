- **ย้อนกลับ**: ยืนยัน 1 ครั้ง (แถบยืนยันเดิม แสดงเลขเข่ง) — ย้อนเข่งล่าสุดของ "ลำดับเลข"
  เดียวกับเลขบนหน้าชั่ง (ของคนกรีด หรือของจุด) ไม่ใช่เฉพาะจุดที่เปิดอยู่;
  `nextBasketNo` ไม่นับเข่งที่ถูกย้อน → เลขเดิมใช้ซ้ำ (คำตอบเจ้าของ)
- **ยกเลิก**: แตะแถวในรายการเข่ง → "ยกเลิกเข่งนี้" → ยืนยัน → `correction` mode `void`;
  แถวยังอยู่ ขีดฆ่า ✗ "ยกเลิกแล้ว"; เลขอื่นคงเดิม เห็นช่อง (คำตอบเจ้าของ)
- **แก้** (น้ำหนักสุทธิ กก. และ/หรือ จุดชั่ง): void ของเดิม (reason แก้) + event ใหม่
  ชนิดเดิม เลขเดิม `input: 'edit'`, `editOf` = id เดิม — ของเดิมอยู่ใน log;
  รายการแสดงตัวใหม่ "แก้แล้ว" ซ่อนตัวเดิม; ย้ายไปจุดที่ยังไม่อยู่ในการขาย → เพิ่ม
  สวน/จุดให้การขายก่อน (`pointSetupPayloads`)
- type เพิ่มอย่างเดียว: `editOf?` บน accept/short, `input` เพิ่ม `'edit'`
- ใคร/เมื่อไร/เครื่องไหน: อยู่ใน envelope ทุก event อยู่แล้ว; ฟอร์มแก้แสดงเครื่อง + เวลา
- **ยังไม่ทำ**: แก้ซ้อนจากสองเครื่องบนฐานเดียวกัน → Conflict (ต้องมี E01-S11 ก่อน);
  ตอนนี้ถ้าเกิดจะได้เข่งแก้สองตัว; ส่วนเข่ง (E04-S06) ยังไม่มี

  - S3: ย้อนกลับในโหมดสาธารณะใช้เข่งล่าสุดของลำดับเดียวกับหน้าผู้บันทึก
