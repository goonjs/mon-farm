## Acceptance criteria

- [ ] AC1 (ข้อ 6): หน้าสรุปยอดส่วนแบ่งใช้การ์ดบนสุดแบบเดียวกับหน้าตรวจยอด (น้ำหนัก ราคา เข่ง เข่งไม่เต็ม ยอดเงิน) ร่วม component เดียว
- [ ] AC2 (ข้อ 7): การ์ดคนกรีดบนหน้าตรวจยอดแสดงจุดเข่ง (เต็ม/ไม่เต็ม), น้ำหนักรวม, จำนวนเข่งไม่เต็ม; การ์ดบนสุดบอกว่าเข่งไม่เต็มแต่ละเข่งเป็นของใคร
- [ ] AC3 (ข้อ 8): การ์ดเงินรายคน (component เดียว `PersonMoney`) ใส่เครื่องหมายตรงกับหน้าเทียบยอด: เงินที่คนนั้นได้รับจากสวน = `+`, เงินที่จ่ายออก/ถูกหัก = `−`
- [ ] AC4 (ข้อ 9): หน้าการจ่ายเงินแสดงรายละเอียดเงินรายคนด้วย `PersonMoney` ตัวเดียวกับหน้าสรุปส่วนแบ่ง
- [ ] AC5 (ข้อ 10): สัญลักษณ์เงิน (บาท) อยู่บรรทัดบน (ป้ายกำกับ) ไม่ตกบรรทัดใหม่เมื่อตัวเลขยาว
- [ ] AC6 (ข้อ 13): `FarmScreen` มีตัวเลือก `scrollCue`: ขณะยังเลื่อนต่อได้ แถบปุ่มล่างมีเงาด้านบนและปุ่มจาง (กดได้ ไม่บังคับ) หายเมื่อเลื่อนถึงท้าย; เปิดใช้กับ 3 หน้านี้
