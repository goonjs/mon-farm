# Story E09-S01: ครอบครัวและสมาชิก

Status: Draft

## Context

- Epic: `docs/epics/e09-worker-documents.md`
- PRD: DOC-1, SYNC-9, SYNC-10, SYNC-12, NFR-5
- ขึ้นกับ: E01 (event log + sync), E02 (กลุ่มฟาร์ม), E03 (คน: คนกรีด)
- ใช้ป้ายจาก E01-S15 (สถานะข้อมูลรายฟิลด์ SYNC-12)

## คำอธิบาย

เจ้าของสร้างครอบครัวของคนงานหลัก (แดง, นัด) และเพิ่มสมาชิกในครอบครัวได้
เป็นฐานให้เอกสารใน E09-S02 ไม่ใช่ทะเบียนราษฎร์

## Acceptance criteria

- [ ] สร้างครอบครัวผูกกับคนงานหลักจากข้อมูลหลัก (E03) ได้ (DOC-1)
- [ ] สมาชิกมีฟิลด์: ชื่อ, ชื่อเรียก, ความสัมพันธ์กับคนงานหลัก, วันเกิด/อายุ, บทบาท (คนงาน/ครอบครัว), หมายเหตุ — บังคับเฉพาะชื่อ (DOC-1)
- [ ] ฟิลด์ที่ไม่กรอกแสดงเป็น "ไม่ได้บันทึก" (ถ้ารู้ว่าไม่มีใครรู้ค่า = "ไม่ทราบ") ไม่ใช่ค่าว่างหรือ 0 — ป้ายจาก E01-S15 (SYNC-12, design-system §12.9 ข้อ 9)
- [ ] แก้ไขสมาชิกได้ทุกเมื่อ และลบแบบกู้คืนได้ (SYNC-9, SYNC-10)
- [ ] ข้อมูลครอบครัวเห็นได้เฉพาะสมาชิกกลุ่มฟาร์มที่ login แล้ว (NFR-5)

## Offline / sync

- สร้าง/แก้/ลบ ได้ออฟไลน์ทั้งหมด เป็น event ในเครื่อง → sync อัตโนมัติเมื่อมีเน็ต (SYNC-1, SYNC-2)
- แก้สมาชิกคนเดียวกันจากสองเครื่องบนฐานเดียวกัน → Conflict ให้เลือก ไม่ทับเงียบ

## Test plan

- [ ] Unit: projection ครอบครัว → สมาชิก จาก event (สร้าง, แก้, soft delete, กู้คืน)
- [ ] Offline: สร้างสมาชิกตอนออฟไลน์ ปิด-เปิดแอป ข้อมูลยังอยู่และขึ้น Pending Sync
- [ ] Rules: ผู้ใช้นอกกลุ่มอ่านข้อมูลครอบครัวไม่ได้ (Firestore rules test)
