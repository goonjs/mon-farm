## Description

ผู้ใช้เลือกขนาดตัวอักษร เล็ก / กลาง / ใหญ่ ได้ที่หน้า "เครื่องนี้" ตัวอักษรทั้งแอปย่อ/ขยายตามสัดส่วน
ยกเว้นตัวเลขนับบนจอสาธารณะ แล้วไล่ตรวจทุกหน้าที่ค้างว่าที่ขนาดใหญ่สุดไม่มีอะไรถูกตัดหรือล้นจอ

พบตอนเขียนสตอรี่: e2e เดิมที่ "ทดสอบตัวอักษรใหญ่สุด" (`v2-sale-history`, `v2-pending-repay`) ตั้งค่า
`mon-farm:text-size = l` แต่ theme ไม่เคยอ่านค่านี้ ตัวอักษรจึงไม่ได้ขยายจริง — ผลตรวจเดิมใช้ไม่ได้ ต้องตรวจใหม่ในสตอรี่นี้
