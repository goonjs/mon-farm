## คำอธิบาย

บันทึกเอกสารของสมาชิก (บัตรชมพู, หนังสือเดินทาง, วีซ่า, ประกันสุขภาพ, เพิ่มประเภทได้)
พร้อมถ่ายรูป/แนบไฟล์ แสดงรายการเอกสารต่อสมาชิกและต่อครอบครัว

## Acceptance criteria

- [ ] เอกสารมีฟิลด์: ประเภท, ผู้ถือ, วันออก (ไม่บังคับ), วันหมดอายุ, สถานะ, รูป/ไฟล์, หมายเหตุการต่ออายุ, ผู้รับผิดชอบ (DOC-2)
- [ ] ประเภทเอกสารเริ่มต้น 4 แบบ และเจ้าของเพิ่มประเภทเองได้ (DOC-2)
- [ ] ถ่ายรูป/แนบไฟล์ได้หลายรูปต่อเอกสาร เก็บวันที่และ entity ที่เกี่ยวข้อง (OPS-13)
- [ ] แอปไม่แสดงหรือคำนวณสถานะทางกฎหมาย (เช่น "อยู่อย่างผิดกฎหมาย") — แสดงแค่วันที่และสถานะที่เจ้าของบันทึก (DOC-5)
- [ ] URL รูปเอกสารเดาไม่ได้ และเปิดได้เฉพาะสมาชิกกลุ่ม (NFR-5)

## Offline / sync

- บันทึกเอกสารและถ่ายรูปได้ออฟไลน์; รูปเข้าคิวในเครื่อง อัปโหลดโดย sync engine (NFR-2)
- รายการแสดงสถานะรูป: อัปโหลดแล้ว / รออัปโหลด

## Test plan

- [ ] Unit: projection เอกสารต่อสมาชิก + ประเภทที่เพิ่มเอง
- [ ] Offline: ถ่ายรูปตอนออฟไลน์ → อยู่ในคิว → ต่อเน็ตแล้วอัปโหลด ข้อมูลไม่หายเมื่ออัปโหลดล้มเหลว
- [ ] Rules: Storage rules ปฏิเสธผู้ใช้นอกกลุ่ม
