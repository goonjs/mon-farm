## คำอธิบาย

หน้าเทียบยอด (18a) เดิมมีเลข "ยอดขายทั้งหมด" เลขเดียว เจ้าของสวนทวนแล้วไม่ชัดว่ายอดมาจากไหน
ให้แสดงยอดขายละเอียดเท่าหน้า 16 (กก. ราคา เข่ง เข่งไม่เต็ม ยอดต่อคน) แล้วตามด้วยเงินแต่ละกอง
พร้อมที่มาของแต่ละยอด แล้วค่อยเทียบ รวมทุกกอง = ยอดขายทั้งหมด

ไม่เปลี่ยน logic: ตัวเลขทุกตัวมาจาก `useSaleMoney` / `settlement` ที่มีอยู่ ไม่คำนวณเงินใหม่ในหน้าจอ

- [x] การ์ดเทียบ: รวมทุกกอง · ยอดขายทั้งหมด · ป้าย "ตรงกันถึงสตางค์" หรือ "ต่างกัน … บาท" + ปิดการขายไม่ได้ เหมือนเดิม (D-72)

## Dev notes

- แก้หลังรีวิว: บรรทัดที่มาเคยหัก "หักกลบ" ออกด้วย ทำให้ผลบวกต่ำกว่าเงินสดจริง (หักกลบหักล้างกันเองในสูตร `workerCash`) → ตอนนี้แสดงแยก "หักกลบ … (ไม่กระทบเงินสด)"; เครื่องหมาย +/− อยู่ในข้อความแปลทั้งไทยและอังกฤษ
- โซนที่ไม่มีคนกรีดยาง (`personId` null) ไม่ขึ้นแถวต่อคน (กรองออก) — ในทางปฏิบัติสรุปเงินไม่ได้จนทุกจุดมีคน (หน้า 16) จึงเป็นแค่กันพลาด ไม่มีเทสต์แยก
- ม็อก 18a ปรับตามโค้ด: ป้าย "ยอดเงิน" (ตรงหน้า 16), "คืนหนี้ มากับโอน", "คืนหนี้ (เงินสด)"; หัวการ์ดยังเป็น "ยอดขายทั้งหมด"
- ภาพ 18a-tally.png ใหม่: ถ่ายเต็มหน้าจากการขายที่มีหักหนี้ + หักกลบ (e2e netting)

- แยก `SaleFigures` (ส่วนแสดงยอดขาย) ออกจาก `CheckBody` ใช้ร่วมกับ `TallyScreen` ด้วย `prefix` ของ testID; ไม่มี logic เงินใหม่
- เอา key `v2s.cashTappers` ออก (ไม่ใช้แล้ว) เพิ่ม `v2s.pilesTitle/cashTo/fromShare/ownerPart` ทั้งไทยและอังกฤษ
