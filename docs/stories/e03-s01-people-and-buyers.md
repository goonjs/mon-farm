## คำอธิบาย

ย้ายรายชื่อคนจากเครื่อง (S16) ไปเป็นข้อมูลหลักของกลุ่มฟาร์ม ที่ทุกเครื่องเห็นเหมือนกัน
เพิ่มบทบาทของคนและรายชื่อผู้ซื้อ เป็นรูปแบบแรกของ "ข้อมูลหลักเป็น event" ที่ story E03 อื่นใช้ต่อ
(คำบนจอ วันที่ และป้าย sync ต่อแถว ที่กำหนดในนี้ ใช้กับข้อมูลหลักทุก story ของ E03)

## Acceptance criteria

- [ ] สร้าง / แก้ชื่อ / ลบ (กู้คืนได้) บุคคลได้ ทุกครั้งเป็น event ของกลุ่มฟาร์ม; แก้ชื่อแล้ว id ไม่เปลี่ยน (MD-5)
- [ ] บุคคลมีบทบาทได้มากกว่าหนึ่ง (เผื่อเลื่อนตำแหน่ง): คนกรีด · ผู้จัดการสวน · ผู้จ่าย · ผู้เช่า · **บทบาทอื่นพิมพ์เองได้** (เช่น "ลูกคนงาน"); **ต้องมีอย่างน้อย 1 บทบาท** (เจ้าของตกลง AC 2026-10-03 — แทน D-65 ข้อ "คนไม่ต้องมีบทบาท")
- [ ] คำบนจอของ Soft Delete = **"ลบ"** พร้อมบอกว่า **"กู้คืนได้"** (ไม่ใช้คำ "เก็บถาวร"); คนที่ลบแล้วไม่ขึ้นในตัวเลือก แต่บันทึกเก่าที่อ้างถึงยังแสดงชื่อได้ และกู้คืนได้ (D-65, D-27)
- [ ] ลบคนกรีด หรือเอาบทบาทคนกรีดออก ขณะยังรับผิดชอบจุดชั่ง (E03-S05) → **เตือน** พร้อมรายชื่อจุด **ไม่ขวาง**; จุดเหล่านั้นจะขึ้นคำเตือน "ยังไม่มีคนกรีด" (D-65)
- [ ] ผู้ซื้อ: เพิ่ม / แก้ / ลบ (กู้คืนได้); การขายใหม่ใช้ผู้ซื้อรายล่าสุดเป็นค่าเริ่มต้น (MD-6); **ผู้ซื้อล่าสุดถูกลบ → ไม่มีค่าเริ่มต้น ให้เลือกเอง** (D-65)
- [ ] `PeoplePicker` อ่านจากข้อมูลหลักชุดนี้ และกรองตามบทบาทได้
- [ ] รายชื่อคนงานเข้าได้จาก ☰ → "ข้อมูลฟาร์ม" และจากการ์ด "ข้อมูลพนักงาน" บนหน้าแรก (ตัวการ์ดอยู่ E13-S01); หน้าคนงานมีทางไป บัญชีหนี้ (E06-S03) · ส่วนแบ่ง (E03-S06) · จุดที่รับผิดชอบ (E03-S05) — ลิงก์ที่ story ปลายทางยังไม่ทำ ไม่ต้องแสดง (D-65)
- [ ] วันที่บนจอแสดงเป็น พ.ศ. (เช่น `1 ต.ค. 2569`) แตะเพื่อสลับ พ.ศ./ค.ศ. ได้ (D-65)
- [ ] ป้าย sync ต่อแถวในรายการข้อมูลหลัก แสดงเฉพาะ **"ขัดกัน"**; รอส่งดูที่ตัวบอกภาพรวม (E01-S10) (D-65)
- [ ] เครื่องที่ 2 ในกลุ่มเดียวกันเห็นคนที่เครื่องแรกสร้าง หลัง sync (SYNC-4)
