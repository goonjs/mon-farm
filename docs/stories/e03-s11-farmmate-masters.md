  `design/` คือที่เดียวที่มีสีดิบได้ (เหมือน `design/tokens.ts`) จึงไม่ต้องยกเว้นกฎ no-raw-colour; โค้ดใน `src/` ไม่มี hex เพิ่ม.
  ผลคือสีของไอคอนไม่ตามธีม — ตั้งใจ ตามที่เจ้าของให้ทำธีมสว่างก่อน
- **SVG หรือ PNG (FM-4)** — วัดบน build เว็บจริง (`expo export`), Chromium, จอ Pixel 7, เวลาจากแตะแถว "ไอคอนทั้งหมดในแอป"
  จนไอคอนครบบนจอ + 2 เฟรม, ค่ามัธยฐานของ 5 รอบ (ตัดรอบแรก):

  | แบบ | ไอคอน | CPU ปกติ | CPU ช้าลง 6× | bundle JS (gzip) |
  |---|---|---|---|---|
  | dev เดิม: แบบวาดง่าย (react-native-svg) | 40 | 103 ms | 400 ms | 989 KB |
  | SVG ต้นฉบับ (`SvgXml`) | 72 | 127 ms | 590 ms | 1,198 KB (+209) |
  | PNG pre-render 144 px (`Image`) | 72 | 212 ms | 1,194 ms | + PNG 356 KB แยกไฟล์ |

  วัดซ้ำหลังแก้ตามรีวิว (เครื่องคนละรอบ ช้ากว่ารอบแรกราว 1.5–2 เท่า จึงเทียบกันเฉพาะในตารางนี้):

  | แบบ | ไอคอน | CPU ปกติ | CPU ช้าลง 6× |
  |---|---|---|---|
  | dev เดิม: แบบวาดง่าย | 40 | 146 ms | 793 ms |
  | SVG ผ่าน `SvgXml` (รอบแรก) | 72 | 212 ms | 1,005 ms |
  | **SVG parse ครั้งเดียว + `SvgAst` (ที่ใช้)** | 72 | 201 ms | 1,143 ms |
  | PNG pre-render 144 px | 72 | 318 ms | 2,319 ms |

  SVG เร็วกว่า PNG ราว 2 เท่า (PNG ต้องโหลดและถอดรหัสทีละไฟล์) และหน้าจริงมีไอคอนแบบนี้ไม่เกินราว 10 อัน → **เลือก SVG ต้นฉบับ**.
  ต้นทุนคือ bundle ใหญ่ขึ้น ~200 KB gzip (ทั้ง 72 อันอยู่ใน bundle เดียว)
- Android: ประเมินจาก CPU ช้าลง 6× (ใกล้มือถือ Android เครื่องล่าง) — ยังไม่ได้วัดบนเครื่อง Android จริง
- ปัดพิกัดเป็นจำนวนเต็ม: ทำแล้วใน PR 5 (ดูหัวข้อ PR 5)
- **แก้ตามรีวิวอิสระ (#145)**: `SvgXml` ส่ง prop `xml` ต่อไปถึง `<svg>` บนเว็บ ทำให้ DOM มีซอร์สของทุกไอคอนเป็น attribute
  (หน้า /v2/dev/icons: 76 svg มี `xml`, HTML 1.25 MB) → `FarmMateArt` parse ต้นฉบับครั้งเดียวต่อ id (เก็บใน Map) แล้ววาดด้วย `SvgAst`
  → ไม่มี `xml` ใน DOM, HTML 0.68 MB (e2e ตรวจไว้). ตัวย่อ SVG ปัดเฉพาะ `d` กับ `viewBox`, คงเครื่องหมายลบของเลขที่ปัดเป็น 0
  (`M5.5-0.04` ไม่กลายเป็น `M5.50`), ตัด width/height เฉพาะที่ `<svg>`, และ throw เมื่อเจอ exponent หรือ element อื่นนอกจาก
  svg/g/path. id มี type `FarmMateArtId` (พิมพ์ผิด compile ไม่ผ่าน). มี `npm run icons:check`
- react-native-svg มีอยู่แล้ว (15.15.4) ไม่ลง package ใหม่
