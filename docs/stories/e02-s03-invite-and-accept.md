## คำอธิบาย

สมาชิกเชิญคนอื่นเข้ากลุ่ม ผู้ถูกเชิญ login แล้วตอบรับ กลายเป็นเจ้าของสิทธิ์เท่ากัน
และเห็นข้อมูลกลุ่มชุดเดียวกันหลัง sync (วิธีเชิญยังรอเจ้าของตัดสิน — ดูด้านล่าง)

## Acceptance criteria

- [ ] สมาชิกสร้างคำเชิญได้ ตามวิธีที่เจ้าของเลือก (ACC-2)
- [ ] ผู้ถูกเชิญ login แล้วตอบรับ → เป็นสมาชิก `role: 'owner'` (ACC-4)
- [ ] หลังตอบรับและ sync ผู้ถูกเชิญเห็นข้อมูลกลุ่มเดียวกับเจ้าของคนอื่น (SYNC-4)
- [ ] คนที่ไม่ได้รับเชิญเข้ากลุ่มเองไม่ได้ — บังคับที่ rules (ACC-5, NFR-5)
- [ ] ข้อความเชิญ/ตอบรับเป็นภาษาไทย

## Offline / sync behavior

- การตอบรับต้องมีเน็ต (เซิร์ฟเวอร์ต้องยืนยันคำเชิญ) — ขึ้นข้อความไทยชัดเจนเมื่อออฟไลน์
- หลังตอบรับ ข้อมูลกลุ่มดึงลงมาเก็บในเครื่องแล้วใช้ออฟไลน์ได้ (ACC-6)

## Test plan

- [ ] rules test บน emulator: มีคำเชิญ → เข้าได้; ไม่มี/ใช้แล้ว/ผิดกลุ่ม → เข้าไม่ได้
- [ ] jest-expo: หน้าจอเชิญ + ตอบรับ, สถานะออฟไลน์
- [ ] integration: 2 ผู้ใช้บน emulator — เชิญ → ตอบรับ → เห็นการขายเดียวกัน

## ต้องให้เจ้าของทำ/อนุมัติ

- เลือกวิธีเชิญ: ลิงก์ / รหัส / ระบุอีเมล Google; คำเชิญหมดอายุไหม ใช้ได้กี่ครั้ง
- ถ้าวิธีที่เลือกต้องใช้โค้ดฝั่งเซิร์ฟเวอร์ (Cloud Functions) → อนุมัติค่าใช้จ่ายและ deploy
