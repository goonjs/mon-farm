# Story E09-S04: ต่ออายุเอกสารและประวัติ

Status: Draft

## Context

- Epic: `docs/epics/e09-worker-documents.md`
- PRD: DOC-4, SYNC-9, SYNC-11
- ขึ้นกับ: E09-S02, E09-S03

## คำอธิบาย

เมื่อต่ออายุ เจ้าของบันทึกเอกสารฉบับใหม่ ฉบับใหม่กลายเป็นฉบับปัจจุบัน
ฉบับเก่าย้ายไปประวัติ ไม่ถูกเขียนทับ

## Acceptance criteria

- [ ] ปุ่ม "ต่ออายุ" สร้างเอกสารใหม่ของผู้ถือและประเภทเดิม โดยเติมค่าเดิมให้ แก้ได้ (DOC-4)
- [ ] ฉบับใหม่เป็นฉบับปัจจุบัน; ฉบับก่อนหน้าแสดงในส่วน "ประวัติ" พร้อมรูปเดิม (DOC-4)
- [ ] การเตือนของฉบับเก่าหยุด และฉบับใหม่เริ่มรอบเตือนใหม่ (DOC-3)
- [ ] งานต่ออายุที่เชื่อมไว้ (ถ้ามี) แสดงลิงก์ไปเอกสารฉบับใหม่ (TASK-1)
- [ ] บันทึกที่มา: ใครต่ออายุ เมื่อไร (SYNC-11)

## Offline / sync

- ต่ออายุได้ออฟไลน์; เป็น event `renew` ที่อ้างฉบับเก่า → ประวัติไม่หายแม้ sync ทีหลัง
- ต่ออายุเอกสารเดียวกันจากสองเครื่อง → Conflict ให้เลือก

## Test plan

- [ ] Unit: projection ฉบับปัจจุบัน/ประวัติ หลัง renew หลายรอบ
- [ ] Unit: ตารางเตือนย้ายจากฉบับเก่าไปฉบับใหม่
- [ ] Offline: ต่ออายุตอนออฟไลน์ แล้ว sync — อีกเครื่องเห็นฉบับปัจจุบันเดียวกัน
