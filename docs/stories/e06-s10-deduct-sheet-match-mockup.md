## ต่างจาก mockup (ดูจากภาพ)

| จุด | mockup | ของจริง |
|---|---|---|
| หักเต็ม / ยังไม่หัก | กล่องสี่เหลี่ยมมุมมน 2 บรรทัด (คำ + ยอด/คำรอง) กว้างเท่ากัน | pill เกือบกลม ขอบเส้น บรรทัดเดียว กว้างไม่เท่ากัน |
| บรรทัด "งวด 1 จาก 3 · งวดต่อไปราว …" | แถบเขียวอ่อนพร้อม ✓ ใต้ หักเต็ม/ยังไม่หัก | ข้อความเล็กข้างช่องยอด |
| "ผ่อนกี่งวด" | หัวข้อบรรทัดของตัวเอง (คำรองชิดขวา) ปุ่มงวดอยู่บรรทัดล่าง | หัวข้ออยู่บรรทัดเดียวกับปุ่มงวด เบียดกัน |
| ปุ่ม 2/3/4 งวด | กล่องเท่ากัน 3 ช่อง เต็มความกว้าง ที่เลือก = พื้นเข้ม | กล่องขอบเส้น ที่เลือก = พื้นฟ้าอ่อน |
| ช่องยอดหัก | เต็มความกว้าง | กว้างครึ่งเดียว มีข้อความข้าง |

## Acceptance criteria (เจ้าของตกลงแล้ว 2026-11-18 03:18)

- [x] **DS-1** หักเต็ม / ยังไม่หัก เป็นกล่องสี่เหลี่ยมมุมมนเล็ก 2 ช่องกว้างเท่ากัน 2 บรรทัด (บรรทัดบน = คำ ตัวหนา · บรรทัดล่าง = ยอด หรือ "ขอติดไว้ก่อน") ตาม mockup — ไม่มี pill เกือบกลม · พฤติกรรมเดิมคงไว้: แตะ "ยังไม่หัก" จากมุมมองแผน = 0 และปิดแผ่นในแตะเดียว (E06-S09)
- [x] **DS-2** บรรทัดสถานะงวด ("งวด 1 จาก N · งวดต่อไปราว X · เศษสตางค์ไปงวดสุดท้าย") เป็นแถบเขียวอ่อนพร้อม ✓ อยู่ใต้ DS-1 ตาม mockup
- [x] **DS-3** "ผ่อนกี่งวด" เป็นหัวข้อบรรทัดของตัวเอง คำรอง "เลือกแล้วจำไว้ใช้การขายหน้า" ชิดขวาบรรทัดเดียวกัน · ปุ่มงวดอยู่บรรทัดถัดไป
- [x] **DS-4** ปุ่มงวด = กล่องสี่เหลี่ยมมุมมนเท่ากัน เต็มความกว้าง (2 บรรทัด: "N งวด" / "งวดละ X") · ที่เลือก = พื้นเข้ม ตัวขาว ตาม mockup
- [x] **DS-5** ช่องยอดหักเต็มความกว้าง ไม่มีข้อความข้าง · ข้อความ "งวด 1 จาก N · งวดต่อไปราว X" ที่เคยอยู่ข้างช่อง ย้ายไปอยู่ในแถบเขียวของ DS-2 (ไม่ลบทิ้ง)
- [x] **DS-6** ตัวเลข การคำนวณ และพฤติกรรมเดิมของ E06-S09 (IP-1…IP-15) ไม่เปลี่ยน · ไม่เปลี่ยน event หรือโครงสร้างข้อมูล
