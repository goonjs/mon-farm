## คำอธิบาย

เปิดการแจ้งเตือนแยกต่องาน (เอกสารเปิดเสมอ) ผู้รับค่าเริ่มต้นคือเจ้าของ เพิ่มอาจารย์
สมหวังได้เป็นเรื่อง ๆ ความถี่ตามที่ระบบแนะนำต่อประเภท แก้ได้

## Acceptance criteria

- [ ] การแจ้งเตือนงานปิดเป็นค่าเริ่มต้น เปิดได้ต่องาน; เอกสารเปิดเสมอ (TASK-4)
- [ ] ผู้รับค่าเริ่มต้น = เจ้าของ; เพิ่มอาจารย์สมหวังได้ต่องาน/เรื่อง ไม่เพิ่มอัตโนมัติ (TASK-5)
- [ ] ความถี่: ค่าแนะนำต่อประเภท แก้ได้; งานทั่วไปไม่เตือนซ้ำเว้นแต่เลือก; เอกสารเตือนซ้ำจนจัดการ (TASK-7)
- [ ] การตั้งค่าเก็บเป็นข้อมูลของงาน sync ไปทุกเครื่อง ตัวส่งฝั่ง server อ่านได้ (E08-S05)
