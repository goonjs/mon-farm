# Story E11-S02: ผู้จ่ายจริงและเงินที่ต้องคืน

Status: Draft

## Context

- Epic: `docs/epics/e11-finance.md`
- PRD: FIN-1, FIN-3, FIN-4
- ขึ้นกับ: E11-S01, E03 (คน: ผู้จ่ายเงิน)

## คำอธิบาย

ระบุว่าใครจ่ายเงินจริงในแต่ละค่าใช้จ่าย ถ้าไม่ใช่เงินของสวน ระบบสร้างรายการ
"เงินที่ต้องคืน" ให้คนนั้นโดยอัตโนมัติ

## Acceptance criteria

- [ ] ผู้จ่ายจริงเลือกจาก: เจ้าของ · อาจารย์สมหวัง · น้องของเจ้าของ · คนงานกรีดยาง · เพิ่มได้ (FIN-3)
- [ ] ผู้จ่ายที่ไม่ใช่เงินของสวน → สร้างเงินที่ต้องคืน: ต้องคืนใคร, ค่าใช้จ่ายที่เชื่อม, ยอดเดิม, ยอดคงเหลือ, วันที่, สถานะ (FIN-4)
- [ ] ค่าใช้จ่ายสวนที่เจ้าของจ่าย = เงินที่ต้องคืนเจ้าของ ไม่ใช่รายจ่ายครัวเรือน (FIN-4)
- [ ] หน้า "ค้างใคร" แสดงยอดคงเหลือรวมต่อคน และเจาะลงถึงค่าใช้จ่ายได้ (FIN-1, ANA-1)
- [ ] เปลี่ยนผู้จ่ายหรือจำนวนเงิน → เงินที่ต้องคืนปรับตาม พร้อมประวัติ

## Offline / sync

- สร้างเงินที่ต้องคืนในเครื่องจาก event ค่าใช้จ่าย → ใช้ได้ออฟไลน์ ไม่มีการสร้างซ้ำหลัง sync

## Test plan

- [ ] Unit: ค่าใช้จ่าย → เงินที่ต้องคืน (ผู้จ่ายแต่ละแบบ, เปลี่ยนผู้จ่าย, ลบค่าใช้จ่าย)
- [ ] Offline: บันทึกสองเครื่องแล้ว sync — ไม่เกิดเงินที่ต้องคืนซ้ำ

## คำถามเจ้าของ

- มี "เงินของสวน" (บัญชี/เงินสดของสวน) เป็นผู้จ่ายแยกต่างหากไหม? ถ้าไม่มี ทุกค่าใช้จ่ายจะเป็นเงินที่ต้องคืนใครสักคน
