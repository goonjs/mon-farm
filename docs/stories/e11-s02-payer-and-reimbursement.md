# Story E11-S02: ผู้จ่ายจริงและเงินที่ต้องคืน

## คำอธิบาย

ระบุว่าใครจ่ายเงินจริงในแต่ละค่าใช้จ่าย ถ้าไม่ใช่เงินของสวน ระบบสร้างรายการ
"เงินที่ต้องคืน" ให้คนนั้นโดยอัตโนมัติ

## Acceptance criteria

- [ ] ผู้จ่ายจริงเลือกจาก: **เงินสวน** · เจ้าของ · อาจารย์สมหวัง · น้องของเจ้าของ · คนงานกรีดยาง · เพิ่มได้ (FIN-3, D-62)
- [ ] ผู้จ่ายเริ่มต้น = **ผู้จ่ายของค่าใช้จ่ายครั้งก่อน** (D-62)
- [ ] ผู้จ่าย = เงินสวน → **ไม่สร้าง** เงินที่ต้องคืน (D-62)
- [ ] ผู้จ่ายที่ไม่ใช่เงินสวน และค่าใช้จ่ายมีวงจร **เกิดจริง** → สร้างเงินที่ต้องคืน: ต้องคืนใคร, ค่าใช้จ่ายที่เชื่อม, ยอดเดิม, ยอดคงเหลือ, วันที่, สถานะ (FIN-4); วงจร ผูกพันแล้ว/วางแผน **ยังไม่สร้าง** — สร้างเมื่อเลื่อนเป็นเกิดจริง
- [ ] ค่าใช้จ่ายสวนที่เจ้าของจ่าย = เงินที่ต้องคืนเจ้าของ ไม่ใช่รายจ่ายครัวเรือน (FIN-4)
- [ ] เงินยืมของคนกรีดจากคนอื่นที่ไม่ใช่เงินสวน **ไม่สร้างเงินที่สวนต้องคืน** — หนี้อยู่ระหว่างคนกรีดกับผู้ให้ยืมโดยตรง (D-69)
- [ ] หน้า "ค้างใคร" แสดงยอดคงเหลือรวมต่อคน และเจาะลงถึงค่าใช้จ่าย/รายการหนี้ต้นทางได้ (FIN-1, ANA-1)
- [ ] การ์ด "รายการที่ต้องจ่าย" บนหน้าแรกใช้ข้อมูล = เงินที่สวนต้องคืน (คงเหลือ > 0) + ค่าใช้จ่ายที่ผูกพันแล้ว (E11-S01) (D-65; ตัวการ์ดอยู่ E13-S01)
- [ ] เปลี่ยนผู้จ่าย จำนวนเงิน หรือวงจร → เงินที่ต้องคืนปรับตาม พร้อมประวัติ (รวมเปลี่ยนเป็นเงินสวน → รายการเงินที่ต้องคืนถูกยกเลิก)
- [ ] เงินที่สวนต้องคืนคนกรีด แสดงให้ E06-S04 เสนอหักกลบตอนสรุปเงินได้ (D-60 — การหักกลบเป็นงานของ E06-S04)
- [ ] ค่าใช้จ่ายส่วนเจ้าของที่สร้างจากหนี้ค่าปุ๋ย: **เลือกผู้จ่ายได้ ไม่บังคับ ใส่ทีหลังได้** (F7) (D-74)

## Offline / sync

- สร้างเงินที่ต้องคืนในเครื่องจาก event ค่าใช้จ่าย (เป็น projection) → ใช้ได้ออฟไลน์ ไม่มีการสร้างซ้ำหลัง sync
- แก้ผู้จ่าย/จำนวนเงินซ้อนจากสองเครื่อง → Conflict ตาม E11-S01 (D-30)

## Test plan

- [ ] Unit: ค่าใช้จ่าย → เงินที่ต้องคืน (เงินสวน = ไม่สร้าง, ผู้จ่ายแต่ละแบบ, ผูกพันแล้ว/วางแผน = ไม่สร้าง, เลื่อนเป็นเกิดจริง = สร้าง, เปลี่ยนผู้จ่าย, ลบค่าใช้จ่าย)
- [ ] Unit: ผู้จ่ายเริ่มต้น = ครั้งก่อน
- [ ] Unit: เงินยืมคนกรีดจากคนอื่น → ไม่มีเงินที่สวนต้องคืน (D-69)
- [ ] Unit: ยอดการ์ด "รายการที่ต้องจ่าย" = คงเหลือที่ต้องคืน + ผูกพันแล้ว
- [ ] Offline: บันทึกสองเครื่องแล้ว sync — ไม่เกิดเงินที่ต้องคืนซ้ำ

## คำถามเจ้าของ

- มี "เงินของสวน" (บัญชี/เงินสดของสวน) เป็นผู้จ่ายแยกต่างหากไหม? ถ้าไม่มี ทุกค่าใช้จ่ายจะเป็นเงินที่ต้องคืนใครสักคน

**คำตอบเจ้าของ (2026-10-03) (D-62, D-59, D-65):**
- **มี "เงินสวน" เป็นผู้จ่าย** (ไม่สร้างเงินที่ต้องคืน); ผู้จ่ายเริ่มต้น = คนเดิมครั้งก่อน
- เงินยืมของคนกรีด บันทึกผู้ให้; ผู้ให้ไม่ใช่เงินสวน → สวนต้องคืนผู้นั้น
- การ์ด "รายการที่ต้องจ่าย" = เงินที่สวนต้องคืน + ค่าใช้จ่ายที่ผูกพันแล้ว

**คำถามค้าง:**
- ✅ (เจ้าของตอบ 2026-10-03) ค่าใช้จ่ายที่ผูกพันแล้ว (สั่งแล้ว ยังไม่จ่าย) ใส่ผู้จ่ายไว้ล่วงหน้าได้ไหม หรือเลือกผู้จ่ายตอนเลื่อนเป็นเกิดจริง (story นี้ร่างไว้: ใส่ได้ แต่สร้างเงินที่ต้องคืนเมื่อเป็นเกิดจริงเท่านั้น) → **ใส่ผู้จ่ายล่วงหน้าได้** แต่เงินที่ต้องคืนเกิดเมื่อเป็น "เกิดจริง" เท่านั้น
