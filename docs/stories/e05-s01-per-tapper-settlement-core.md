## คำอธิบาย

เขียน `settle()` ใหม่ให้รวมยอด เข่ง → จุดชั่ง → คนกรีด → สวน → การขาย และแบ่งเงิน
ตามส่วนแบ่ง **รายคนกรีด** ที่มีผล ณ วันขาย แทนสัญญารายโซน ยังไม่ปัดเศษเป็นบาท
(อยู่ E05-S02) และยังไม่หักปุ๋ย (อยู่ E06-S04)

## Acceptance criteria

- [ ] ยอดรวม กก., จำนวนเข่ง และยอดเงิน = ราคา × กก. คำนวณได้ทุกระดับ เข่ง → จุดชั่ง → คนกรีด → สวน → การขาย (SET-1)
- [ ] ส่วนแบ่งเจ้าของ/คนกรีด ใช้ค่า MD-8 ที่มีผล ณ วันที่ขาย; ไม่มีค่าที่ตั้งไว้ = 50/50
- [ ] ผลรวมรายคนกรีดเท่ากับยอดการขายพอดีทุกสตางค์ (ไม่เกลี่ยจากยอดรวมกลับลงไป)
- [ ] เข่งที่ void และการขาย Cancelled ไม่ถูกนับ (SALE-20)
- [ ] ไม่มีราคา → ปฏิเสธการสรุปเงิน ไม่เดา
- [ ] เอา `zone_contract_set`, `basis` และ `perZone` ออกจาก `settle()` (D-12); ผลลัพธ์ยังเป็นขั้นตอนคำนวณทีละบรรทัด (derivation) ที่ตรวจด้วยมือได้
