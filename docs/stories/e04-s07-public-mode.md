## คำอธิบาย

แตะครั้งเดียวสลับเป็นจอให้ผู้ซื้ออ่าน: เลขเข่งใหญ่ที่สุดที่จอรองรับ หมุนเป็นแนวนอนได้

## Acceptance criteria

- [ ] แตะครั้งเดียวสลับ ผู้บันทึก ↔ สาธารณะ ทั้งสองทาง (SALE-15)
- [ ] แสดงเฉพาะเลขเข่งปัจจุบัน (เข่งที่กำลังชั่ง ตาม E04-S05) — ไม่มีชื่อจุดชั่ง/คนกรีด (อยู่แถบบนของโหมดผู้บันทึกเท่านั้น)
- [ ] เลขเข่งใหญ่ที่สุดเท่าที่จอรองรับ ทั้งแนวตั้งและแนวนอน; สี `numeral` ไม่ขยายตาม `textScale` (§12.10)
- [ ] หมุนเป็นแนวนอนได้เฉพาะโหมดนี้; โหมดผู้บันทึกคงแนวตั้ง (D-17)
- [ ] กดค้างบันทึกเข่งได้ในโหมดสาธารณะ เลขเปลี่ยนทันที
- [ ] ไม่มีเงา card บนจอสาธารณะ (§12.10 ข้อ 4)
- [ ] ตัวเลขนับใช้ Noto Sans Thai (E01-S13); ปรับเกณฑ์ rotate hint (`tokens.publicNumeral.minHeightRatio`, design-system §9) ใหม่จากการทดสอบในสวน บันทึกค่าที่วัดได้ใน Dev notes (D5)
