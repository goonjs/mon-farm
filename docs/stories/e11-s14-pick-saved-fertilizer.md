# Story: E11-S14 แตะปุ๋ยที่จำไว้แต่ยังไม่เคยซื้อ แล้วได้ชื่อนั้นเลย

Status: Review

## Context

- ต่อจาก `docs/stories/e11-s11-fertilizer-order.md` (FO-3)
- เจ้าของรายงาน 2026-11-04 (ภาพ 2 รูป ผ่าน lead): "เลือกรายการดีเกลือแล้ว มันไม่ขึ้น แต่ถ้าเลือกอันที่เคยใช้แล้วถึงจะขึ้น"

## สาเหตุ (ตรวจในโค้ดแล้ว)

"ซื้อปุ๋ยอะไร" แสดงสูตรที่จำไว้แต่ยังไม่เคยซื้อ ("จำสูตรไว้ · ยังไม่เคยซื้อ") ซึ่งยังไม่รู้ชนิดและขนาดกระสอบ แตะแล้วจึงเปิด "ปุ๋ยใหม่" ให้เลือก — แต่ `order-screen.tsx` เปิดแผ่นนั้นด้วยสูตรว่างเสมอ ชื่อที่แตะจึงหายไป

## Acceptance criteria

- [x] **PS-1** แตะสูตรที่จำไว้แต่ยังไม่เคยซื้อ → แผ่น "ปุ๋ยใหม่" เปิดพร้อมชื่อนั้นในช่อง "สูตร / ชื่อปุ๋ย" (ชนิด เคมี และ 50 กก. เลือกไว้ก่อนเหมือนเดิม แก้ได้)
- [x] **PS-2** กด "ใช้ปุ๋ยนี้" ทีเดียว → แผ่นรายการเปิดด้วยชื่อนั้น
- [x] **PS-3** ปุ๋ยที่เคยซื้อแล้วทำงานเหมือนเดิม (เข้าใบทันที พร้อมราคาครั้งก่อน)

ไม่เดาชนิด/ขนาดให้เอง เพราะสูตรที่ยังไม่เคยซื้อยังไม่มีข้อมูลนั้น
