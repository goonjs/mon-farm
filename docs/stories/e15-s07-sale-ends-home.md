## สิ่งที่เจอในแอปจริง (ลีด 4, 2026-11-18)

1. **เครื่องคิดเลข (S3) ไม่ขึ้นเลย** หน้าแรกยังเป็นตาชั่ง "กำลังชั่ง" ทั้งตอนอยู่หน้าสรุปและหลังติ๊กจ่ายแล้ว จนปิดการขาย · สาเหตุ: `salePhase` รอให้ไม่มีกองไหน "กำลังนับ" แต่ในแอปไม่มีหน้าไหนเขียน `pile_closed` (มีแค่ใน `src/core/fixtures.ts`) เทสต์ jest ผ่านเพราะใส่ข้อมูลนี้เอง
2. **กดปิดการขายแล้วไปหน้ารายการขาย** (`router.dismissTo('/v2/sales')`) ต้องกดกลับหน้าแรกเองถึงเห็น ✓
3. **ช่องเตรียมขายเหลือง "เหลือ 1 ข้อ" ข้าง ✓ เขียว** ตอนเตรียมไม่ครบแล้วเริ่มขายไปแล้ว ค้างทั้งวันแม้เคลียร์เงินครบ
4. **การขายก่อน 2026-11-01 ที่ยังไม่ติ๊กจ่าย** ไม่ขึ้น "เงินค้าง" (ตั้งใจไว้ใน E15-S06 `UNPAID_COUNTED_FROM`)
