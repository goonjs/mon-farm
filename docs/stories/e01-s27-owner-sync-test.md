## คำอธิบาย

ทุกอย่างของ E01-S09 ทดสอบกับ emulator เท่านั้น ยังไม่เคยลองกับฐานข้อมูลจริง (`(default)` ของ `mon-farmmate`, D-84) กับ Google
login จริง story นี้คือขั้นตอนที่เจ้าของทำเองบนเว็บ dev (`https://mon-farm-dev.web.app`) ด้วยเบราว์เซอร์ 2–3 ตัว ทีมไม่แตะฐานข้อมูลจริง
ไม่มีโค้ดใหม่ ผลที่ได้คือรายงานของเจ้าของว่าข้อไหนผ่าน/ไม่ผ่าน แล้วทีมแก้ใน story ของมันเอง

**ข้อจำกัดที่ต้องรู้ก่อนทดสอบ (เห็นจากโค้ดบน `dev` 2026-11-23):**

- ใช้ **บัญชี Google เดียวกัน** ทุกเบราว์เซอร์ — ระบบเชิญคนอื่นเข้ากลุ่ม (E02-S03) ยังไม่ได้ทำ
- **หน้าเงิน (ค่าใช้จ่าย, หนี้, ซื้อปุ๋ย, ปิดยอด) ยังไม่ sync** — อยู่ในเครื่องเท่านั้นจนกว่า E01-S28 เสร็จ อย่าใช้หน้าเงินทดสอบ
  (ป้ายสถานะบนหน้าเงินตอนนี้นับเฉพาะข้อมูลคน/การขาย ไม่ได้นับเงิน)
- เครื่องอื่นเห็นข้อมูลใหม่ **เมื่อเปิดแอป/โหลดหน้าใหม่, เน็ตกลับมา, หรือหลังเครื่องนั้นบันทึกอะไรเอง** — ยังไม่ฟังสด และสลับแท็บอย่างเดียวไม่ดึงข้อมูล
  ในขั้นด้านล่าง "โหลดใหม่" = กดปุ่มโหลดหน้าเว็บใหม่ (reload)
- ยังไม่มีปุ่ม "ลองใหม่" (E01-S10) และหน้าจอตัดสินข้อมูลขัดกัน (E01-S11)

## ขั้นตอนทดสอบ (สำหรับเจ้าของ)

เตรียม: เบราว์เซอร์ 2–3 ตัว เรียกว่า **A, B, C** (เช่น Chrome บนมือถือ = A, Chrome บนคอม = B, Edge หรือ Firefox บนคอม = C)
เปิด `https://mon-farm-dev.web.app` ทุกตัว ใช้บัญชี Google ตามคำตอบ S27-Q1 · ใช้เวลาราว 30–40 นาที

**ป้ายสถานะ** (`ซิงก์แล้ว` / `รอส่ง …` / `ส่งไม่สำเร็จ`) อยู่มุมขวาบนของ **หน้าแรก** และหน้าใน "ข้อมูลฟาร์ม" (เช่นหน้า "คน")
**หน้านับเข่งและหน้ารายการขายไม่มีป้ายนี้** — ถ้าขั้นไหนให้ดูป้าย ให้ดูที่หน้าแรกหรือหน้า "คน"

ถ้าขั้นไหนไม่ผ่าน (ทุกขั้นเหมือนกัน): **อย่าล้างข้อมูลเบราว์เซอร์ อย่า logout** กดกลับไปหน้าแรก ถ่ายรูปหน้าแรก (ที่มีป้ายสถานะมุมขวาบน)
จดเวลา แล้วบอก lead ในแชตว่า "ขั้นที่ N ไม่ผ่าน" ข้อมูลยังอยู่ในเครื่องนั้น ไม่หาย
ถ้าขั้น 1–3 ไม่ผ่าน หยุดแล้วบอก lead (ขั้นอื่นทำต่อไม่ได้) · ถ้าขั้น 4 ขึ้นไปไม่ผ่าน ทำขั้นถัดไปต่อได้

## Offline / sync behavior

ไม่มีโค้ดใหม่ ทดสอบพฤติกรรมของ E01-S09 ตามที่มีบน `dev`: outbox ในเครื่อง, ส่งเองเมื่อมีเน็ต, pull เมื่อเปิดแอป/เน็ตกลับ/หลังเขียน (ยังไม่มี listener สด),
