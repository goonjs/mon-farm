## คำอธิบาย

ทุกอย่างของ E01-S09 ทดสอบกับ emulator เท่านั้น ยังไม่เคยลองกับฐานข้อมูลจริง (`(default)` ของ `mon-farmmate`, D-84) กับ Google
login จริง story นี้คือขั้นตอนที่เจ้าของทำเองบนเว็บ dev (`https://mon-farm-dev.web.app`) ด้วยเบราว์เซอร์ 2–3 ตัว ทีมไม่แตะฐานข้อมูลจริง
ไม่มีโค้ดใหม่ ผลที่ได้คือรายงานของเจ้าของว่าข้อไหนผ่าน/ไม่ผ่าน แล้วทีมแก้ใน story ของมันเอง

**ข้อจำกัดที่ต้องรู้ก่อนทดสอบ (เห็นจากโค้ดบน `dev` 2026-11-23):**

- ใช้ **บัญชี Google เดียวกัน** ทุกเบราว์เซอร์ — ระบบเชิญคนอื่นเข้ากลุ่ม (E02-S03) ยังไม่ได้ทำ
- **หน้าเงิน (ค่าใช้จ่าย, หนี้, ซื้อปุ๋ย, ปิดยอด) ยังไม่ sync** — อยู่ในเครื่องเท่านั้นจนกว่า E01-S28 เสร็จ อย่าใช้หน้าเงินทดสอบ
  (ป้ายสถานะบนหน้าเงินตอนนี้นับเฉพาะข้อมูลคน/การขาย ไม่ได้นับเงิน)
- เครื่องอื่นเห็นข้อมูลใหม่ **เมื่อเปิดแอป/โหลดหน้าใหม่, เน็ตกลับมา, หรือหลังเครื่องนั้นบันทึกอะไรเอง** — ยังไม่ฟังสด และสลับแท็บอย่างเดียวไม่ดึงข้อมูล
  ในขั้นด้านล่าง "โหลดใหม่" = กดปุ่มโหลดหน้าเว็บใหม่ (reload)
- ยังไม่มีปุ่ม "ลองใหม่" (E01-S10) และหน้าจอตัดสินข้อมูลขัดกัน (E01-S11)

## ขั้นตอนทดสอบ (สำหรับเจ้าของ)

เตรียม: เบราว์เซอร์ 2–3 ตัว เรียกว่า **A, B, C** (เช่น มือถือ = A, คอม = B, อีกเบราว์เซอร์หรืออีกโปรไฟล์บนคอม = C)
ใช้บัญชี Google ตามคำตอบ S27-Q1 · ใช้เวลาราว 30–40 นาที

**รู้ก่อนเลือกเบราว์เซอร์: แอปไม่มีปุ่มออกจากระบบ (D-23)** เบราว์เซอร์ที่เคยเปิด `https://mon-farm-dev.web.app` แล้ว จะเข้ากลุ่มเดิมเองทุกครั้ง
ไม่ขึ้นหน้า login อีก และสลับไปบัญชีอื่นไม่ได้ แอปไม่แสดงชื่อบัญชีหรือชื่อกลุ่มบนหน้าแรก จึงต้องดูจากข้อมูลตามข้อ "เช็กก่อนบันทึก" ข้างล่าง

- **ถ้าตอบ S27-Q1 = ก (บัญชีทดสอบ):** A, B, C ต้องเป็นเบราว์เซอร์หรือโปรไฟล์ที่ **ยังไม่เคยเปิด** `mon-farm-dev.web.app` เลย
  - คอม (Chrome หรือ Edge): เพิ่มโปรไฟล์ใหม่ — กดรูปโปรไฟล์มุมขวาบนของเบราว์เซอร์ → "เพิ่ม" (Add) → เลือกใช้ต่อโดยไม่ลงชื่อเข้าใช้บัญชี →
    จะได้หน้าต่างใหม่ของโปรไฟล์นั้น เปิดเว็บในหน้าต่างนี้ (โปรไฟล์ใหม่มีข้อมูลเว็บแยกจากโปรไฟล์เดิมทั้งหมด) อยากได้ C บนคอมเครื่องเดียวกัน ก็เพิ่มอีกโปรไฟล์
  - มือถือ: Chrome บน Android ไม่มีโปรไฟล์ ถ้า Chrome บนมือถือเคยเปิดเว็บนี้แล้ว ใช้เบราว์เซอร์อีกตัวที่ยังไม่เคยเปิด (เช่น Firefox หรือ Samsung Internet)
  - **อย่าใช้หน้าต่างส่วนตัว / ไม่ระบุตัวตน (incognito / private):** พอปิดหน้าต่างส่วนตัวบานสุดท้าย เบราว์เซอร์ลบข้อมูลเว็บของมันทั้งหมด
    ทั้งการ login และข้อมูลที่ยังไม่ส่ง ขั้น 9–10 จะไม่ผ่านเองทั้งที่แอปไม่ผิด (บางเบราว์เซอร์อาจไม่เก็บไฟล์แอปไว้เปิดตอนไม่มีเน็ตในหน้าต่างส่วนตัวด้วย — ทีมยังไม่ได้ลอง)
  - **อย่าล้างข้อมูลเว็บของเบราว์เซอร์ที่ใช้กับฟาร์มจริง** เพื่อเอามาใช้ทดสอบ: ข้อมูลฟาร์มที่ยังไม่ส่งในเบราว์เซอร์นั้นจะหายถาวร (S27-AC5)
  - หลังทดสอบ เบราว์เซอร์/โปรไฟล์เหล่านี้อยู่กับบัญชีทดสอบตลอด เก็บไว้ใช้ทดสอบรอบหน้า และอย่าใช้บันทึกงานฟาร์มจริง
  - ตอนกด "เข้าสู่ระบบด้วย Google" ถ้า Google เสนอบัญชีจริง ให้กด "ใช้บัญชีอื่น" แล้วเลือกบัญชีทดสอบ
- **ถ้าตอบ ข (บัญชีจริง):** ใช้เบราว์เซอร์ที่เปิดฟาร์มจริงอยู่แล้วได้ เบราว์เซอร์แบบนี้ไม่ขึ้นหน้า login เปิดเว็บแล้วเข้าหน้าแรกของกลุ่มจริงเลย
  (ขั้น 1, 3 และ "C login" ในขั้น 7 จึงหมายถึงเปิดเว็บแล้วเห็นหน้าแรก) เบราว์เซอร์ที่ยังไม่เคยเปิด ให้ login ด้วยบัญชีจริง ห้ามสร้างกลุ่มใหม่

**เช็กก่อนบันทึก (ทุกเบราว์เซอร์ ก่อนเพิ่มอะไรครั้งแรก):**

- ตอบ ก: เปิดเว็บแล้ว **ต้องเห็นหน้า "เข้าสู่ระบบด้วย Google" ก่อน** ถ้าเข้าหน้าแรกเลยโดยไม่ถาม แปลว่าเบราว์เซอร์นี้อยู่กับบัญชีอื่นแล้ว
  → **หยุด อย่าบันทึกอะไร** ใช้เบราว์เซอร์/โปรไฟล์อื่น · หลัง login เปิดหน้า "คน" (ใน "ข้อมูลฟาร์ม"): A ครั้งแรกต้องว่าง, B และ C ต้องเห็นเฉพาะคน `ทดสอบ …`
  ถ้าเห็นคนกรีดของฟาร์มจริง → หยุด อย่าบันทึก แล้วบอก lead
- ตอบ ข: หน้า "คน" ต้องเห็นคนกรีดของฟาร์มจริง ถ้าว่าง แปลว่าเข้าผิดกลุ่ม → หยุด แล้วบอก lead

**ป้ายสถานะ** (`ซิงก์แล้ว` / `รอส่ง …` / `ส่งไม่สำเร็จ`) อยู่มุมขวาบนของ **หน้าแรก** และหน้าใน "ข้อมูลฟาร์ม" (เช่นหน้า "คน")
**หน้านับเข่งและหน้ารายการขายไม่มีป้ายนี้** — ถ้าขั้นไหนให้ดูป้าย ให้ดูที่หน้าแรกหรือหน้า "คน"

ถ้าขั้นไหนไม่ผ่าน (ทุกขั้นเหมือนกัน): **อย่าล้างข้อมูลเว็บ (cache / site data) และอย่าปิดหน้าต่างส่วนตัวถ้าเผลอใช้** กดกลับไปหน้าแรก ถ่ายรูปหน้าแรก (ที่มีป้ายสถานะมุมขวาบน)
จดเวลา แล้วบอก lead ในแชตว่า "ขั้นที่ N ไม่ผ่าน" ข้อมูลยังอยู่ในเครื่องนั้น ไม่หาย

## Offline / sync behavior

ไม่มีโค้ดใหม่ ทดสอบพฤติกรรมของ E01-S09 ตามที่มีบน `dev`: outbox ในเครื่อง, ส่งเองเมื่อมีเน็ต, pull เมื่อเปิดแอป/เน็ตกลับ/หลังเขียน (ยังไม่มี listener สด),
create-only + id ไม่ซ้ำ → ส่งซ้ำได้ปลอดภัย ข้อมูลทดสอบเขียนลง `(default)` ซึ่งใช้เป็น dev (D-84) — เป็น environment dev ตามกฎ ไม่ใช่ prod

**S27-Q1 — ทดสอบในกลุ่มไหน**

- **ก (แนะนำ)** ใช้บัญชี Google อีกบัญชี (บัญชีทดสอบ) สร้างกลุ่มใหม่ชื่อ "ทดสอบ sync" แล้ว login บัญชีนั้นทุกเบราว์เซอร์ — ข้อมูลทดสอบไม่ปนกับฟาร์มจริง
  เก็บกลุ่มไว้ใช้ทดสอบรอบหน้าได้ (แอปยังสลับกลุ่มไม่ได้ E02-S04 จึงใช้บัญชีแยกแทน)
  ราคา: ต้องใช้เบราว์เซอร์หรือโปรไฟล์ Chrome ที่ยังไม่เคยเปิดแอป (ไม่ใช่หน้าต่างส่วนตัว) และเบราว์เซอร์นั้นจะอยู่กับบัญชีทดสอบตลอด
  เพราะแอปยังไม่มีปุ่มออกจากระบบ (D-23) — วิธีทำอยู่ในหัวข้อ "รู้ก่อนเลือกเบราว์เซอร์" ข้างบน
- **ข** ใช้บัญชีจริงและกลุ่มฟาร์มจริง แล้วลบคน `ทดสอบ …` และการขายทดสอบออกหลังทดสอบ — ใช้เบราว์เซอร์ที่เปิดฟาร์มจริงอยู่แล้วได้เลย
  ไม่ต้องเตรียมโปรไฟล์ แต่ข้อมูลทดสอบอยู่ในประวัติกลุ่มจริงตลอด (ลบคือซ่อน ไม่ได้ลบจริง, E01-S04) และการขายทดสอบ 25 เข่ง (ขั้น 8)
  อยู่ในกลุ่มจริงจนกว่าจะลบ
