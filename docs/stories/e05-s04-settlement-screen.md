## Acceptance criteria

- [ ] การ์ดคนกรีดแต่ละคน: กก., ยอดขาย, ส่วนแบ่งคนกรีด, หักหนี้, ส่วนปรับปัดเศษ, **เงินสดที่ต้องจ่าย** (SET-4) — เรียงตามลำดับคำนวณ: ปัดเศษหลังหักหนี้ (D-60)
- [ ] การ์ดเจ้าของ: ส่วนแบ่งจากคนกรีดแต่ละคน, ส่วนแบ่งรวม, **โอนเข้าบัญชีธนาคาร** (SET-4); บัญชีปลายทางไม่บังคับ (D-38 — การตั้งค่าบัญชีรับเงินเป็น story candidate ใน E05)
- [ ] เงินสดที่ต้องจ่ายเป็นตัวเลขเด่นที่สุดของการ์ดคนกรีด; ไม่ติดลบ (FERT-6)
- [ ] แตะตัวเลขใดก็ได้ → เห็นขั้นตอนคำนวณจนถึงจุดชั่ง/เข่ง
- [ ] ก่อน E06-S04 พร้อม บรรทัดหักหนี้แสดง 0 และไม่มีฟอร์มหักเงินแบบ S29 (ปุ่ม "หักเงินคืนหนี้" ที่หน้า 17 มาพร้อม E06-S04)
