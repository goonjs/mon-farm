## Acceptance criteria

- [ ] การ์ดคนกรีดแต่ละคน: กก., ยอดขาย, ส่วนแบ่งคนกรีด, หักค่าปุ๋ย, ส่วนปรับปัดเศษ, **เงินสดที่ต้องจ่าย** (SET-4)

- [ ] แตะตัวเลขใดก็ได้ → เห็นขั้นตอนคำนวณจนถึงจุดชั่ง/เข่ง
