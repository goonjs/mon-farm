# Story E01-S23: ติดตั้งเว็บแอปบนโทรศัพท์ และเปิดได้ตอนไม่มีเน็ต (PWA)

Status: Ready (เจ้าของ 2026-11-16 ผ่านลีด คำต่อคำ: "อยากไปที่ Android สักทีแล้วก็บิวมาใช้…ใช้ได้ทั้ง PWA แล้วก็ Android" · ลีดจัดเป็นงานข้อ 6 คู่กับ E01-S06)

## Context

- Epic: `docs/epics/e01-foundation-sync.md` (offline-first: ใช้ได้เต็มที่ตอนไม่มีเน็ต)

- ไอคอน: ภาพ "กรีดยาง" ตัวเดียวกับ favicon ค่าเริ่มต้น (E03-S10)

## Description

ตอนนี้เว็บแอปเพิ่มไปหน้าจอโฮมแบบแอปไม่ได้ และถ้าปิดเบราว์เซอร์แล้วเปิดใหม่ตอนไม่มีเน็ต หน้าแอปไม่ขึ้น ทั้งที่ข้อมูลอยู่ในเครื่อง สตอรี่นี้ทำให้ติดตั้งได้ (manifest + ไอคอน) และเปิดได้ตอนออฟไลน์ (service worker แคชไฟล์ของแอป) โดยไม่ลง package ใหม่

## Acceptance criteria

- [ ] **PW-1** มี web app manifest: ชื่อ mon-farm · เปิดที่หน้าแรก `/v2` · แสดงแบบแอป (standalone) แนวตั้ง · ไอคอน 192 และ 512 px (ภาพกรีดยาง พื้นขาว) · Chrome บน Android ขึ้น "ติดตั้งแอป" ได้
- [ ] **PW-2** เปิดแอปครั้งหนึ่งตอนมีเน็ตแล้ว ปิด แล้วเปิดใหม่ตอนไม่มีเน็ต หน้าแรกขึ้นพร้อมข้อมูลในเครื่อง
- [ ] **PW-3** มีเน็ตเมื่อไหร่ได้เวอร์ชันใหม่ล่าสุดเสมอ (ไม่ค้างเวอร์ชันเก่าจากแคช)
- [ ] **PW-4** ไม่ลง package ใหม่ · ไม่แตะข้อมูลหรือ event

## Offline / sync behavior

- service worker: หน้าเว็บโหลดจากเน็ตก่อน ไม่ได้ค่อยใช้แคช (ได้ของใหม่เสมอเมื่อออนไลน์) · ไฟล์ `/_expo/static/` ชื่อมี hash ใช้แคชก่อน · ข้อมูลและการซิงก์ไม่เปลี่ยน
