## Dev notes

- ไม่มี package ใหม่: `public/manifest.webmanifest`, `public/sw.js` (เขียนเอง), ไอคอน `public/icons/icon-{192,512}.png` เรนเดอร์จาก `design/icons/farmmate/farmwork.tapping.svg` ด้วย Chromium ที่มีอยู่ (พื้นขาว ขอบ 20% ให้อยู่ในวง maskable) · `expo export` คัดลอก `public/` ไปที่ราก `dist/`
- ลงทะเบียนใน `src/app/+html.tsx` · ครั้งแรกที่เปิด ไฟล์ bundle/ฟอนต์โหลดก่อนที่ worker จะคุมหน้า หน้าจึงส่งรายการไฟล์ที่โหลดแล้วให้ worker เก็บ (ไม่งั้นเปิดออฟไลน์ครั้งแรกจะค้างที่ splash)
- `firebase.json` ไม่ต้องแก้: เบราว์เซอร์เช็ก `sw.js` ใหม่โดยไม่ใช้ HTTP cache อยู่แล้ว
