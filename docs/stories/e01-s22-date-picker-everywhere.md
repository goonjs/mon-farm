## Description

สำรวจแอป v2 (2026-11-15) พบช่องวันที่ที่ยังต้องพิมพ์เอง 8 จุด: 4 จุดพิมพ์แบบ ปปปป-ดด-วว (บันทึกการคืน, เพิ่มหนี้, บันทึกจ่ายคืน, ค่าใช้จ่าย → เพิ่มรายละเอียด) และ 4 จุดพิมพ์แบบ ว/ด/ปปปป พ.ศ. (เปลี่ยนพื้นที่สวน, ส่วนแบ่ง, วางแผนคนกรีด วันเริ่ม และ วันสุดท้าย) · สตอรี่นี้เปลี่ยนทั้ง 8 จุดเป็นแถวเลือกวันที่หน้าตาเดียวกัน (ไอคอนปฏิทิน ป้าย วันที่ตัวหนา ›) แตะแล้วเปิดตัวเลือกวันตัวเดิม ไม่ต้องพิมพ์ · ข้อมูลที่บันทึกเหมือนเดิมทุกจุด

## Acceptance criteria

- [ ] **DP-1** ทั้ง 8 จุดไม่มีช่องพิมพ์วันที่แล้ว ใช้แถวเลือกวัน (`DateField`): ป้ายของช่องเดิม · ไอคอนปฏิทิน · วันที่ตามยุคที่ผู้ใช้เลือก (พ.ศ./ค.ศ.) ตัวหนา · › · แตะทั้งแถวเปิดตัวเลือกวัน
- [ ] **DP-2** ช่องที่ว่างได้ (วันเริ่มของจุดกรีดที่ยังไม่มีคนกรีด) มีตัวเลือก "ไม่ระบุวันเริ่ม" ในตัวเลือกวัน และแถวบอกว่ายังไม่ระบุ
- [ ] **DP-3** ตัวเลือกวันเลื่อนทีละปีได้ (สำหรับหนี้ยกมาหรือวันเก่า) นอกจากทีละเดือน
- [ ] **DP-4** ช่วงวันที่: ค่าเริ่มต้น **ไม่จำกัด** ตามคำเจ้าของ · กฎที่มีอยู่เดิม (เช่น ส่วนแบ่งต้องหลังวันขายที่ปิดแล้ว, วันสุดท้ายต้องอยู่ในช่วงของคนกรีด) ยังทำงานเหมือนเดิมเป็นข้อความผิดพลาด · ช่วงที่เลือกได้ตามคำตอบ Q1–Q6 ด้านล่าง: คืนเงินและจ่ายคืนหนี้เลือกได้ถึงวันนี้ · ค่าใช้จ่ายเกิดจริงและค้างจ่ายเลือกได้ถึงวันนี้ (ตอนบันทึกถ้าวันอยู่ในอนาคตขึ้น "วันที่ยังไม่ถึง เลือกวันใหม่") วางแผนเลือกอนาคตได้ · ที่เหลือไม่จำกัด
- [ ] **DP-5** ตัวเลือกวันที่ใช้อยู่แล้ว 2 จุดที่ยังไม่มี › (การ์ดวันที่ซื้อในใบซื้อ ทำแล้วใน E01-S21 · แถววันที่ในแก้หัวใบ) หน้าตาเหมือนแถวเลือกวันอื่น
- [ ] **DP-6** ทุกจุด: แตะได้ ≥ 48 · ไม่มีอะไรถูกตัดที่ 320 และ 360 px ตัวอักษรกลางและใหญ่ · ข้อมูลที่บันทึก (ISO หรือวันที่ของแบบฟอร์ม พ.ศ.) เหมือนเดิม

## คำถามเจ้าของ (ตอบแล้ว 2026-11-16 00:09 บนแดชบอร์ด ผ่านลีด คำต่อคำ)

- Q1 คืนเงิน / จ่ายคืนหนี้: ห้ามวันในอนาคตไหม → "ก · ห้ามอนาคต (เลือกได้ถึงวันนี้)"
- Q2 เพิ่มหนี้: ห้ามวันในอนาคตไหม (หนี้ยกมาเก่าได้) → "ข · ไม่จำกัด"
- Q3 ค่าใช้จ่าย: เกิดจริง ห้ามอนาคต (เหมือนใบซื้อ) · วางแผน เลือกอนาคตได้ — ใช่ไหม → "ก · ใช่ ตามนั้น" · ถามต่อ → "1 ก 2 ก" ข้อ 2 ก: ค้างจ่ายก็ห้ามอนาคต และตอนบันทึก ถ้าเกิดจริงหรือค้างจ่ายแต่วันอยู่ในอนาคต ให้บอกให้เลือกวันใหม่
- Q4 ส่วนแบ่ง: ทำกฎเดิม "หลังวันขายที่ปิดแล้ว" เป็นวันแรกที่เลือกได้ในตัวเลือกวัน — โอเคไหม → "ข · ไม่จำกัด" (ตัวเลือกวันไม่มี `min`) · ถามต่อเรื่องกฎตอนบันทึก "หลังวันขายที่ปิดแล้ว" → เจ้าของ 2026-11-16 ในแชตกับลีด คำต่อคำ "1 ก 2 ก" = ข้อ 1 ก: คงกฎตอนบันทึกไว้
- Q5 วางแผนคนกรีด: ทำกฎเดิมเป็นช่วงที่เลือกได้ — โอเคไหม → "ก · คงกฎเดิม" (กฎขึ้นกับช่วงของคนกรีดแต่ละคน จึงคงเป็นข้อความตอนบันทึกเหมือนเดิม ไม่ใส่ช่วงในตัวเลือกวัน)
- Q6 เปลี่ยนพื้นที่ "มีผลตั้งแต่": อนาคตได้ ไม่จำกัด — ใช่ไหม → "ก · ใช่ ไม่จำกัด"

## Dev notes

- `DateField` (src/ui/date-field.tsx) เป็นแถวเลือกวัน + `DatePickerSheet` ในตัว · เปิดซ้อนบนชีตได้ (React Native Web Modal ซ้อนกัน) ไม่ต้องซ่อนชีตแม่ · ทดสอบใน e2e v2-money
- ช่อง พ.ศ. 4 จุด เก็บค่าเป็นข้อความ ว/ด/ปปปป เหมือนเดิม (parseThaiDay/thaiDayInput) การตรวจและข้อมูลที่บันทึกไม่เปลี่ยน
- ชีตเปลี่ยนพื้นที่: เดิมซ่อนแป้นตัวเลขตอนพิมพ์วันที่ (`typingDate`) ตอนนี้ไม่มีการพิมพ์ แป้นแสดงตลอด
- ข้อความผิดพลาด "ใส่วันที่เป็น ปปปป-ดด-วว" เปลี่ยนเป็น "เลือกวันที่" · ป้ายวันเริ่ม/วันสุดท้ายเลิกบอกรูปแบบการพิมพ์ · ลบ `v2f.dateHint`
- ตัวเลือกวัน: ชื่อเดือนอยู่บรรทัดบน ปุ่ม «‹ ›» บรรทัดล่าง (เดิมที่ 320 ตัวใหญ่ล้นจอเมื่อมี 4 ปุ่ม)
- รวมงานจากรีวิว #193 (ลีดสั่ง 2026-11-15 ให้รวมใน PR นี้): การ์ดร้าน/วันที่ในใบซื้อเรียงบรรทัดละใบ · ตัดประโยค "แตะสลับ พ.ศ./ค.ศ." ในแถววันที่หน้าเริ่มการขาย (แตะวันที่ยังสลับยุคได้ เหมือนวันที่อื่นทั้งแอป) · แก้คำ ▾ ใน design-system · e2e guard ใน v2-money
- `min` และ `emptyLabel` เป็นความสามารถใหม่ของตัวเลือกวัน · `min` ยังไม่ได้ใส่ที่จุดไหน (Q4 ข ไม่จำกัด, Q5 ก คงกฎเดิม) · `max` = วันนี้ ที่คืนเงิน จ่ายคืนหนี้ และค่าใช้จ่ายที่ไม่ใช่วางแผน · `checkExpense(f, today)` คืน `date-future` สำหรับเกิดจริง/ค้างจ่ายที่วันเกินวันนี้
