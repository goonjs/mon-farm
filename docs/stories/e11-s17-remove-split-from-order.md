## ทำไม (เจ้าของ 2026-11-06)

หน้าบันทึกรายจ่ายค่าปุ๋ยเหลือแค่บันทึกต่อใบสั่งซื้อ การแบ่งคนกรีดและใส่โซนไหนเพราะอะไรย้ายไปการดูแลสวน การแบ่งที่เคยทำไว้บนใบซื้อ "ไม่เอาแล้ว ลบทิ้งได้เลย" โค้ดยกไปใช้ใน E16

## Acceptance criteria (ร่าง)

- [ ] **RM-1** รายการปุ๋ยในใบซื้อไม่มีปุ่ม เหตุผล / ใส่ที่ไหน / คนกรีด · ไม่มีแถบ "บอกแล้ว X จาก N" · ใบซื้อที่ได้ของแล้วมีลิงก์รอง "ใส่ปุ๋ยจากใบนี้ ›" ไปหน้าใส่ปุ๋ย (E16-S02) โดยเลือกปุ๋ยของใบนี้ไว้ให้
- [ ] **RM-2** หน้าจอที่ยกไปใช้ใน E16 (sheet เหตุผล โซน คนกรีด) ย้ายโค้ด ไม่ทำซ้ำสองชุด
- [ ] **RM-3** **ข้อมูลเดิม**: การแบ่ง โซน เหตุผลบนรายการปุ๋ยในใบซื้อ (`expense.share`, `expense.fertilizer.zones/reasons` ของหมวดปุ๋ย) **ไม่ถูกอ่านอีก** — ไม่สร้างหนี้ ไม่นับเป็นใช้ออก ไม่แสดง · event เดิมไม่ถูกแก้หรือลบ (event log ต่อท้ายอย่างเดียว) แค่ projection หยุดอ่าน
- [ ] **RM-4** ❓ หนี้ปุ๋ยเดิมที่ **หักไปแล้ว** ในการขายที่ปิดแล้ว: เมื่อหนี้ต้นทางหายไป ยอดที่หักไปจะเกินยอดหนี้ (ธงหักเกิน D-61 หรือยอดติดลบ) — **รอเจ้าของ** (ประเด็นค้าง ข้อ 1)
- [ ] **RM-4b** ก่อน merge: ทีม dev รายงานบนฐาน `(default)` (ใช้เป็น dev, D-84) ว่ามีรายการปุ๋ยกี่รายการที่มีการแบ่งเดิม และหนี้คนกรีดยอดเท่าไรจะหายจากยอดค้าง — แจ้งผ่าน lead ให้เจ้าของเห็นก่อน ack
- [ ] **RM-5** การแบ่งค่าใช้จ่ายหมวดอื่น (ไม่ใช่ปุ๋ย) ให้คนกรีด (E11-S10 ส่วน B, `share-sheet.tsx`) **คงเดิม** ไม่อยู่ในสตอรี่นี้
- [ ] **RM-6** หน้าบัญชีหนี้ไม่มีก้อน "ค่าปุ๋ยจากใบซื้อ" อีก มีแต่ก้อน "ใส่ปุ๋ย {วันที่}" (E16-S03) และหนี้อื่น

## ประเด็นค้าง (ยังไม่ได้ถามเจ้าของ)

1. ❓ หนี้ปุ๋ยจากการแบ่งบนใบซื้อเดิมที่หักไปแล้วบางส่วน ทำอย่างไร: (ก) เก็บก้อนเดิมไว้เป็น "หนี้ปุ๋ยแบบเดิม" อ่านอย่างเดียว ไม่ให้แบ่งเพิ่ม — แนะนำ ถ้ามีการหักไปแล้ว (ข) ลบทั้งหมด ส่วนที่หักไปแล้วกลายเป็นเครดิตคืนคนกรีด (ค) ถ้า RM-4b รายงานว่าไม่มีการหักจริง ลบทั้งหมดได้เลย ไม่ต้องเลือก
