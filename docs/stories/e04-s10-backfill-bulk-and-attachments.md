## คำอธิบาย

ใส่การชั่งที่ไม่ได้บันทึกสด (เช่น โน้ตกระดาษของอาจารย์สมหวัง) เป็นยอดรวมต่อจุดชั่ง
และแนบรูปกองยาง ใบชั่ง หลักฐานเงิน กับการขายหรือจุดชั่ง

## Acceptance criteria

- [ ] บันทึกรวมต่อจุดชั่ง: เข่งเต็ม N เข่ง + เศษ กก.; แอปกำหนดเลขเข่งต่อเนื่องให้ (SALE-18, SALE-10)
- [ ] เข่งจากบันทึกรวมติดป้าย "บันทึกย้อนหลัง" ทุกที่ที่แสดง (SALE-18)
- [ ] แนบรูปกระดาษกับบันทึกรวมได้ (SALE-18)
- [ ] แนบรูป/เอกสารกับการขาย หรือกับจุดชั่งในการขายได้ (SALE-19, SALE-2)
- [ ] ยอดรวมจากบันทึกรวมเข้ายอดจุดชั่ง/คนกรีด/การขาย เหมือนเข่งปกติ

## Offline / sync
