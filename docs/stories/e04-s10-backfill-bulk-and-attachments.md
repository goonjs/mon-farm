## คำอธิบาย

ใส่การชั่งที่ไม่ได้บันทึกสด (เช่น โน้ตกระดาษของอาจารย์สมหวัง) เป็นยอดรวมต่อจุดชั่ง
และแนบรูปกองยาง ใบชั่ง หลักฐานเงิน กับการขายหรือจุดชั่ง

## Acceptance criteria

- [ ] บันทึกย้อนหลังใช้ flow เดียวกับการชั่งต่อจุดชั่ง (สวน → คนกรีด → จุดชั่ง) ต่างแค่หน้าจอ: ใส่ตัวเลขเองแทนการกดค้างนับเข่งและการแสดงเข่งปัจจุบัน (SALE-18, D-49)
- [ ] บันทึกรวมต่อจุดชั่ง: เข่งเต็ม N เข่ง + เศษ กก.; แอปกำหนดเลขเข่งให้ตามโหมดเลขเข่งของการขาย (SALE-18, SALE-10, D-46)
- [ ] เข่งจากบันทึกรวมติดป้าย "บันทึกย้อนหลัง" ทุกที่ที่แสดง (SALE-18)
- [ ] แนบรูปกระดาษกับบันทึกรวมได้ (SALE-18)
- [ ] ขั้นแนบรูปของบันทึกรวม: เสนอประเภทรูปแนะนำก่อน — โน้ตกระดาษ / ใบชั่ง-สลิปผู้ซื้อ / หน้าตาชั่ง / กองยาง / สลิปโอน (เจ้าของยืนยัน 2026-10-03) + "รูปอื่น" ใส่ caption ได้; ทุกรูปไม่บังคับ
- [ ] ทุกคนในกลุ่มแนบ/ดูรูปได้เท่ากันใน MVP
- [ ] แนบรูป/เอกสารกับการขาย หรือกับจุดชั่งในการขายได้ (SALE-19, SALE-2)
- [ ] ยอดรวมจากบันทึกรวมเข้ายอดจุดชั่ง/คนกรีด/การขาย เหมือนเข่งปกติ
