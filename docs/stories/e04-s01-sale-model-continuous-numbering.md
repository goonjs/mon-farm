## คำอธิบาย

เปลี่ยนแกนของการขาย (core อย่างเดียว ยังไม่แตะ UI): การขายหนึ่งครั้งชั่งได้หลายจุดหลายสวน ลำดับใดก็ได้
และทุกเข่งได้เลขต่อเนื่องเลขเดียวทั้งการขาย

## Acceptance criteria

- [ ] การขายบันทึกเข่งที่จุดชั่งใดก็ได้ หลายสวน ลำดับใดก็ได้ ไม่ต้องประกาศจุดล่วงหน้า (SALE-1, D-9)
- [ ] เลขเข่งกำหนดอัตโนมัติ ต่อเนื่องข้ามจุดชั่งและสวน ไม่เริ่มใหม่ต่อจุด; เลขเก็บอยู่ใน event ของเข่ง (SALE-10)
- [ ] ทุกเข่ง (หรือส่วนของเข่ง) ผูกกับจุดชั่งเดียว → คนกรีดคนเดียว ตามการมอบหมาย ณ วันขาย (SALE-4)
- [ ] ยอดรวมต่อจุดชั่ง / คนกรีด / สวน / การขาย เป็นกรัมจำนวนเต็ม และรวมกันลงตัว (NFR-3)
- [ ] เข่งเก็บ snapshot น้ำหนักสุทธิและ tare ณ ตอนบันทึก (คงหลักการ S3)
- [ ] `src/core` ยังไม่ import react / expo (คงกฎเดิม)
