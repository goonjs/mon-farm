## คำอธิบาย

เปลี่ยนแกนของการขาย (core อย่างเดียว ยังไม่แตะ UI): การขายหนึ่งครั้งชั่งได้หลายจุดหลายสวน ลำดับใดก็ได้
และทุกเข่งได้เลขอัตโนมัติ — ต่อเนื่องทั้งการขาย (โหมด a) หรือนับแยกต่อจุดชั่งเริ่มที่ 1 (โหมด b) (D-46)

- [ ] โหมดเลขเข่งของการขาย (SALE-10, D-46):
  - (a) ต่อเนื่องทั้งการขาย — ต่อเนื่องข้ามจุดชั่งและสวน ไม่เริ่มใหม่ต่อจุด
  - (b) **นับแยกต่อคนกรีดยาง** (D-79 แทน D-46) — คนกรีดยางแต่ละคนเริ่มที่เข่ง 1 และนับต่อข้ามจุดของตัวเอง; ระบุเข่งด้วย (คนกรีดยาง, เลข); คำบนจอ "เริ่มเข่ง 1 ตามคนกรีดยาง"
  - ยอดรวมต่อจุด / คนกรีด / สวน / การขาย ได้ค่าเดียวกันทั้งสองโหมด (สรุปเงินใช้น้ำหนักรวม)
  - เลือกโหมดตอนเริ่มการขาย ค่าเริ่มต้นมาจากตั้งค่ากลุ่ม (D-53)
- [ ] ทุกเข่ง (หรือส่วนของเข่ง) ผูกกับจุดชั่งเดียว → คนกรีดคนเดียว ตามการมอบหมาย ณ วันขาย (SALE-4)
- [ ] ยอดรวมต่อจุดชั่ง / คนกรีด / สวน / การขาย เป็นกรัมจำนวนเต็ม และรวมกันลงตัว (NFR-3)
- [ ] เข่งเก็บ snapshot น้ำหนักสุทธิและ tare ณ ตอนบันทึก (คงหลักการ S3)
