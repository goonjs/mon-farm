Design System เราตามความหมายของเรานะแล้วก็แต่ถ้าจ่ายครบแล้วก็ขึ้นสีไม่ใช่ขึ้นสีขอโทษเจ้าไอคอนนั้นก็จะเปลี่ยนเป็นเครื่องหมายติ๊กถูกโอเคคุณลองย่อยกลับมาเป็นข้อแตกเป็น state machine หรืออะไรที่เข้าใจง่ายเพื่อบันทึกลงในสตอรี่ให้เรียบร้อยด้วยนะแล้วก็สำหรับถ้ามีการย้อนกลับในแต่ละจุดก็อย่าลืมเปลี่ยนสเตทและไอคอนกลับด้วยเผื่อมีคำถามเผื่อผมคิดว่าคุณอาจจะถามว่าแล้วเมื่อไหร่ที่ปุ่มเตรียมขายกับปุ่มเริ่มการขายจะถูกเอาสีออกนะโอเคก็ปุ่มเตรียมขายจะถูกเอาออกเมื่อการขายที่เกี่ยวข้องปิดจบสมบูรณ์นะคำว่าปิดจบสมบูรณ์คืออะไรคำว่าปิดจบสมบูรณ์คือปิดการขายแล้วเคลียร์ยอดเงินแล้วเช็คติ๊กถูกแล้วจนจบวันนั้นนะจนจบวันนะแปลว่าจะแสดงอยู่จนจบวันแต่ถ้ายังมียอดเงินเคลียร์ไม่ครบไม่ว่าจะกี่วันก็ยังต้องขึ้นคาอยู่โอเคนะอันนี้จะเป็นการเพื่อให้เคลียร์เงินให้เรียบร้อยแต่คุณน่าจะมีคำถามถัดมาแล้วถ้าเกิดเงินไม่สามารถเคลียร์ได้จริงๆจะเกิดอะไรขึ้นโอเคสำหรับกรณีนั้นถ้าเรากดเตรียมการขายใหม่ในขณะที่เป็นวันใหม่ไปแล้วอยู่ในสเตจที่บอกที่ไม่ได้เคลียร์เงินจริงๆจะให้ถามว่าจะเตรียมการขายใหม่ครั้งใหม่หรือไม่หรือถ้าไม่ใช่ก็คือแค่เปิดดูเหมือนเดิมโอเคนะมีคำถามอะไรถามมาได้เลยตอนนี้

### รอบ 3 — เจ้าของยืนยัน 3 จุด (dashboard answers/home-tiles-day, 2026-11-17 23:51) คำต่อคำ:

> ก · ก · ตกลงทั้ง 3 จุด (แนะนำ)

3 จุดคือ: (1) "วัน" = เที่ยงคืนเวลาไทย · (2) การเตรียมของวันขายล่วงหน้าไม่ถูกล้างจนวันขายนั้นผ่านไป · (3) การขายที่ยังไม่จบไปอยู่ในแถว "การขายที่ยังไม่ปิด" ของบล็อก "ควรรู้ / ควรจัดการ" ที่มีอยู่ ไม่มีรายการที่สอง

## State machine ของปุ่ม (ร่าง ตามคำเจ้าของข้างบน)

กฎสี: **เหลือง** = ยังไม่ครบ · **ฟ้า** = เชิญชวนให้ทำ/กำลังทำ · **เขียว** = สมบูรณ์ · **แดง** = ยังมีเงินค้าง · มุมบนขวาเป็นไอคอนหรือตัวเลขเสมอ (ป้ายลอย ปุ่มไม่ขยับ ไม่เพิ่มบรรทัด) · ทุกสถานะคำนวณจากข้อมูลทุกครั้ง ไม่เก็บซ้ำ → ย้อนกลับจุดไหน สถานะ สีและไอคอนก็ย้อนตามเอง

**ปุ่มเตรียมขาย**

| สถานะ | เมื่อไหร่ | สีปุ่ม | มุมบนขวา |
|---|---|---|---|
| P0 ว่าง | ยังไม่ได้เริ่มเตรียม | ปกติ | ไม่มี |
| P1 ไม่ครบ | เริ่มเตรียมแล้ว เหลือ N ข้อ | เหลือง | ตัวเลข N |
| P2 ครบ | ครบ 4 ข้อ | เขียว | ✓ |

P2 คงอยู่ตลอดการขายที่เกี่ยวข้อง จนกลับเป็น P0 ตามกฎ "เมื่อไหร่สีหาย" ด้านล่าง

**ปุ่มเริ่มการขาย**

| สถานะ | เมื่อไหร่ | สีปุ่ม | มุมบนขวา |
|---|---|---|---|
| S0 ปกติ | ยังไม่มีการเตรียมครบ ไม่มีการขายเปิดอยู่ | ปกติ | ไม่มี |
| S1 เชิญชวน | P2 และยังไม่เริ่มการขาย (ถึงวันนัดแล้วก็ยังเป็นสถานะนี้) | ฟ้า | ⏳ นาฬิกาทราย |
| S2 กำลังนับ | การขายเปิดอยู่ ยังนับยางอยู่ | ฟ้า | ตาชั่ง |
| S3 รอเคลียร์เงิน | นับครบ เลือกคนกรีดครบ ถึงขั้นเคลียร์เงิน (หน้าสรุป) | ฟ้า | เครื่องคิดเลข |
| S4 ปิดแล้ว มีกองเงินค้าง | ปิดการขายแล้ว ยังเหลือ n กองที่ต้องจ่าย | เขียว | ตัวเลข n สีแดง (แตะ = หน้าเคลียร์เงินสุดท้าย ดูว่าจ่ายแล้วเท่าไหร่) |
| S5 จบสมบูรณ์ | ปิดการขาย + เคลียร์เงินครบทุกกอง (ติ๊กถูกครบ) | เขียว | ✓ |

**เมื่อไหร่สีหาย และของค้าง (แก้รอบ 2 ตามคำเจ้าของ 2026-11-17 23:47 ข้างบน — แทนกฎ "ค้างกี่วันก็ได้" และคำถามกดเตรียมใหม่)**
- ปุ่มทั้ง 2 บอกสถานะของ "วันนี้" เท่านั้น: พอข้ามเที่ยงคืนเวลาไทย ทั้งปุ่มเตรียมขายและปุ่มเริ่มการขายกลับเป็นปกติ (P0 + S0) ไม่ค้างสี
- การเตรียมของวันขายล่วงหน้า: ไม่ถูกล้างจนกว่าวันขายนั้นผ่านไป
- การขายที่ข้ามวันแล้วยังไม่จบ (ไม่ว่าปิดแล้วหรือยัง) คือยังไม่ถึงขั้นที่ 6 "เคลียร์เงินครบ" → ไปอยู่เป็นแถวในรายการ "ควรรู้ / ควรจัดการ" บนหน้าแรก เช่น "การขาย 17 พ.ย. · เงินค้าง 3 กอง ›" แตะแล้วไปหน้าเคลียร์เงิน แถวอยู่จนเคลียร์ครบ กี่วันก็ได้
- ผล: ไม่มีกรณีกดเตรียมขายใหม่ทับการขายค้างอีก (ปุ่มกลับปกติทุกวัน) · คำถามข้อ 1 ด้านล่างจึงไม่ต้องตอบแล้ว

**ไอคอน (ตรวจชุดแล้ว):** FarmMate มีตาชั่ง (`sale.weigh`) และเครื่องคิดเลข (`finance.summary`) · ไม่มีนาฬิกา/นาฬิกาทราย ใช้ `ClockIcon` (ไอคอนเส้นของแอป `src/ui/icons.tsx`) แทน ตามที่เจ้าของอนุญาต ("หรือนาฬิกา") · ✓ ใช้ `Check`

**เริ่มการขายโดยไม่ได้เตรียม:** ปุ่มเตรียมขายปกติ ปุ่มเริ่มการขายฟ้า + ตาชั่ง (สถานะ 9 ใน mockup ที่เจ้าของตกลงแล้ว)

## Dev notes

- **ช่วงเคลียร์เงิน (S3) ไม่มี event ของตัวเอง** (เป็นแค่หน้า): อ่านจากสิ่งที่หน้านั้นเขียน = มีการติ๊กจ่ายหรือบรรทัดหักหนี้ของการขายนั้น และไม่มีกองที่กำลังนับ (`clearingStarted` ใน `src/core/home-tiles.ts`) → จากหน้าสรุปจนกดยืนยัน ปุ่มยังเป็นตาชั่ง (S2) ถ้าอยากให้ขึ้นเครื่องคิดเลขตั้งแต่นับเสร็จ ต้องเพิ่ม event ที่ฝั่งขาย (เปลี่ยน schema = PR สำคัญ)
- **กองเงินค้าง** นับตามแถวหน้าจ่ายเงิน (`src/core/finance/sale-unpaid.ts`): เงินสดคนกรีด, เงินสดคืนหนี้, ยอดโอนเจ้าของสวน · ไม่นับการขายก่อน 2026-11-01 (`UNPAID_COUNTED_FROM`) เพราะก่อนนั้นไม่มีการติ๊กจ่าย จะค้างแดงตลอด (ตัดเดียวกับ `pendingRepayLines`)
- แถว "การขายที่ยังไม่ปิด" ข้ามวัน: การขายที่ปิดแล้วแต่มีเงินค้างขึ้นแถวเดิม (ป้ายแดง "เงินค้าง n กอง") แทนแถว "การขายล่าสุด" ไม่มีรายการที่สอง · การขายที่ยังไม่ปิดข้ามวันใช้แถวเดิมที่มีอยู่แล้ว
- **เตรียมที่ยังไม่ระบุวัน** นับเป็นของวัน (เวลาไทย) ที่เขียนครั้งล่าสุด: ข้ามเที่ยงคืนแล้วกลับเป็นปกติ (HT-5) ยกเว้นมีการขายวันนี้ที่ใช้มันไปแล้ว · เตรียมที่ระบุวันขายล่วงหน้าคงอยู่จนวันขายนั้นผ่านไป
- ไอคอนในป้าย: เส้นของแอป (`Check`, `ClockIcon`, `Scale`, และ `CalculatorIcon` ใหม่ใน `src/ui/icons.tsx`) ไม่ใช่ FarmMate เพราะ FarmMate เป็นภาพสีหลายโทน ไม่เหมาะกับป้ายกลมสีเดียว
- ปุ่มเริ่มการขายไม่เป็นกรอบหนา (`main`) ตอนปกติ ตาม mockup สถานะ 1
