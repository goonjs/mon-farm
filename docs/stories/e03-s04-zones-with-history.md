# Story E03-S04: โซนไม่บังคับ พร้อมประวัติโครงสร้าง

Status: Draft

## Context

- Epic: `docs/epics/e03-master-data.md`
- PRD: MD-2
- แทนที่: โซนใน S27 (`ProfileZone`) และ `zone_added` ในการขาย (S3/S6)

## คำอธิบาย

โซนเป็นตัวเลือก เพิ่ม เลิกใช้ แยก รวม ได้ โดยบันทึกในอดีตยังเห็นโครงสร้างโซน ณ ตอนนั้น

## Acceptance criteria

- [ ] ไม่มีโซนก็ใช้งานทุกอย่างได้; ไม่มีหน้าจอใดบังคับให้สร้างโซน (MD-2)
- [ ] เพิ่ม / เลิกใช้ โซนได้ พร้อมวันที่มีผล (MD-2)
- [ ] แยกโซน: เลือกว่าจุดชั่งใดไปโซนใหม่ใด; รวมโซน: จุดชั่งย้ายไปโซนเดียว — มีผลตั้งแต่วันที่ที่ระบุ (MD-2)
- [ ] ถามว่า "โซนของจุดชั่ง X ณ วันที่ Y" ได้คำตอบตามโครงสร้างวันนั้น ไม่ใช่โครงสร้างปัจจุบัน
- [ ] กำหนดโซนให้บันทึกย้อนหลังได้ (เช่น เพิ่มโซนทีหลังแล้วนำไปใช้กับช่วงที่ผ่านมา) (MD-2)

## Offline / sync

- ทุกการเปลี่ยนโครงสร้างเป็น event ต่อท้าย ทำออฟไลน์ได้
- แยก/รวมโซนเดียวกันซ้อนจากสองเครื่อง → Conflict ตาม E01 ให้เจ้าของเลือก

## Test plan

- [ ] Vitest: โซน ณ วันที่ — ก่อน/หลัง แยก, รวม, เลิกใช้, กำหนดย้อนหลัง
- [ ] jest-expo: หน้าแยก/รวมโซน (เลือกจุดชั่ง, วันที่มีผล)
- [ ] Playwright: แยกโซนออฟไลน์ → reload → โครงสร้างเก่ายังอ่านได้ตามวันที่
