## คำอธิบาย

แสดงจำนวนวันระหว่างการขายเป็นบริบท ถ้าห่างนาน ให้ใส่เหตุผลแบบกดเลือกได้เร็ว

## Acceptance criteria

- [ ] แสดงระยะห่าง (วัน) ระหว่างการขายต่อสวน — ใช้คำว่า "ระยะห่างการขาย" ไม่เรียกว่าจำนวนวันกรีด (ANA-7)
- [ ] ระยะห่างยาวผิดปกติ → ชวนใส่เหตุผล: ฝน, สภาพสวน, แรงงาน, หยุดตามฤดู, นัดผู้ซื้อ, ตั้งใจ, ไม่ทราบ, อื่น ๆ + ข้อความอิสระ (ANA-7)
- [ ] เหตุผลไม่บังคับ ข้ามได้ และแก้ภายหลังได้
- [ ] เหตุผลแสดงในกราฟและ timeline (ANA-2)

## Offline / sync

- ใส่เหตุผลได้ออฟไลน์ เป็น event ผูกกับการขาย → sync ตามปกติ
