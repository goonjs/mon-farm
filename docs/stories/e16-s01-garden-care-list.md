## Description

ที่รวมงานดูแลที่ทำไปแล้ว เรียงตามวันที่ ตอนนี้มีชนิดเดียวคือใส่ปุ๋ย ชนิดอื่น (ตัดหญ้า ฉีดยา) มาทีหลังในหน้าเดียวกัน

## Acceptance criteria

- [ ] **GC-1** ทางเข้า: ไทล์ "การดูแลสวน" (ไอคอน FarmMate `farmwork.maintenance`) บนหน้าแรก/เมนู — ตำแหน่งตามที่หน้าแรกจัด (E13)
- [ ] **GC-2** รายการเรียงใหม่→เก่า: วันที่ · ชนิด (ไอคอน `farmwork.fertilize`) · ปุ๋ยและจำนวนแบบสั้น · โซน (ถ้ามี) · ป้าย "ยังไม่แบ่ง" หรือ "แบ่งไม่ครบ" (สีอำพัน มีคำเสมอ) เมื่อมีการ์ดปุ๋ยที่ยังไม่แบ่ง หรือแบ่งไม่ครบแบบ "แบ่งที่เหลือทีหลัง" (E16-S03 SP-6/6b, D-94) — นับเหมือนเตรียมขายข้อ 4

- [ ] **GC-4** ว่าง: บอกว่าจะเห็นอะไรที่นี่ และปุ่มบันทึกครั้งแรก
- [ ] **GC-5** การใส่ปุ๋ยที่ลบแล้วดูและกู้คืนได้ (แบบเดียวกับใบซื้อ)
