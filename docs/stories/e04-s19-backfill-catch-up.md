## Description

คนนับมาถึงตอนที่ชั่งไปแล้วหลายเข่ง มีกระดาษที่คนอื่นจดไว้ กรอกตามกระดาษ **ทีละจุดตามลำดับ** แล้วนับเองต่อในแอป ·
แอปใส่เลขเข่งเริ่มให้ กรอกแค่ "จบที่เข่งไหน" กับเข่งสุดท้ายเต็มไหม · เข่งไม่เต็มที่ค้างจากจุดก่อนถามที่จุดถัดไปว่าเติมหรือไม่เติม ตามที่เกิดขึ้นจริง ·
น้ำหนักรวม (Σ) อยู่บนสุดทุกหน้าและขึ้นอย่างเดียว · สรุปเรียงตามเลขเข่งเหมือนกระดาษ ·
คำชุดเดียว: **เต็ม / ไม่เต็ม / เติม / ไม่เติม (ปิดเข่ง) / ยังเปิดอยู่** · เลือกวันขายได้ที่หน้าเริ่มการขาย

## Acceptance criteria

- [x] **BF-1** (นับต่อเนื่อง) หน้าเต็ม "ชั่งจุดไหนก่อนหลัง": จุดของคนกรีดนั้น แตะตามลำดับ (เลข 1, 2 …) แตะซ้ำเอาออก · จุดที่ไม่แตะ = ยังไม่ได้ชั่ง · คนกรีดมีจุดเดียวข้ามหน้านี้
- [x] **BF-2** หน้าละจุด: "จุดนี้จบที่เข่งไหน" · เลขเริ่มแอปใส่ให้ (นับต่อเนื่อง = ต่อจากจุดก่อน, นับแยก = 1) กรอกเลขจบด้วยแป้นในแอป · แสดง "= N เข่ง" ตัวโต · เลขจบนับรวมเข่งสุดท้ายแม้ไม่เต็ม · เลขจบน้อยกว่าเลขเริ่มไม่ได้ (นับต่อเนื่อง: เท่ากับเลขเริ่ม − 1 ได้ เมื่อจุดนี้เติมอย่างเดียว ข้าม BF-3)
- [x] **BF-3** หน้าเดียวกัน: "เข่ง N เต็มไหม" สองการ์ด เต็ม (กก. มาตรฐาน) / ไม่เต็ม — **ไม่เลือกให้** ต้องแตะก่อนถึงไปต่อได้ · ไม่เต็ม → ช่อง กก. ยางสุทธิ (มากกว่า 0 น้อยกว่ามาตรฐาน)
- [x] **BF-4** (นับต่อเนื่อง) จุดถัดไปของคนกรีดเดียวกัน ถ้าจุดก่อนจบด้วยเข่งไม่เต็ม: หน้า "เข่ง N (x กก.) เติมที่จุดนี้ไหม" — **เติม** (ใส่ กก. ที่เติมจริง เริ่มที่ส่วนที่ขาด แก้ได้ เกินได้ถึง 1.5 เท่ามาตรฐานของทั้งเข่ง) / **ไม่เติม** (ปิดเข่ง N ที่ x กก.) — ไม่เลือกให้ · เติมไม่ถึงมาตรฐาน = เข่งยังไม่เต็ม ถามอีกที่จุดถัดไป
- [x] **BF-5** เข่งไม่เต็มของจุดสุดท้าย (นับต่อเนื่อง) หรือของแต่ละจุด (นับแยก) **ยังเปิดอยู่** หลังบันทึก นับเองต่อแล้วเติมได้เหมือนนับเอง (ชีตเติมเข่งเดิม)
- [x] **BF-6** สรุปก่อนบันทึก เรียงตามเลขเข่ง: "เข่ง a–b เต็ม · n × 50" · "เข่ง N ไม่เต็ม x + เติมที่จุด … อีก y" · "เข่ง N ไม่เต็ม x · ปิดเข่ง" · "เข่ง N ยังเปิดอยู่ x" · บรรทัด Σ เข่ง กก. · ปุ่มบันทึกกดได้ครั้งเดียว (ระหว่างบันทึกกดซ้ำไม่ได้ ไม่มีเข่งซ้ำ)
- [x] **BF-7** ช่อง "ยอดรวมในกระดาษ" (ไม่บังคับ) ในหน้าสรุป · ตรง → "✓ ตรง" · ไม่ตรง → สีแดง (พร้อมไอคอน) บอกต่างกี่ กก. · บันทึกได้ทั้งสองกรณี
- [x] **BF-8** กรอกย้อนหลังได้เฉพาะก่อนนับเอง: นับต่อเนื่อง = คนกรีดนั้นยังไม่มีเข่งในการขายนี้ · นับแยก = จุดนั้นยังไม่มีเข่ง · ไม่ได้ → บอกเหตุผล (ไม่มีปุ่มไปต่อ)
- [x] **BF-9** หน้าเริ่มการขายมีแถว "วันขาย" ค่าเริ่มต้นวันนี้ แตะเลือกวันจากปฏิทินในแอป วันหลังวันนี้เลือกไม่ได้ · คนกรีดของจุดและส่วนแบ่งคิดตามวันขาย · การขายที่ไม่มีวันขาย (ของเดิม) ใช้วันที่เริ่มเหมือนเดิม
