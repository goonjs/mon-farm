# Story E14-S01: AI endpoint ฝั่ง server

Status: Draft

## Context

- Epic: `docs/epics/e14-ai-assistance.md`
- PRD: AI (ออนไลน์เท่านั้น), NFR-2, NFR-5, NFR-6
- ขึ้นกับ: E01 (Firebase dev/prod, server endpoint), E02 (login + กลุ่มฟาร์ม)

## คำอธิบาย

endpoint เดียวฝั่ง server ที่แอปเรียกเพื่อใช้ AI: ตรวจว่าเป็นสมาชิกกลุ่ม,
ดึงข้อมูลเฉพาะของกลุ่มนั้น, เรียกโมเดล key ของโมเดลไม่อยู่ในแอป

## Acceptance criteria

- [ ] key ของโมเดลเก็บเป็น secret ฝั่ง server; bundle แอปไม่มี key (NFR-5)
- [ ] เรียกได้เฉพาะผู้ใช้ที่ login และเป็นสมาชิกกลุ่ม; อ่านข้อมูลได้เฉพาะกลุ่มนั้น (NFR-5)
- [ ] มีเพดานจำนวนครั้ง/ค่าใช้จ่ายต่อวัน เกินแล้วตอบ "ใช้ AI ครบโควตาวันนี้" (NFR-6)
- [ ] dev/CI ใช้โมเดลปลอม (fake) ไม่เรียกโมเดลจริง (NFR-6)
- [ ] แอปออฟไลน์ → ปุ่ม AI แสดง "ต้องต่ออินเทอร์เน็ต" ไม่ค้าง ไม่ขวางงานอื่น (NFR-2)

## Offline / sync

- AI ออนไลน์เท่านั้น; ไม่อยู่ในเส้นทางที่ต้องทำงานออฟไลน์ ทุกหน้ายังใช้ได้เมื่อ AI ใช้ไม่ได้
- คำขอ AI ไม่เข้าคิวรอส่งตอนออฟไลน์ (ผู้ใช้ถามใหม่เมื่อมีเน็ต)

## Test plan

- [ ] Rules/Integration: ผู้ใช้นอกกลุ่มเรียกแล้วถูกปฏิเสธ (emulator)
- [ ] Unit: เพดานโควตา
- [ ] Offline: ตัดเน็ต → ปุ่ม AI แสดงสถานะ ไม่ error

## คำถามเจ้าของ

- เลือกโมเดล + งบค่าใช้จ่ายต่อเดือน (ใช้ตั้งเพดานโควตา)
- ส่งข้อมูลอ่อนไหว (เอกสารคนงาน, การเงิน) ให้โมเดลภายนอกได้ไหม หรือส่งเฉพาะข้อมูลการขาย/สวน?
