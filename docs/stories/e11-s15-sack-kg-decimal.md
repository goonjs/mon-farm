# Story: E11-S15 ขนาดกระสอบใส่ทศนิยมได้ (2.5 กก.)

Status: Review

## Context

- ต่อจาก `docs/stories/e11-s11-fertilizer-order.md` (FO-3 "ปุ๋ยใหม่")

## สาเหตุ (ตรวจในโค้ดแล้ว)

ช่อง "กิโลกรัมต่อกระสอบ" ใต้ "+ ขนาดอื่น" (`src/v2/money/order/item-sheets.tsx`) ใช้ `QuantityField` แบบจำนวนเต็ม แป้นจึงไม่มีปุ่ม "." ส่วนข้อมูล (`FertilizerDetails.sackKg: number | null`, event, การตรวจ `> 0`) รับทศนิยมอยู่แล้ว

## Acceptance criteria

- [x] **KG-1** ช่องขนาดอื่นใช้แป้นทศนิยม (E01-S20) ได้ถึง **2 ตำแหน่ง** (เช่น 2.5, 1.25) สูงสุด 999.99 ขั้นต่ำ 0.01
- [x] **KG-2** เก็บเป็น กก. ตรง ๆ (`sackKg: 2.5`) ไม่ปัด ไม่เปลี่ยน schema/event; ข้อมูลเก่าที่เป็นจำนวนเต็มอ่านและแสดงเหมือนเดิม
- [x] **KG-3** แสดงผลถูก: "2.5 กก. / กระสอบ", "รวม 10 กก." (4 กระสอบ), ชิปขนาด "2.5 กก." ครั้งหน้า (จำไว้เป็น "2.5")
