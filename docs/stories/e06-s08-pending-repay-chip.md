## คำอธิบาย

ตอนปิดการขาย ถ้ายังไม่ได้ติ๊กว่ารับเงินคืนหนี้แล้ว (โอนรวมเข้าบัญชีสวน หรือเงินสดคืนหนี้) ระบบลดหนี้ของคนกรีดไปแล้วตามยอดหัก
แต่เงินยังไม่เข้าสวน. สตอรี่นี้ให้ป้าย "↘ คืนหนี้ X รอรับโอน / รอรับเงินสด" ที่อยู่บนหน้าจ่ายเงิน (E05-S11)
ตามไปแสดงที่หน้ารายชื่อบัญชีหนี้และหน้าบัญชีหนี้ของคนนั้น จนกว่าจะติ๊กรับเงินแล้ว.

หลักบัญชี (D-85): ยอดหนี้ลดตามการหักทันที (หนี้ไม่ใช่ยอดขาย) — ป้ายบอกแค่ว่า **เงินที่คืนหนี้ยังไม่เข้า** ไม่ได้บอกว่าหนี้ยังไม่ลด.

## Acceptance criteria (ร่าง — รอเจ้าของตกลง)

- [ ] **PR-1** หน้าบัญชีหนี้ของคนกรีด (`/v2/debt/[workerId]`): ใต้ยอดค้างมีการ์ด "เงินคืนหนี้ ยังไม่ได้รับ" บรรทัดรอง "หนี้ลดแล้ว · รอเงินเข้าสวน" (ตัวเข้ม อ่านกลางแดดได้) — แถวละการขายที่ยังไม่ติ๊กรับ: "ขาย {วันที่}" · "↘ คืนหนี้ {ยอดเต็มสตางค์}" สีน้ำเงิน (D-85) · ป้ายสถานะสีอำพันบอกว่ารอจากใคร: "รอคนซื้อโอน" / "รอเงินสดจากคนซื้อ" / "ยังไม่ได้หยิบจากเงิน{ชื่อ}" (สีอำพัน = สถานะรอ ไม่ใช่สีของคืนหนี้; มีคำเสมอ) (M2, M3)
- [ ] **PR-2** ยอดค้างตัวใหญ่ **ไม่เปลี่ยน** เพราะป้าย (หนี้ลดตามการหักแล้ว D-85); การ์ดรอรับไม่บวกกลับเข้ายอดค้าง และสรุปเทียบยอด (E06-S03) ยังตรง ✓
- [ ] **PR-3** หลายการขายค้าง: แถวละการขาย เรียงเก่า→ใหม่ ยอดแถวเต็มสตางค์ (เป็นรายการ ไม่ใช่บรรทัดสรุป); มากกว่า 1 แถวมีบรรทัด "Σ รอเงินเข้ารวม" ย่อ k/m บรรทัดของตัวเอง (summary-lines) (M4)
- [ ] **PR-4** หน้ารายชื่อ (`/v2/debts`): คนที่มีเงินรอเข้ามีป้ายสีอำพัน "หนี้ลดแล้ว · รอเงิน ฿ X" ในแถว (ตัวเลขย่อ `CompactMoney`, รวมทุกการขายของคนนั้น); ป้ายไม่ใช่ปุ่มแยก แตะทั้งแถวเปิดบัญชี (M1)
- [ ] **PR-12** หน้ารายชื่อมีการ์ดสรุปบนสุดเมื่อมีคนรอเงินเข้า: "รอเงินคืนหนี้เข้า: แดง ฿ 3,250 · นัด ฿ 5,250" (เกิน 2 คน บรรทัดละ 2) แล้ว "Σ รอเงินเข้า ฿ 8,500" บรรทัดของตัวเอง (summary-lines); ไม่มีใครรอ = ไม่มีการ์ด (M1)
- [ ] **PR-5** แตะแถว → แผ่นล่าง "รับเงินคืนหนี้แล้วหรือยัง" แสดงการขาย ยอด ทาง และปุ่มที่บอกยอดที่ต้องเห็นจริง "✓ ได้รับโอน 19,687.50 แล้ว" / "✓ ได้รับเงินสด 3,250.00 แล้ว" ซึ่งบันทึก**ช่องเดียวกับหน้าจ่ายเงิน** (event เดิมของ E05-S11) + ลิงก์รอง "เปิดการขายนี้ ›" (ที่แตะ ≥ 48) (M5, M5b) — ❓ Q1
- [ ] **PR-6** รับแล้ว: แถวหายจากการ์ด (การ์ดหายเมื่อไม่เหลือ); ในประวัติ บรรทัด "↘ หักหนี้ · ขาย {วันที่}" มีป้ายเขียว "✓ รับเงินแล้ว ›" (M6)
- [ ] **PR-13** แก้กลับได้: หลังกดมีแถบ "บันทึกแล้ว · เลิกทำ" ชั่วครู่; แตะ "✓ รับเงินแล้ว ›" ในประวัติ → แผ่นเดิมมีปุ่ม "ยังไม่ได้รับ"; แก้ที่หน้าจ่ายเงินก็ได้ — ทุกทางเขียน event ชนิดเดิม ป้ายกลับมา
