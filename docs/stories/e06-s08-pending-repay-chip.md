## คำอธิบาย

ตอนปิดการขาย ถ้ายังไม่ได้ติ๊กว่ารับเงินคืนหนี้แล้ว (โอนรวมเข้าบัญชีสวน หรือเงินสดคืนหนี้) ระบบลดหนี้ของคนกรีดไปแล้วตามยอดหัก
แต่เงินยังไม่เข้าสวน. สตอรี่นี้ให้ป้าย "↘ คืนหนี้ X รอรับโอน / รอรับเงินสด" ที่อยู่บนหน้าจ่ายเงิน (E05-S11)
ตามไปแสดงที่หน้ารายชื่อบัญชีหนี้และหน้าบัญชีหนี้ของคนนั้น จนกว่าจะติ๊กรับเงินแล้ว.

หลักบัญชี (D-85): ยอดหนี้ลดตามการหักทันที (หนี้ไม่ใช่ยอดขาย) — ป้ายบอกแค่ว่า **เงินที่คืนหนี้ยังไม่เข้า** ไม่ได้บอกว่าหนี้ยังไม่ลด.

## Acceptance criteria (ร่าง — รอเจ้าของตกลง)

- [ ] **PR-1** หน้าบัญชีหนี้ของคนกรีด (`/v2/debt/[workerId]`): ใต้ยอดค้างมีการ์ด "↘ คืนหนี้รอรับ" หนึ่งแถวต่อการขายที่ยังไม่ติ๊กรับ — วันที่การขาย · ยอด · ป้าย "รอรับโอน" หรือ "รอรับเงินสด" (ลูกศร + คำ + สี ไม่ใช่สีอย่างเดียว) (M2, M3)
- [ ] **PR-2** ยอดค้างตัวใหญ่ **ไม่เปลี่ยน** เพราะป้าย (หนี้ลดตามการหักแล้ว D-85); การ์ดรอรับไม่บวกกลับเข้ายอดค้าง และสรุปเทียบยอด (E06-S03) ยังตรง ✓
- [ ] **PR-3** หลายการขายค้าง: แถวละการขาย เรียงเก่า→ใหม่; มากกว่า 1 แถวมีบรรทัด Σ รวมท้ายการ์ด (กติกา summary-lines) (M4)
- [ ] **PR-4** หน้ารายชื่อ (`/v2/debts`): คนที่มีรอรับมีป้ายเล็ก "↘ รอรับ ฿ X" ในแถวของคนนั้น (ตัวเลขย่อ `CompactMoney`, รวมทุกการขายของคนนั้น); หลายทางรับปนกันใช้คำ "รอรับ" อย่างเดียว (M1)
- [ ] **PR-5** แตะแถวรอรับ → แผ่นล่าง "รับเงินคืนหนี้แล้วหรือยัง" แสดงการขาย ยอด ทาง และปุ่ม "รับแล้ว" ที่ติ๊ก**ช่องเดียวกับหน้าจ่ายเงิน** (event เดิมของ E05-S11) + ลิงก์รอง "เปิดการขายนี้ ›" (M5) — ❓ Q1
- [ ] **PR-6** รับแล้ว: แถวหายจากการ์ดรอรับ (การ์ดหายเมื่อไม่เหลือ); ในประวัติ บรรทัดหักของการขายนั้นมีคำ "✓ รับเงินแล้ว" (M6); ยกเลิกติ๊กที่หน้าจ่ายเงิน → ป้ายกลับมา
- [ ] **PR-7** ทางโอนรวม: ติ๊กเดียวของ "เจ้าของได้รับเงินโอนแล้ว" ปิดรอรับของทุกคนที่โอนรวมในการขายนั้น — แผ่นบอกชัดว่าติ๊กนี้รวมส่วนสวนด้วย ("โอนรวม ฿ 22,937.00 · ส่วนสวน + คืนหนี้แดงและนัด") — ❓ Q2

## Offline / sync behavior

- ป้ายคำนวณจาก event log ในเครื่องเสมอ (การหัก + ทางรับเงิน + ติ๊กของการขาย) ออฟไลน์ได้ ไม่มีข้อมูลใหม่ที่ต้องเก็บ
- ติ๊ก "รับแล้ว" จากหน้าบัญชีหนี้เขียน **event ชนิดเดิม** ที่หน้าจ่ายเงินใช้ (E05-S11) — ไม่มีชนิด event ใหม่ ไม่มี migration
- สองเครื่องติ๊ก/ยกเลิกติ๊กพร้อมกัน → กติกา Conflict เดิมของติ๊กจ่าย (D-30)
- ตรวจ `docs/checklists/offline-sync-checklist.md` ก่อน Done
