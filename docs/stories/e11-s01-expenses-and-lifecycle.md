# Story E11-S01: ค่าใช้จ่ายและวงจร Actual / Committed / Planned

Status: Draft

## Context

- Epic: `docs/epics/e11-finance.md`
- PRD: FIN-1, FIN-2, SYNC-9, SYNC-10, SYNC-12, NFR-3, NFR-5
- ขึ้นกับ: E01 (event log + sync), E03 (สวน)

## คำอธิบาย

บันทึกค่าใช้จ่ายของสวนแบบแยกฟิลด์ (หมวด, สวน, วงจร) และเลื่อนวงจร
วางแผน → ผูกพันแล้ว → เกิดจริง ได้ เป็นฐานของทุก story ใน E11

## Acceptance criteria

- [ ] ค่าใช้จ่ายมีฟิลด์แยกกัน: รายการ, หมวด (เพิ่มได้), สวน (ไม่บังคับ), จำนวนเงิน, วันที่, วงจร, หมายเหตุ, ใบเสร็จ/รูป — ไม่รวมเป็นฟิลด์เดียว (FIN-1)
- [ ] วงจร 3 แบบ: เกิดจริง · ผูกพันแล้ว · วางแผน; เลื่อนวงจรได้โดยเก็บประวัติ (FIN-2, SYNC-9)
- [ ] ยอด "เกิดจริง" ไม่รวมรายการ วางแผน เด็ดขาด (FIN-2)
- [ ] แสดงผล: เกิดจริง = ทึบ, ผูกพันแล้ว = มีกรอบ, วางแผน = กรอบเส้นประ ทุกแบบมีป้ายคำ (design-system §12.9 ข้อ 9)
- [ ] เงินเก็บเป็นสตางค์จำนวนเต็ม; ลบแบบกู้คืนได้ (NFR-3, SYNC-10)
- [ ] ข้อมูลการเงินเห็นเฉพาะสมาชิกกลุ่ม (NFR-5)

## Offline / sync

- บันทึก/แก้/เลื่อนวงจรได้ออฟไลน์ → sync อัตโนมัติ
- แก้จำนวนเงินหรือวงจรของรายการเดียวกันซ้อนกัน → Conflict ไม่ทับเงียบ (SYNC-4)

## Test plan

- [ ] Unit: เลื่อนวงจรเก็บประวัติ; จำนวนเงินเป็นสตางค์ ไม่มี float
- [ ] Offline: สองเครื่องแก้จำนวนเงินรายการเดียวกัน → Conflict
