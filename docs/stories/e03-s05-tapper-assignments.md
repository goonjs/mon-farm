- ขึ้นกับ: E03-S01 (คนกรีด), E03-S03 (จุดชั่ง) — **ไม่ขึ้นกับ E03-S04 แล้ว**

## คำอธิบาย

ระบุว่าจุดชั่งไหนเป็นของคนกรีดคนไหน ตั้งแต่เมื่อถึงเมื่อไร ("ผู้รับผิดชอบจุด" = คนกรีดของจุด, D-55)
หน้าชั่ง (E04) และสรุปเงิน (E05) ใช้ข้อมูลนี้รู้ว่าเข่งเป็นของใคร และเข่งไม่เต็มต่อข้ามจุดได้หรือไม่

## Acceptance criteria

- [ ] จุดชั่งหนึ่งมีคนกรีดได้ 1 คน ณ วันหนึ่ง; การมอบหมายมี valid-from (ว่างได้ = ไม่ระบุวันเริ่ม ครอบคลุมย้อนหลังทั้งหมด) และ valid-to (ว่างได้ = ยังมีผล) (MD-4, D-63)
- [ ] เปลี่ยนคนกรีด **ทำจากหน้าจุดชั่งทีละจุดเท่านั้น**: เลือกคนใหม่ + วันเริ่ม → คนเดิมสิ้นสุด **วันก่อนวันเริ่มของคนใหม่ (รวมวันนั้น)** เช่น เริ่ม 1 ต.ค. → คนเดิมถึง 30 ก.ย. (D-63)
- [ ] คนกรีดปกติอยู่ประจำ; หน้าจุดชั่งมี **"วางแผนเปลี่ยนคนกรีด"**: ใส่คนใหม่ + วันเริ่ม (**ตั้งล่วงหน้าได้**) คนเดิมสิ้นสุดวันก่อนให้อัตโนมัติ; ลาออกโดยยังไม่มีคนแทน → ใส่วันสิ้นสุดอย่างเดียว จุดเป็น "ยังไม่มีคนกรีด" ตั้งแต่วันถัดไป (เจ้าของตกลง AC 2026-10-03)
- [ ] "คนกรีดของจุดชั่ง X ณ วันที่ Y" คืนคนเดียวหรือ "ยังไม่มีคนกรีด" (SALE-4)
- [ ] เปลี่ยนคนกรีดไปข้างหน้า ไม่เปลี่ยนเจ้าของเข่งในการขายก่อนวันเริ่ม (MD-4)
- [ ] การมอบหมายตั้งต้นจากโครงสร้างตั้งต้น (E03-S03): จุดของแดง → แดง, จุดของนัด → นัด — **ไม่ระบุวันเริ่ม** (D-63)
- [ ] จุดที่ยังไม่มีคนกรีด ณ วันขาย: **ชั่งได้** (แสดงคำเตือน "ยังไม่มีคนกรีด" ไม่ขวาง) และ **มอบหมายย้อนหลังได้** — เข่งเป็นของคนที่มอบหมาย ณ วันขาย (คำนวณใหม่จาก log) (D-63)
- [ ] สรุปเงิน/ปิดการขาย **ทำไม่ได้จนทุกจุดในการขายนั้นมีคนกรีด** ณ วันขาย — บอกจุดที่ขาด พร้อมทางไปมอบหมาย (D-63)
- [ ] มอบหมาย/เปลี่ยนคนกรีดย้อนหลังจนเงินของการขายที่ Completed แล้วเปลี่ยน → ขอเหตุผลสั้น ๆ + ติดธงตรวจการจ่ายของการขายนั้น (D-16)
- [ ] หน้าคนงาน (E03-S01) แสดง "จุดที่รับผิดชอบ" ปัจจุบันของคนนั้น (D-65)
- [ ] แผนเปลี่ยนคนกรีดที่ตั้งล่วงหน้า **แก้ไขและยกเลิกได้ก่อนถึงวันเริ่ม**; ถ้าการแก้ซับซ้อน ให้ยกเลิกแผนแล้วทำ flow วางแผนใหม่ (F3) (D-74)
- [ ] หลังบันทึกจุดชั่งใหม่ เสนอ "มอบหมายคนกรีดให้จุดนี้" ทันที หรือกดทำทีหลังได้ (F15) (D-74)
- [ ] กรณีพิเศษ (หายาก): ปิดการขายได้โดยจุดไม่มีคนกรีด เช่น คนกรีดไม่อยู่แล้วแต่กรีดกองไว้แล้ว → ให้เลือก **ผู้รับผลประโยชน์** ของยอดจุดนั้นจากคนในระบบ (ใครก็ได้ หรือเจ้าของสวน) **ยกเว้นผู้ซื้อ** (F17) (D-74)

## Offline / sync

- event ต่อท้าย ทำออฟไลน์ได้
- สองเครื่องเปลี่ยนคนกรีดของจุดเดียวกันจนช่วงเวลาทับกันตอนออฟไลน์ → Conflict ตาม E01 ไม่เลือกเองเงียบ ๆ (การมอบหมายเปลี่ยนเงิน — D-30)
- ระหว่างมี Conflict ในการมอบหมาย: คำนวณ/แสดงได้ แต่ **ปิดการขาย/สรุปเงินของการขายที่ได้รับผลไม่ได้** จนกว่าเจ้าของตัดสิน (D-29)

## Test plan

- [ ] Vitest: คนกรีด ณ วันที่ (ไม่ระบุวันเริ่ม, ก่อน/ตรง/หลังวันเปลี่ยน); คนเดิมสิ้นสุดวันก่อนวันเริ่ม (รวมวันนั้น); การเปลี่ยนไม่กระทบการขายก่อนวันเริ่ม
- [ ] Vitest: จุดไม่มีคนกรีด → ชั่งได้, สรุปเงิน/ปิดถูกขวาง; มอบหมายย้อนหลัง → เข่งเป็นของคนนั้น, ปลดการขวาง
- [ ] Vitest: มอบหมายย้อนหลังถึงการขาย Completed → ต้องมีเหตุผล + ธงการจ่าย (D-16)
- [ ] Vitest: event มอบหมายทับช่วงจากสองเครื่อง → Conflict; การขายที่ได้รับผลปิด/สรุปเงินไม่ได้ (D-29)
- [ ] jest-expo: หน้าจุดชั่ง → เปลี่ยนคนกรีด (คนใหม่, วันเริ่ม, แสดงวันสิ้นสุดของคนเดิม)
- [ ] Playwright: มอบหมายออฟไลน์ → reload → ยังอยู่

## คำถามเจ้าของ

- มอบหมายระดับโซน กับระดับจุดชั่ง ขัดกัน (โซนเป็นของแดง แต่มีจุดหนึ่งเป็นของนัด): (a) ระดับจุดชั่งชนะ · (b) ห้ามมีทั้งสองระดับในพื้นที่เดียวกัน

**คำตอบเจ้าของ (2026-10-03):**
- มอบหมายโซนกับจุดชั่งขัดกัน → **ห้ามมอบหมายซ้อนกัน** (พื้นที่เดียวกันมอบหมายได้ระดับเดียว) — *ย้ายไปใช้กับ E03-S04 เมื่อกลับมาทำ (D-64); story นี้ทำระดับจุดเท่านั้น*

**คำตอบเจ้าของ (2026-10-03, PR #44) (D-55):**
- "ผู้รับผิดชอบจุด" = **คนกรีดของจุด** (จุดละ 1 คน มีช่วงเวลา, MD-4) — epic นี้อยู่ลำดับแรก

**คำตอบเจ้าของ (2026-10-03) — UX e03 Q11, Q15, Q16, Q23 (D-63, D-64, D-29):**
- Q11 การมอบหมายตั้งต้น → **ไม่ระบุวันเริ่ม**
- Q15 วันที่ "ถึง" → **รวมวันนั้น** (คนเดิมถึงวันก่อนวันเริ่มของคนใหม่); เปลี่ยน **จากหน้าจุดชั่งทีละจุด**
- Q16 จุดที่ยังไม่มีคนกรีด → **ชั่งได้ มอบหมายย้อนหลังได้** แต่สรุปเงิน/ปิดไม่ได้จนทุกจุดมีคนกรีด; การขาย Completed ที่เงินเปลี่ยน → เหตุผล + ธง (D-16)
- Q23 Conflict ในการมอบหมาย → **ขวางการปิด/สรุปเงิน** (D-29)
- โซน → อิสระ ไม่บังคับ เลื่อนออกจากลำดับแรก (D-64)
