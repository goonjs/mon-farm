# Story E03-S05: มอบหมายคนกรีด ↔ จุดชั่ง/โซน แบบมีช่วงเวลา

Status: Draft

## Context

- Epic: `docs/epics/e03-master-data.md`
- PRD: MD-4, SALE-4, SALE-12
- แทนที่: การผูกคนกรีดต่อโซนต่อการขายใน `zone_contract_set` (S15) — ฝั่งการเงินแยกไปที่ E03-S06
- ขึ้นกับ: E03-S01 (คนกรีด), E03-S03 (จุดชั่ง), E03-S04 (โซน)

## คำอธิบาย

ระบุว่าจุดชั่ง/โซนไหนเป็นของคนกรีดคนไหน ตั้งแต่เมื่อถึงเมื่อไร หน้าชั่ง (E04) ใช้ข้อมูลนี้รู้ว่าเข่งเป็นของใคร
และเข่งไม่เต็มต่อข้ามจุดได้หรือไม่

## Acceptance criteria

- [ ] มอบหมายคนกรีดให้จุดชั่งหรือโซน มี valid-from และ valid-to (ว่างได้ = ยังมีผล) (MD-4)
- [ ] "คนกรีดของจุดชั่ง X ณ วันที่ Y" คืนคนเดียว; มอบหมายช่วงเวลาทับกันบนจุดเดียวกันถูกปฏิเสธพร้อมเหตุผล (SALE-4)
- [ ] ย้ายจุดชั่งไปคนกรีดอื่นตั้งแต่วันที่ใหม่ ไม่เปลี่ยนเจ้าของเข่งในการขายเก่า (MD-4)
- [ ] จุดชั่งที่ไม่มีคนกรีด ณ วันขาย ถูกแสดงเป็นคำเตือนตอนเลือกจุดชั่ง ไม่ขวางการชั่ง
- [ ] ค่าตั้งต้นตาม E03-S03: จุดของแดง → แดง, จุดของนัด → นัด
