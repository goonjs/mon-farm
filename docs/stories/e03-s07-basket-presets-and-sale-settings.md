## คำอธิบาย

ตั้งค่าที่การชั่งใช้ไว้ที่เดียว: น้ำหนักเข่งสุทธิมาตรฐานและ tare ภาชนะ, โหมดตรวจศูนย์/tare, เวลากดค้าง,
เสียง และช่วงเวลาจับนับซ้ำ

## Acceptance criteria

- [ ] ค่าตั้งต้นเข่งสุทธิ: มี 50 และ 60 กก. เพิ่มได้; ค่า tare หลายค่าได้; อย่างละหนึ่งค่าเป็นค่าเริ่มต้นการขายใหม่ (MD-7)
- [ ] โหมดตรวจศูนย์/tare: ทุกจุด (ค่าเริ่มต้น) · เฉพาะจุดแรกของแต่ละสวน · ข้ามทั้งหมด (MD-9, SALE-6)
- [ ] เวลากดค้าง ตั้งได้ในช่วง ~0.5–1 วินาที (D-7)
- [ ] เสียงภาษาไทย เปิด/ปิด (D-8)
- [ ] ช่วงเวลาจับนับซ้ำ ตั้งได้ 7–10 วินาที (SYNC-6)
- [ ] น้ำหนักเก็บเป็นกรัมจำนวนเต็ม (NFR-3)

## Offline / sync

- แก้ตั้งค่าออฟไลน์ได้; ค่าระดับกลุ่มฟาร์ม sync ทุกเครื่อง; ค่าระดับเครื่องไม่ sync (ดูคำถาม)
- การขายที่เริ่มแล้วเก็บ snapshot ค่าที่ใช้ — แก้ตั้งค่าทีหลังไม่เปลี่ยนเข่งที่บันทึกแล้ว
