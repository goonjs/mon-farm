## Acceptance criteria

- [ ] ค่าตั้งต้นเข่งสุทธิ: มี 50 และ 60 กก. เพิ่มได้; ค่า tare หลายค่าได้; อย่างละหนึ่งค่าเป็นค่าเริ่มต้นการขายใหม่ (MD-7)
- [ ] โหมดตรวจศูนย์/tare: ทุกจุด (ค่าเริ่มต้น) · เฉพาะจุดแรกของแต่ละสวน · ข้ามทั้งหมด (MD-9, SALE-6)
- [ ] เวลากดค้าง ตั้งได้ในช่วง ~0.5–1 วินาที (D-7); เป็นค่าของเครื่อง แสดง/แก้ได้จากหน้าตั้งค่าวันขาย พร้อมป้าย "เฉพาะเครื่องนี้" (D-79)
- [ ] เสียงภาษาไทย เปิด/ปิด (D-8)
- [ ] ช่วงเวลาจับนับซ้ำ ตั้งได้ 7–10 วินาที (SYNC-6)
- [ ] น้ำหนักเก็บเป็นกรัมจำนวนเต็ม (NFR-3)
- [ ] น้ำหนักเข่ง/ตะกร้าในตั้งค่า ใช้ความละเอียดตามประเภทตาชั่ง: ไม่มีทศนิยม (ค่าเริ่มต้น) = ใส่ทีละ 1 กก. (?19, D-66) (D-74)
- [ ] ช่องโหมดเลขเข่งอยู่หน้าตั้งค่าวันขายแบบกระชับ ไม่มีประโยคบอกว่าเป็นค่าตั้งต้น; ใช้คำ "น้ำหนักยางสุทธิ" และวางน้ำหนักตะกร้าคู่กัน (F1, คอมเมนต์หน้า 3) (D-74)

## คำถามเจ้าของ

- ค่าใดเป็นของกลุ่ม (ทุกเครื่องเหมือนกัน) ค่าใดเป็นของเครื่อง: เวลากดค้าง · เสียงเปิด/ปิด · โหมดตรวจศูนย์ — (a) ทั้งหมดเป็นของกลุ่ม · (b) เวลากดค้างและเสียงเป็นของเครื่อง ที่เหลือเป็นของกลุ่ม
- ค่าเริ่มต้นของเวลากดค้าง และช่วงจับนับซ้ำ (เช่น 0.7 วินาที / 8 วินาที)?
