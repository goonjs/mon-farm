เพิ่มสวนเป็นข้อมูลหลัก (ยาง/ทุเรียน) เก็บพื้นที่เป็นไร่แบบมีวันที่ เพื่อให้การวิเคราะห์ใช้พื้นที่ ณ เวลานั้น

## Acceptance criteria

- [ ] สร้าง / แก้ / ลบ (กู้คืนได้) สวนได้: ชื่อ*, ประเภท* (ยาง / ทุเรียน) (MD-1, D-65)
- [ ] พื้นที่ (ไร่) **ไม่บังคับ** — ไม่ใส่ แสดง "ไม่ทราบ"; ใส่แล้วต้องเป็นตัวเลข > 0 (D-65)
- [ ] พื้นที่บันทึกพร้อมวันที่มีผล; เปลี่ยนพื้นที่ = เพิ่มรายการใหม่ ไม่ทับของเดิม (MD-1)
- [ ] พื้นที่สองรายการ **วันที่มีผลเดียวกัน → ใช้รายการที่บันทึกล่าสุด** (ทั้งจากเครื่องเดียวและสองเครื่อง) รายการเดิมยังอยู่ในประวัติ (D-65)
- [ ] ฟังก์ชัน "พื้นที่ ณ วันที่ X" คืนค่าที่มีผลในวันนั้น (หรือ "ไม่ทราบ" ถ้ายังไม่มีรายการ)
- [ ] ปีที่ปลูก **ไม่บังคับ** (พิมพ์เป็น พ.ศ. ตามการแสดงวันที่ D-65) แอปคำนวณอายุ; ไม่ใส่ = ไม่ทราบ
- [ ] GPS ไม่บังคับ; ถ้าไม่ใส่ แสดงเป็น Unknown (MD-1, SYNC-12); GPS นี้คือพิกัดที่การ์ดพยากรณ์อากาศใช้เปิดเว็บภายนอก (D-51)
- [ ] สวนทุเรียน: แนบไฟล์/รูปสัญญาเช่าได้ — **เก็บในเครื่องได้ทันที ส่วนอัปโหลดรออัปเกรด Blaze** (D-48; เงื่อนไขสัญญาอยู่ E11)
- [ ] **ลบสวนได้เสมอ (กู้คืนได้)** — ไม่มีการขวางเพราะรายการหักเงินคนกรีด; การขายเก่ายังนับเข่งเดิม ส่วนแบ่งไม่หาย (D-58 แทน D-44)
- [ ] ลบสวนแล้ว **จุดชั่งในสวนนั้นหายตาม** (ไม่ขึ้นตอนเริ่มการขาย ไม่ต้องลบทีละจุด); กู้คืนสวน → จุดชั่งกลับมาด้วย; การขายเก่ายังอ้างถึงได้ (D-65)
- [ ] ไฟล์สัญญาที่ยังไม่อัปโหลด **เครื่องอื่นในกลุ่มไม่เห็นอะไรเลย** จนอัปโหลดเสร็จ (F16) (D-74)

## Dev notes

**ทำแล้ว (2026-10-09 คืน, ทีม FARM)**

- event `property_added` / `property_edited` (patch + `cleared` สำหรับตั้งฟิลด์ไม่บังคับกลับเป็น "ไม่ทราบ" เพราะ
  canonical JSON ไม่มี null) / `area_recorded` (เพิ่มต่อท้ายเสมอ) ใน `MasterPayload`; fold ที่ `projectMaster`
- หน่วยจำนวนเต็ม (canonical JSON): พื้นที่ = `centiRai` (ไร่ × 100), GPS = ไมโครองศา (`latE6`/`lngE6`),
  วันที่มีผล = วันแบบ ISO `YYYY-MM-DD`
- `areaOn(property, day)`: รายการที่วันที่มีผล ≤ วันนั้น ล่าสุด; วันเดียวกัน → รายการที่อยู่หลังในลำดับ fold
  (= บันทึกทีหลัง) ชนะ — ใช้ลำดับ fold ไม่ใช่นาฬิกาเครื่อง (NFR-3) ทั้งเครื่องเดียวและสองเครื่อง (D-65 Q8);
  ยังไม่มีรายการ = `null` → "ไม่ทราบ" ไม่ใช่ 0
- ปีที่ปลูกพิมพ์เป็น พ.ศ.; `ageInYears` คำนวณจากปีปัจจุบัน (เวลากรุงเทพฯ)
- ลบสวน = Soft Delete ธรรมดา ไม่ต่อเข้า `delete-guard.ts` (D-58); การซ่อนจุดชั่งตามสวน (AC10) ทำใน E03-S03 ที่สร้างจุดชั่ง
  — ข้อความยืนยันลบบอกแล้วว่าจุดชั่งหายตามและกู้คืนได้
- จอ: `/properties` (ประเภท + พื้นที่วันนี้ หรือ "พื้นที่ ไม่ทราบ", ลิงก์ที่ลบแล้ว) · `/property/[id]` (`PropertyForm`:
