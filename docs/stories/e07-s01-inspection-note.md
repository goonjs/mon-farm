## คำอธิบาย

บันทึกการตรวจสวนแบบอิสระ: พิมพ์โน้ต ระบุที่ดิน / โซน / จุด และเก็บ GPS ถ้ามี
เก็บตำแหน่งที่บันทึกแยกจากตำแหน่งที่เกิดเหตุจริง

## Acceptance criteria

- [ ] พิมพ์โน้ตอิสระ; ข้อความต้นฉบับเก็บไว้ไม่ถูกแก้ทับ (OPS-1, SYNC-11)
- [ ] ระบุที่ดิน (บังคับ) / โซน / จุด (ไม่บังคับ) (OPS-2)
- [ ] GPS ไม่บังคับ: เก็บ **ตำแหน่งที่บันทึก** อัตโนมัติถ้าอนุญาต แยกจาก **ตำแหน่งที่เกิดจริง** (OPS-11)
- [ ] ปฏิเสธสิทธิ์ตำแหน่ง หรือบันทึกจากที่อื่น → บันทึกได้ตามปกติ ไม่มีการบังคับ (OPS-11)
- [ ] รายการการตรวจสวน เรียงใหม่สุดก่อน กรองตามที่ดินได้

## Offline / sync

- บันทึกและอ่าน GPS ได้ออฟไลน์; สถานะ Pending Sync ต่อรายการ
- การตรวจสวนจากหลายเครื่องเป็นบันทึกแยกกัน รวมได้เสมอ
