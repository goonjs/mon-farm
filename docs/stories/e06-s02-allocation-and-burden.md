## คำอธิบาย

แบ่งกระสอบของการซื้อให้คนกรีดแต่ละคน (ระบุโซนได้ ไม่บังคับ) ต้นทุนต่อคน
คิดตามจำนวนกระสอบ คนกรีดรับ 50% เป็นภาระในบัญชีของตน อีก 50% เป็นค่าใช้จ่ายสวน

## Acceptance criteria

- [ ] แบ่งกระสอบของการซื้อหนึ่งครั้งให้คนกรีดหลายคน; โซนไม่บังคับ (FERT-3)
- [ ] ต้นทุนต่อคน = ราคาการซื้อ × (กระสอบที่ได้ ÷ กระสอบทั้งหมด) เป็นสตางค์จำนวนเต็ม
- [ ] ภาระคนกรีด = 50% ของต้นทุนที่แบ่งให้ → บรรทัดภาระในบัญชีคนกรีด (FERT-4)
- [ ] อีก 50% → ค่าใช้จ่ายสวน (Actual) ใน FIN (FERT-4, FIN-2)
- [ ] กระสอบที่ยังไม่แบ่งแสดงเป็น "ยังไม่แบ่ง" ไม่ถูกคิดเป็นภาระของใคร
- [ ] แก้การแบ่ง → ภาระและค่าใช้จ่ายคำนวณใหม่ ประวัติไม่หาย
