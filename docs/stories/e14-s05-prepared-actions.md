## คำอธิบาย

จากแชต AI เตรียมการเปลี่ยนแปลงได้ (สร้าง/แก้งาน, ตั้งเตือน, แก้ข้อมูล, ผู้รับแจ้งเตือน)
แสดงเป็น diff ก่อน และทำจริงเฉพาะเมื่อเจ้าของกดยืนยัน

## Acceptance criteria

- [ ] คำสั่งที่ AI เตรียมแสดงเป็น diff: ค่าเดิม → ค่าใหม่ ต่อฟิลด์ (AI-5)
- [ ] ปุ่ม ยืนยัน · แก้ก่อน · ยกเลิก; ไม่มีการเขียนข้อมูลก่อนกดยืนยัน (AI-5, TASK-3)
- [ ] เมื่อยืนยัน สร้าง event ปกติ ที่มาติด "AI" + ผู้ยืนยัน (SYNC-11)
- [ ] AI ไม่เปลี่ยนการตั้งค่า/กฎเงียบ ๆ; ไม่เพิ่มอาจารย์สมหวังเป็นผู้รับเอง (AI-6, TASK-5)
- [ ] ข้อมูลเปลี่ยนไปก่อนกดยืนยัน (ฐานไม่ตรง) → แจ้งให้เตรียมใหม่ ไม่ทับ

## Offline / sync

- การเตรียมต้องออนไลน์; diff ที่เตรียมแล้วกดยืนยันได้แม้เน็ตหลุด เพราะเขียนเป็น event ในเครื่อง → sync ตามปกติ
