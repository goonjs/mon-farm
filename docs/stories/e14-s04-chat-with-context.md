## คำอธิบาย

แชตภาษาไทยที่จำบริบทภายในบทสนทนา ตอบจากฐานข้อมูลของสวนทุกครั้ง
(ไม่ใช่จากความจำของแชต) และถามกลับเมื่อคำถามกำกวม

## Acceptance criteria

- [ ] ถาม-ตอบภาษาไทย; คำถามต่อเนื่องเข้าใจบริบทของข้อก่อนหน้าในบทสนทนาเดียวกัน (AI-4, NFR-1)
- [ ] ทุกคำตอบดึงข้อมูลจากฐานข้อมูลใหม่ ไม่ใช้ตัวเลขจากข้อความเก่าในแชตเป็นแหล่งความจริง (AI-4)
- [ ] คำถามกำกวม (เช่น ไม่ระบุสวน/ช่วงเวลา) → ถามกลับก่อนตอบ (AI-4)
- [ ] คำตอบเป็นรูปแบบมีป้ายและอ้างอิง (AI-1, AI-2)
- [ ] เริ่มบทสนทนาใหม่ได้ (ล้างบริบท)

## Offline / sync

- ออฟไลน์: ช่องพิมพ์ปิดพร้อม "ต้องต่ออินเทอร์เน็ต"; บทสนทนาที่เปิดอยู่ยังอ่านได้

## Test plan

- [ ] Unit: ประกอบ context (ประวัติแชต + ข้อมูลจากฐานข้อมูล) ต่อคำถาม
- [ ] Eval: คำถามกำกวมได้คำถามกลับ (fake model + ตรวจ manual กับโมเดลจริง)
