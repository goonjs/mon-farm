## คำอธิบาย

ก่อนชั่งที่จุดชั่ง ถามตรวจศูนย์และยืนยัน tare ตามโหมดที่ตั้งไว้ และให้เลือกขนาดเข่งของการขาย/จุดนั้น

## Acceptance criteria

- [ ] โหมด "ทุกจุด": ถามที่ทุกจุดชั่งก่อนเข่งแรกของจุดนั้น (SALE-6)
- [ ] โหมด "จุดแรกของแต่ละสวน": ถามเฉพาะจุดแรกที่ชั่งในแต่ละสวน (SALE-6)
- [ ] โหมด "ข้าม": ไม่ถาม แต่บันทึกการข้ามไว้ในการขาย (SALE-6)
- [ ] ตาชั่งเปล่าไม่อ่านศูนย์ → เลือก 2 ทาง (D-75 แทนการติดธงแล้วไปต่อของ S9):
  - **รอเปลี่ยนตาชั่ง**: หน้าจอรอ (ภาพเคลื่อนไหว) ข้อความ "รอเปลี่ยนตาชั่ง" + ปุ่ม "ตกลง" กลับหน้าเดิม; ชั่งเข่งไม่ได้จนตรวจศูนย์ใหม่ผ่าน
  - **รับเข็มเบี้ยวและใช้ต่อ**: บันทึกค่าเบี้ยว (± ตามความละเอียดของประเภทตาชั่ง) ใช้จนถึงการตรวจศูนย์ครั้งถัดไป
- [ ] เมื่อมีค่าเบี้ยว: **ทุกที่ที่แสดง "ตาชั่งควรอ่าน" รวมค่าเบี้ยว และแสดงค่าเบี้ยวแยกเป็นบรรทัดของตัวเอง** (สุทธิ · ตะกร้า · เข็มเบี้ยว · ตาชั่งควรอ่าน) (D-75, D-70)
- [ ] การขายที่มีค่าเบี้ยว → **ทุกครั้งที่ย้ายจุดต้องตรวจตาชั่งเปล่า** ไม่สนโหมดตรวจศูนย์ในตั้งค่า สำหรับการขายนั้น (D-76)
- [ ] น้ำหนักสุทธิที่เก็บ = ค่าที่อ่าน − ตะกร้า − ค่าเบี้ยว; เงินคิดจากสุทธิ; ทางที่เลือกและค่าเบี้ยวเป็น event ในบันทึกการขาย (D-75)
- [ ] ขนาดเข่ง: ค่าเริ่มต้นจากค่าตั้งต้นกลุ่ม เปลี่ยนได้รายการขาย/รายจุด; หน้าจอแสดงค่าที่ตาชั่งควรอ่าน (สุทธิ + tare) (SALE-7, MD-7)
