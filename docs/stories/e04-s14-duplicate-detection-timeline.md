## คำอธิบาย

บันทึกจากหลายเครื่องโดยไม่ส่งต่อก็ได้ แต่ตอนรวมข้อมูล ถ้าเข่งจากต่างเครื่องใกล้กันเกินไป แอปถามว่าเป็นการนับซ้ำไหม
พร้อมไทม์ไลน์ให้เห็นภาพ

## Acceptance criteria

- [ ] ตอนรวม (sync หรือ QR): เข่งของการขายเดียวกันจากต่างเครื่อง ห่างกันไม่เกินช่วงที่ตั้ง (7–10 วิ) → ขึ้น "นี่คือการนับซ้ำไหม?" (SYNC-6)
- [ ] ตรวจซ้ำกับเลขเข่ง (เลขเดียวกันจากสองเครื่อง = สงสัยซ้ำ แม้เวลาห่าง) และทนนาฬิกาคลาดเคลื่อน (SYNC-6)
- [ ] ไทม์ไลน์แบบง่าย แถวละเครื่อง แสดงช่วงที่บันทึกทับกัน (SYNC-7)
- [ ] "ใช่ ซ้ำ" → ยกเลิกเข่งที่เลือกเป็น event (E04-S09); "ไม่ซ้ำ" → เก็บทั้งคู่ บันทึกการตัดสินใจ
- [ ] ยังไม่ตัดสิน → การขายติดธง ไม่ขวางการชั่ง

## Offline / sync

- ตรวจในเครื่องทุกครั้งที่มี event จากเครื่องอื่นเข้ามา; การตัดสินใจเป็น event ที่ sync
- ไม่ลบหรือแก้เข่งเองอัตโนมัติ เจ้าของตัดสินเสมอ

## Test plan

- [ ] Vitest: ห่าง 6 วิ / 11 วิ กับช่วง 10 วิ; เลขซ้ำต่างเวลา; นาฬิกาเครื่องหนึ่งเร็ว 2 นาที
- [ ] jest-expo: คำถามนับซ้ำ + ไทม์ไลน์สองแถว
- [ ] Playwright: สอง context บันทึกพร้อมกัน → sync → คำถามขึ้น → เลือก "ใช่" → ยอดลด 1 เข่ง
