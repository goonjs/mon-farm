## คำอธิบาย

## Acceptance criteria

- [ ] บันทึก ซื้อ/รับเข้า, ใช้/เบิกออก, ตรวจนับ พร้อมวันที่, จำนวน, หน่วย, ต้นทุน (ถ้าทราบ), ผู้แจ้ง (INV-2)
- [ ] ยอดคงเหลือ = ผลรวมรับเข้า − ใช้ออก นับจากการตรวจนับครั้งล่าสุด; ตรวจนับแสดงผลต่างจากยอดที่คำนวณ
- [ ] ต้นทุนเก็บเป็นสตางค์จำนวนเต็ม; ไม่ทราบต้นทุน = "ไม่ทราบ" ไม่ใช่ 0 (NFR-3, SYNC-12)
- [ ] ผู้แจ้งเลือกได้ (เช่น อาจารย์สมหวัง) ส่วนผู้บันทึกคือผู้ใช้ที่ login (INV-3, SYNC-11)
- [ ] ดูประวัติธุรกรรมต่อรายการได้ และแก้/ลบแบบกู้คืนได้ (SYNC-9, SYNC-10)

## Offline / sync

- ธุรกรรมเป็น event แบบเพิ่มอย่างเดียว → สองเครื่องบันทึกพร้อมกันรวมกันได้โดยไม่ conflict
- การตรวจนับสองครั้งจากสองเครื่องเรียงตามเวลาที่นับ; ยอดคำนวณใหม่หลัง sync
