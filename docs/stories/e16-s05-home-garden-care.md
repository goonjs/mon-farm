# Story E16-S05: การดูแลสวนบนหน้าแรก และลำดับความสำคัญของหน้าแรก

Status: In Progress (เจ้าของ 2026-11-16 ผ่านลีด คำต่อคำ: "ในหน้าแรกก็ควรจะมีเรื่องการจัดการสวนอยู่ด้วยค่อนข้างเป็นอะไรสำคัญเหมือนกันนะลองดูระดับความสำคัญให้หน่อยแล้วก็สิ่งที่ต้องทำมันที่มันยาวเป็นบรรทัดเดียว2คอลัมน์ก็น่าจะลดความสำคัญลงหน่อย" และตอบข้อเสนอของลีดว่า "ข · เอาการดูแลสวนขึ้นไปเป็นปุ่มใหญ่บนสุดด้วย (4 ปุ่ม 2×2)" · spec จากลีด 2026-11-16 · ทำใน PR #190)

## Description

การดูแลสวนสำคัญพอ ๆ กับการขายและค่าใช้จ่าย จึงขึ้นไปอยู่กับปุ่มใหญ่บนสุด · "รายการที่ต้องจ่าย" ที่เคยเป็นแถวยาวเต็มจอใน "ไปที่" ลดลงเป็นไทล์ครึ่งจอเหมือนอันอื่น ส่วนยอดที่ต้องจ่ายขึ้นใน "ควรรู้ / ควรจัดการ" เฉพาะเมื่อมียอด

## Acceptance criteria

- [x] **HM-1** ปุ่มใหญ่บนสุด 4 ปุ่ม 2×2: แถวบน เตรียมขาย · เริ่มการขาย (ปุ่มหลัก) · แถวล่าง บันทึกค่าใช้จ่าย · การดูแลสวน (ไปหน้าการดูแลสวน) · หน้าตาแบบปุ่มเดิม
- [x] **HM-2** ปุ่มการดูแลสวนมีป้ายสั้นสีอำพัน "ยังไม่แบ่ง N ครั้ง" เมื่อมีการใส่ปุ๋ยที่ยังไม่แบ่งหรือแบ่งไม่ครบ (นับแบบป้ายในหน้าการดูแลสวน GC-2 · ไม่นับที่ลบแล้ว) · ไม่มีก็ไม่มีป้าย
- [x] **HM-3** "ควรรู้ / ควรจัดการ" แบบเดิม · ถ้ารายการที่ต้องจ่ายมากกว่า 0 มีแถว "รายการที่ต้องจ่าย" พร้อมยอดแบบสั้น (CompactMoney) แตะไปหน้ารายการที่ต้องจ่าย
- [x] **HM-4** "ไปที่" เป็นไทล์ครึ่งจอทั้งหมด ไม่มีแถวยาวเต็มจอ ตามลำดับ: สต็อกปุ๋ย | ค่าใช้จ่ายทั้งหมด · ซื้อของร้าน | รายการที่ต้องจ่าย · ข้อมูลคนงาน | รายงานการขายย้อนหลัง · พยากรณ์อากาศ (ครึ่งจอ) · ไม่มีไทล์การดูแลสวนซ้ำ · ไทล์รายการที่ต้องจ่ายไม่มียอดแล้ว (ยอดอยู่ใน HM-3)
- [x] **HM-5** ทุกปุ่มแตะได้อย่างน้อย 48 · ไม่มีอะไรถูกตัดหรือเกินขอบที่ 320 และ 360 px ตัวอักษรขนาดกลางและใหญ่
