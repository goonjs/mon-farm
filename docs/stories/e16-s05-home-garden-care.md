## Description

การดูแลสวนสำคัญพอ ๆ กับการขายและค่าใช้จ่าย จึงขึ้นไปอยู่กับปุ่มใหญ่บนสุด · "รายการที่ต้องจ่าย" ที่เคยเป็นแถวยาวเต็มจอใน "ไปที่" ลดลงเป็นไทล์ครึ่งจอเหมือนอันอื่น ส่วนยอดที่ต้องจ่ายขึ้นใน "ควรรู้ / ควรจัดการ" เฉพาะเมื่อมียอด

## Acceptance criteria

- [ ] **HM-1** ปุ่มใหญ่บนสุดกลับเป็นแบบเดิม 3 ปุ่มแถวเดียว (เตรียมขาย · เริ่มการขาย (ปุ่มหลัก) · บันทึกค่าใช้จ่าย) — ไม่มี 2×2 (เจ้าของ 2026-11-16)
- [ ] **HM-2** ไทล์การดูแลสวนใช้ไอคอนต้นกล้า (`farm.treeCondition`) แทนเครื่องมือช่าง · มีบรรทัดสั้นสีอำพัน "ยังไม่แบ่ง N ครั้ง" เมื่อมีการใส่ปุ๋ยที่ยังไม่แบ่งหรือแบ่งไม่ครบ (ไม่นับที่ลบ) · ไม่มีก็ไม่มีบรรทัดนี้
- [ ] **HM-3** "ควรรู้ / ควรจัดการ" แบบเดิม · ถ้ามีค่าใช้จ่ายที่สั่งหรือตกลงไว้แล้วยังไม่ได้จ่าย (ขั้น "ผูกพันแล้ว" ไม่รวมเงินที่สวนต้องคืน ซึ่งมีแถวของตัวเองแล้ว · เหตุผล "สั่งหรือตกลงไว้แล้ว ยังไม่ได้จ่าย" · ยอดคิดใน core `shopPayableSatang`) มีแถว "รายการที่ต้องจ่าย" พร้อมยอดแบบสั้น (CompactMoney) แตะไปหน้ารายการที่ต้องจ่าย
- [ ] **HM-4** "ไปที่" เรียงแบบเดิม: รายงานการขาย | พยากรณ์อากาศ · **รายการที่ต้องจ่าย | การดูแลสวน** (แถวการ์ดยาวเดิมกลายเป็น 2 ปุ่มสั้น) · ค่าใช้จ่ายทั้งหมด | ซื้อของร้าน · สต็อก (แถวยาว) · ข้อมูลคนงาน (แถวยาว) · ไทล์รายการที่ต้องจ่ายไม่มียอด (ยอดอยู่ใน HM-3)
- [x] **HM-6** ทุกแถวใน "ควรรู้ / ควรจัดการ" มีเหตุผลสั้น 1 บรรทัดว่าทำไมขึ้นและต้องทำอะไร · การขายที่ยังไม่ปิด: ถ้ากำลังชั่ง "ชั่งอยู่ · ชั่งเสร็จแล้วจ่ายเงินและกดปิดการขาย" ถ้าไม่ได้ชั่งแล้ว "ยังไม่ได้กดปิดการขาย · จ่ายเงินให้ครบแล้วกดปิด" (การขายปิดเมื่อกด ปิดการขาย ในหน้าจ่ายเงินเท่านั้น)
- [x] **HM-7** หน้าการดูแลสวน: สูตรปุ๋ยไม่แตกกลางสูตร ("15-15-" / "15") · แถวที่ลบแล้วจัดแบบเดียวกับแถวปกติ (บรรทัดวันที่ แล้วปุ๋ยและจำนวน) สีจาง มี "กู้คืน" แยก
- [x] **HM-5** ทุกปุ่มแตะได้อย่างน้อย 48 · ไม่มีอะไรถูกตัดหรือเกินขอบที่ 320 และ 360 px ตัวอักษรขนาดกลางและใหญ่
