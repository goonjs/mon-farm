## คำอธิบาย

เริ่มการขายจากข้อมูลหลัก ไม่ต้องพิมพ์ซ้ำ: เลือกสวน → โซน/คนกรีด → จุดชั่ง แล้วชั่งได้เลย ราคาใส่ทีหลังได้

## Acceptance criteria

- [ ] ลำดับเริ่ม: สวน → โซน/คนกรีด → จุดชั่ง → หน้าชั่ง; สลับไปจุดอื่น/สวนอื่นได้ทุกเมื่อ (SALE-1)
- [ ] โซนเป็นโซนย่อยในสวน ไม่บังคับ (MD-2, E03-S04, D-43): สวนที่ไม่มีโซน ไม่มีขั้นเลือกโซน
- [ ] หัวการขาย: วันที่ (วันนี้), ผู้ซื้อ (รายล่าสุด), ผู้จัดการ (เติมอัตโนมัติจากข้อมูลหลัก), เวลาเริ่ม (ไม่บังคับ), หมายเหตุ (SALE-2)
- [ ] ไม่มีฟิลด์สวนในหัวการขาย — เลือกสวนตอนเลือกจุดชั่ง การขายเดียวรวมหลายสวนได้ (SALE-1, D-9, D-36)
- [ ] ไม่มีฟิลด์หัวหน้าคนงาน และไม่มีตัวเลือก "ขายที่ลานล้ง" (D-10)
- [ ] ราคา ฿/กก. ใส่/แก้ได้ทุกเมื่อก่อนสรุปเงิน; การชั่งไม่รอราคา; ไม่ดึงราคาเก่า; ไม่มี %DRC (SALE-3, D-11)
- [ ] เริ่มการขายถึงเข่งแรกได้ใน ≤ 4 แตะ เมื่อใช้ค่าเริ่มต้นทั้งหมด (NFR-4)

## Dev notes

**ทำแล้ว (2026-10-09 คืน, ทีม FARM) — ต่อยอดหน้านับเข่งเดิม ไม่ทำซ้ำ, เปลี่ยนแบบเพิ่มเท่านั้น**

- `/sale/[id]/start` (mockup จอ 5): วันที่วันนี้ (พ.ศ. แตะสลับ), คนรับซื้อยางรายล่าสุด (ถูกลบ → ไม่มีค่าเริ่มต้น), ผู้จัดการสวน
  เติมจากข้อมูลฟาร์ม (คนแรกที่มีบทบาทผู้จัดการ), ราคาไม่บังคับ (ใส่ทีหลังได้, ไม่ดึงราคาเก่า), น้ำหนักยางสุทธิ/โหมดเลขเข่ง/
  ประเภทตาชั่ง ค่าเริ่มต้นจากตั้งค่ากลุ่ม, หมายเหตุ; ไม่มีฟิลด์สวน/หัวหน้าคนงาน/ขายที่ลานล้ง — "ถัดไป" = แตะเดียว
- เขียน `sale_started` เดิม + ฟิลด์ใหม่แบบ optional `managerId`, `note` (คู่กับ `buyerId` ของ E03-S01) และ `numbering_set`
  — ฟิลด์เดิมที่ AC บอกให้เอาออก (`farmName`, `workerLead`, `where`, `indexRef`) ยังอยู่ เขียนเป็นค่าว่าง/`farm` เพราะ lead สั่งให้
  การลบรอเจ้าของ
- `/sale/[id]/points` (mockup จอ 6): สวน → คนกรีดยาง (ณ วันขาย) → จุด; จุดที่ไม่มีคนกรีดแยกกลุ่มล่าง ชั่งได้ + คำเตือน (D-70);
  แตะจุด → `pointSetupPayloads` เพิ่มสวนเป็น zone และจุดเป็น pile (id เดียวกับข้อมูลหลัก ครั้งเดียว, น้ำหนักจากคู่ที่เลือก) แล้วเปิด
  **หน้านับเข่งเดิม** ที่จุดนั้น (`?pile=`) — gate ตรวจศูนย์/tare, กดค้าง, undo ใช้ของเดิมทั้งหมด
- หน้านับเข่ง: เข่งที่จุดของข้อมูลหลักได้ `pointId` + `basketNo` (E04-S01) และเสียงอ่านเลขเข่งนั้น; กองจาก setup เดิมไม่เปลี่ยน
- หน้าแรก "เริ่มการขายใหม่" → `/start`; หน้า setup เดิมยังเปิดได้ด้วย URL (e2e ของ setup ปรับให้เปิดด้วย URL)

**ยังไม่ครอบคลุม**: โซนย่อย (E03-S04 ยังไม่ทำ — สวนไม่มีขั้นโซน), เวลาเริ่มชั่ง, แนบรูปในหมายเหตุ, "≤ 4 แตะถึงเข่งแรก" ยังไม่ถึง
เพราะ gate ตรวจศูนย์/tare ของหน้านับเดิม (โหมดตรวจเป็นของ E04-S03), สลับจุดกลางการขายใช้ตัวสลับกองเดิม
