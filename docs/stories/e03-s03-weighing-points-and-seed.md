# Story E03-S03: จุดชั่ง (= กอง) และโครงสร้างตั้งต้น

- แทนที่: S27 farm profile (`src/store/farm*.ts`, `src/app/farm-profile.tsx`) — โซน+กองในเครื่อง → สวน+จุดชั่งที่ sync; คงกฎ id ถาวร (S27 Decision 1)
- ขึ้นกับ: E03-S02 (สวน), E01-S09 (ดึงข้อมูลกลุ่มครั้งแรก — ใช้ตัดสินว่าแสดงปุ่มโครงสร้างตั้งต้นหรือไม่)
- การมอบหมายคนกรีดตั้งต้น (แดง/นัด) **อยู่ E03-S05** ไม่อยู่ใน story นี้ — เพื่อตัดวง S03 ↔ S05 (S05 ขึ้นกับ S03 ทางเดียว)
- ผูกจุดชั่งกับโซน **ไม่อยู่ใน story นี้** — โซนเลื่อนออกจากลำดับแรกพร้อม E03-S04 (D-64)

## คำอธิบาย

จุดชั่งเป็น entity เดียวของสถานที่จริง (ไม่มี entity "กอง" แยก) อยู่ใต้สวน ใช้ซ้ำทุกการขาย
พร้อมปุ่มสร้างโครงสร้างตั้งต้นของสองสวน โดยให้เจ้าของใส่ชื่อเอง

## Acceptance criteria

- [ ] สร้าง / แก้ชื่อ / ลบ (กู้คืนได้) จุดชั่งใต้สวนได้ (MD-3, D-65)
- [ ] id จุดชั่งถาวร ใช้ซ้ำข้ามการขาย; ลบแล้วการขายเก่ายังอ้างถึงได้ (MD-3)
- [ ] **ชื่อจุดซ้ำในสวนเดียวกันไม่ได้** — ข้อความไทยบอกเหตุ ไม่บันทึก; สวนต่างกันใช้ชื่อเดียวกันได้ (D-65)
- [ ] จุดชั่งไม่มีค่า tare/น้ำหนักเข่งของตัวเอง — ใช้ค่ากลุ่ม (MD-7) และเปลี่ยนได้ตอนชั่งต่อการขาย/จุด
- [ ] โครงสร้างตั้งต้น: จันทเขลม — จุด 4 จุด (ของแดง 3, ของนัด 1); คลองพลู — จุด 1 จุด (ของนัด); ชื่อจุดเจ้าของเป็นผู้ใส่ ไม่มีชื่อแต่งขึ้น (MD-3)
- [ ] ปุ่มโครงสร้างตั้งต้น **แสดงเฉพาะเมื่อกลุ่มยังไม่มีจุดชั่งเลย และเครื่องนี้ดึงข้อมูลกลุ่มครั้งแรกเสร็จแล้ว** (กันสร้างซ้ำบนเครื่องที่ยังไม่เห็นจุดของเครื่องอื่น)
- [ ] จุดชั่งไม่เก็บสต็อก — เป็นสถานที่ ไม่ใช่กองยางคงค้าง (SALE-5)
- [ ] ลบจุดชั่งที่การขายที่ยังเปิดอยู่ (Draft) ใช้อยู่ → ยืนยันพร้อมบอกว่าการขายนั้นต้องเลือกจุดใหม่; ในการขายนั้น **ต้องเลือกจุดใหม่** ก่อนชั่งต่อ และตัวเลือกมีทาง **สร้างจุดใหม่ได้ทันที** (D-65)
- [ ] ลบจุดชั่ง (หรือสวนของมัน — E03-S02) ได้เสมอ ไม่ขวางเพราะรายการหักเงินคนกรีด (D-58)
- [ ] หน้า farm profile เดิม (S27) ถูกแทนด้วยหน้าจัดการสวน/จุดชั่ง ใต้ ☰ → "ข้อมูลฟาร์ม"; ลบ `src/store/farm*.ts` เมื่อไม่มีผู้ใช้ (ขอยืนยันก่อนลบไฟล์)

## Offline / sync

- สร้าง/แก้/ลบออฟไลน์ได้ Pending Sync; ทุกเครื่องในกลุ่มเห็นจุดชั่งชุดเดียวกันหลัง sync
- สองเครื่องสร้างจุดชื่อเดียวกันในสวนเดียวกันตอนออฟไลน์ (รวมกดโครงสร้างตั้งต้นทั้งสองเครื่อง) → หลัง sync เก็บไว้ทั้งคู่ **ติดธงชื่อซ้ำ** ให้เจ้าของแก้ชื่อหรือลบ (กู้คืนได้) ไม่รวมเองเงียบ ๆ (D-65)
- ลบจุดที่อีกเครื่องกำลังชั่งในการขายที่เปิดอยู่ → เครื่องนั้นเห็นหลัง sync และต้องเลือกจุดใหม่ตาม AC ข้างบน
