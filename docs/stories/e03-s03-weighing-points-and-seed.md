# Story E03-S03: จุดชั่ง (= กอง) และโครงสร้างตั้งต้น

Status: Draft

## Context

- Epic: `docs/epics/e03-master-data.md`
- PRD: MD-3, MD-2 (โซนไม่บังคับ), SALE-5
- แทนที่: S27 farm profile (`src/store/farm*.ts`, `src/app/farm-profile.tsx`) — โซน+กองในเครื่อง → สวน+จุดชั่งที่ sync; คงกฎ id ถาวร (S27 Decision 1)
- ขึ้นกับ: E03-S02 (สวน)

## คำอธิบาย

จุดชั่งเป็น entity เดียวของสถานที่จริง (ไม่มี entity "กอง" แยก) อยู่ใต้สวน ใช้ซ้ำทุกการขาย
พร้อมปุ่มสร้างโครงสร้างตั้งต้นของสองสวน โดยให้เจ้าของใส่ชื่อเอง

## Acceptance criteria

- [ ] สร้าง / แก้ชื่อ / เก็บถาวร จุดชั่งใต้สวนได้; ผูกโซนได้แต่ไม่บังคับ (MD-3, MD-2)
- [ ] id จุดชั่งถาวร ใช้ซ้ำข้ามการขาย; เก็บถาวรแล้วการขายเก่ายังอ้างถึงได้ (MD-3)
- [ ] โครงสร้างตั้งต้น: จันทเขลม — จุดของแดง 3 จุด, ของนัด 1 จุด; คลองพลู — ของนัด 1 จุด; ชื่อจุดเจ้าของเป็นผู้ใส่ ไม่มีชื่อแต่งขึ้น (MD-3)
- [ ] จุดชั่งไม่เก็บสต็อก — เป็นสถานที่ ไม่ใช่กองยางคงค้าง (SALE-5)
- [ ] หน้า farm profile เดิม (S27) ถูกแทนด้วยหน้าจัดการสวน/จุดชั่ง; ลบ `src/store/farm*.ts` เมื่อไม่มีผู้ใช้ (ขอยืนยันก่อนลบไฟล์)

## Offline / sync

- สร้าง/แก้ออฟไลน์ได้ Pending Sync; ทุกเครื่องในกลุ่มเห็นจุดชั่งชุดเดียวกันหลัง sync
- ปุ่มโครงสร้างตั้งต้นกดซ้ำจากสองเครื่องตอนออฟไลน์ อาจได้จุดซ้ำ — ต้องแสดงให้เห็นและเก็บถาวรได้ ไม่รวมเองเงียบ ๆ

## Test plan

- [ ] jest-expo: หน้าจัดการจุดชั่ง, ปุ่มโครงสร้างตั้งต้นบังคับใส่ชื่อ
- [ ] Playwright: สร้างโครงสร้างตั้งต้นออฟไลน์ → reload → ครบ 5 จุด
