## Description

ตอนเริ่มขาย ถ้ามีการเตรียมไว้ แอปเติมราคาที่ตกลงให้ แก้ได้ และคนรับซื้อที่นัดไว้ให้ แก้ได้ (D-91) ไม่ขัด SALE-3 เพราะเป็นราคาของการขายครั้งนี้ ไม่ได้ดึงจากการขายก่อน

## ที่เป็นอยู่ตอนนี้ (ดูจากแอปจริงบน dev b46124a, 2026-11-17)

- เริ่มขายได้ทางเดียว: ปุ่ม "เริ่มการขาย" บนหน้าแรก → `/v2/sale/start` (`SALE_START` ใช้ที่เดียว ไม่มีทางจากเมนูอื่น) → ถ้ามีการขายเปิดอยู่ จะเปิดอันนั้นแทน
- หน้าเริ่มขายไม่รู้เรื่องการเตรียม: ทำการเตรียมครบ (สหกรณ์บ้านนา · วันนี้ · 52.50) แล้วกดเริ่มขาย → คนรับซื้อ "ยังไม่ได้เลือก" (ค่าเริ่มต้น = ใช้ล่าสุด) ราคา "ใส่ทีหลัง" (ภาพ "ก่อน" ใน dashboard)
- หน้าเริ่มขายเขียน `sale_started` (มี `buyerId`, `day` อยู่แล้ว) และ `price_set` อยู่แล้ว → เติมค่าจากการเตรียม **ไม่ต้องมี event หรือฟิลด์ใหม่**
- การเตรียมถือว่า "ถูกใช้" เมื่อมีการขายเริ่มหลังเขียนครั้งสุดท้าย (E15-S01 PREP-8, `salePrep(events, lastSaleTs)`) และปุ่มหน้าแรกกลับปกติตามวัน (E15-S06) → ผูกด้วยเวลาอยู่แล้ว ไม่ต้องมี `prepId`

## Acceptance criteria (ร่าง — ปรับตามแอปจริง รอเจ้าของตกลง)

- [x] **PS-1** ทางเข้า: ปุ่มหน้าแรกชวนให้เริ่มเมื่อเตรียมครบ (ฟ้า + นาฬิกา) แตะ = หน้าเริ่มขายเดิม · **ทำแล้วใน E15-S06** (การ์ดเตรียมขายใหญ่ถูกเอาออก ไม่ต้องมีปุ่ม เริ่มขาย บนการ์ด)
- [ ] **PS-2** หน้าเริ่มขายเติมจากการเตรียมที่ยังไม่ถูกใช้ (mockup A): คนรับซื้อ = ที่นัดไว้ บรรทัดรอง "ที่นัดไว้ · แก้ได้" (แทน "ใช้ล่าสุด") · ราคา ฿/กก. = ราคาที่ตกลง บรรทัดรอง "ราคาที่ตกลงไว้ · แก้ได้" · วันที่ = วันนี้เหมือนเดิม (หน้านี้เลือกวันหลังวันนี้ไม่ได้) · ผู้จัดการ/น้ำหนักสุทธิ/เลขเข่งเหมือนเดิม · แตะแก้ได้ทุกช่อง · ราคาเขียนเป็น `price_set` ตามเดิม คนรับซื้อลง `sale_started.buyerId` ตามเดิม · คนรับซื้อที่นัดไว้ถูกลบไปแล้ว → ช่องว่างเหมือนไม่เคยเตรียม
- [ ] **PS-3** เมื่อไหร่เติม / ถาม — **เจ้าของตกลง ก (q1)**: เติมคนรับซื้อ + ราคาให้เลย (mockup A) เมื่อวันที่เตรียม = วันนี้ เลยมาแล้ว หรือไม่ระบุวัน · ถามก่อนเฉพาะเมื่อเตรียมไว้วันข้างหน้า: การ์ดบนสุด "ใช้ที่เตรียมไว้ไหม" ปุ่มเต็มความกว้าง "ใช้ที่เตรียมไว้" + ลิงก์ขีดเส้นใต้ "ไม่ใช้ ตั้งเอง" (mockup B) ไม่เติมเงียบ ๆ
- [ ] **PS-4** การเตรียมที่ใช้แล้วหายจากหน้าแรกเอง (ทำแล้ว: E15-S01 PREP-8 + E15-S06 ผูกด้วยเวลา) · **ไม่เก็บ `prepId` ในการขาย ไม่เปลี่ยนโครงสร้างข้อมูล — เจ้าของตกลง ก (q2)** · บรรทัด "เตรียมไว้: ราคาที่ตกลง X" ในรายละเอียดการขาย (q3): **รอเจ้าของ (q3)** ทำหรือไม่ทำ และวางที่ไหน (E รายการการขายทั้งหมด / F หน้าจ่ายเงิน · ปิดการขาย) · ถ้าทำ อ่านย้อนจาก `sale_prep_set` ที่เขียนก่อนเวลาเริ่มขาย ไม่เปลี่ยน schema
- [ ] **PS-5** ตอนปิดการขาย หักหนี้ตามเดิม (CO-3 เสนอยอดตามแผนผ่อนเดิม) — หนี้ปุ๋ยที่เพิ่งแบ่งในข้อ 4 อยู่ในยอดค้างแล้ว ไม่มีขั้นใหม่
- [ ] **PS-6** การเตรียมไม่ได้ใส่ราคา → **เจ้าของตกลง ก (q4)**: เติมแค่คนรับซื้อ ช่องราคาว่าง "ใส่ทีหลัง" เหมือนเดิม (mockup C) ใส่ราคาได้ทุกเมื่อก่อนสรุปเงิน (SALE-3 เดิม)
- [ ] **PS-7** ไม่มีการเตรียม หรือถูกใช้ไปแล้ว: หน้าเริ่มขายเหมือนเดิมทุกอย่าง (mockup D) ทดสอบว่าไม่เปลี่ยนผลของผู้เรียกอื่น

## Offline / sync behavior

- ทำได้ออฟไลน์ · อ่านการเตรียมจาก event ในเครื่อง (`sale_prep_set`) ไม่เขียนอะไรใหม่ · ไม่มี event/ฟิลด์ใหม่ (ถ้าเจ้าของเลือกเก็บ `prepId` จึงจะเป็น schema ใหม่ + PR สำคัญ)
