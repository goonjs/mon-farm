## Description

ตอนเริ่มขาย ถ้ามีการเตรียมไว้ แอปเติมราคาที่ตกลงให้ แก้ได้ (D-91; เติมคนรับซื้อด้วยเป็นค่าแนะนำ) ไม่ขัด SALE-3 เพราะเป็นราคาของการขายครั้งนี้ ไม่ได้ดึงจากการขายก่อน

## Acceptance criteria (ร่าง)

- [ ] **PS-1** การ์ด "เตรียมขาย" ที่มีวันที่ = วันนี้ (หรือเลยมาแล้ว) มีปุ่มหลัก "เริ่มขาย" → หน้าเริ่มขายเดิม
- [ ] **PS-2** หน้าเริ่มขายเติม: ราคา ฿/กก. = ราคาที่ตกลง พร้อมคำบอกที่มา "ราคาที่ตกลงไว้ · แก้ได้" (D-91) · (แนะนำ) คนรับซื้อ = ที่นัดไว้ แทนค่าเริ่มต้น "รายล่าสุด" (SALE-2) · วันที่ = วันนี้ · แก้ได้ทุกช่องเหมือนเดิม
- [ ] **PS-3** (แนะนำ) เริ่มขายจากเมนูปกติขณะมีการเตรียมอยู่ → ถาม "ใช้ที่เตรียมไว้ไหม" (ใช้ / ไม่ใช้) ไม่เติมเงียบ ๆ
- [ ] **PS-4** การเตรียมผูกกับการขายที่เริ่ม (เก็บ `prepId` ในการขาย) แล้วการ์ดเตรียมขายหายจากหน้าแรก · ดูได้ในรายละเอียดการขายว่า "เตรียมไว้: ราคาที่ตกลง X"
- [ ] **PS-5** ตอนปิดการขาย หักหนี้ตามเดิม (CO-3 เสนอยอดตามแผนผ่อนเดิม) — หนี้ปุ๋ยที่เพิ่งแบ่งในข้อ 4 อยู่ในยอดค้างแล้ว ไม่มีขั้นใหม่
- [ ] **PS-6** ราคาไม่ใส่ตอนเตรียม → ช่องราคาว่าง ใส่ได้ทุกเมื่อก่อนสรุปเงิน (SALE-3 เดิม)

## Offline / sync behavior

- ทำได้ออฟไลน์ · `prepId` เป็นฟิลด์ของการขาย · สองเครื่องเริ่มขายจากการเตรียมเดียวกัน → ทั้งสองการขายผูก prep เดียวกัน แสดงธงให้รวม/ลบหนึ่งการขาย (กติกาซ้ำเดิม E04-S14)
