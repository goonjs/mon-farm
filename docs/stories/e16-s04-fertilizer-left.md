## Description

ปุ๋ยคงเหลือคือสต็อกปุ๋ย ไม่ต้องนับหรือเก็บตัวเลขแยก: **รับเข้า** = รายการปุ๋ยในใบซื้อที่ได้ของแล้ว · **ใช้ออก** = การใส่ปุ๋ย ตัวเลขนี้คือรายการที่หน้าใส่ปุ๋ยใช้ให้เลือก (E16-S02 FZ-2) สตอรี่นี้เพิ่มหน้าดูคงเหลือและธงใส่เกิน

## Acceptance criteria

- [ ] **FL-1** คงเหลือ **ต่อการ์ด (ชนิด + ราคาต่อถุง, D-92/D-94)** = Σ ถุงที่ได้ของแล้ว − Σ ถุงที่ใส่ไปแล้ว (ไม่นับที่ลบ) · จะแสดงยอดรวมต่อชนิดเพิ่มก็ได้ แต่ตัวเลขหลักและธงใส่เกิน (FL-3) คิดต่อการ์ด · ทุกที่ในแอปใช้ตัวเลขเดียวกับ "N ในสต็อก" ของ E16-S02 (รีวิวอิสระ 2026-11-08)
- [ ] **FL-2** หน้าปุ๋ยคงเหลือ (ไอคอน `materials.stock`): รายการชนิด · คงเหลือ · บรรทัดรองมาจากใบไหน · "สั่งไว้ยังไม่ได้ของ N ถุง" แยกบรรทัด
- [ ] **FL-3** **ใส่เกิน** (คงเหลือติดลบ จากสองเครื่องออฟไลน์ หรือแก้ใบต้นทางให้น้อยลง): ธงสีอำพันมีคำ "ใส่เกินที่ได้ของ N ถุง" ที่หน้าคงเหลือ หน้าการดูแลสวน และการใส่ปุ๋ยที่เกี่ยว · แตะไปแก้ได้ · ไม่ตัดหรือแก้ให้เอง
- [ ] **FL-4** **วันตัด 1 ต.ค. 2026** (D-96): ใบซื้อที่ **วันที่ของใบ** อยู่ก่อน 1 ต.ค. 2026 (ไม่รวมวันที่ 1) ถือว่าใช้หมดแล้ว ไม่นับเป็นสต็อก ไม่ว่าจะสร้างใบเมื่อไหร่ · ใบตั้งแต่ 1 ต.ค. 2026 ที่ได้ของแล้วนับเป็นคงเหลือจนกว่าจะบันทึกใส่ปุ๋ย · การแบ่งบนใบซื้อแบบเดิมไม่นับเป็นใช้ออก (ยกเลิกตาม D-89 / E11-S17) · ตอนเปลี่ยนใบเป็น "ได้ของแล้ว" **ไม่ถามวันที่** — ผู้ใช้แก้วันที่ของใบเองได้ (เจ้าของเลือก ก 2026-11-13)
