## Description

ก่อนวันขาย เจ้าของเตรียม 4 ข้อ: นัดคนรับซื้อ · วันที่ (และเวลา) · ราคาที่ตกลงกัน · แบ่งปุ๋ยที่ยังไม่ได้แบ่งให้คนกรีดให้เรียบร้อย เพื่อวันขายจะหักหนี้ได้ แอปเก็บการเตรียมนี้ไว้ แล้วตอนเริ่มขายเติมให้ (E15-S02)

## Acceptance criteria (ร่าง)

- [ ] **PREP-1** ทางเข้า: การ์ด "เตรียมขาย" บนหน้าแรก (D-45) · ยังไม่ได้เตรียม = "เตรียมการขายครั้งถัดไป ›" · เตรียมอยู่ = วันที่ + คนรับซื้อ + "เหลือ N ข้อ" (ครบ = ✓ พร้อมขาย)
- [ ] **PREP-2** หน้าเตรียมขายหน้าเดียว (390×844 ไม่เลื่อน): 4 แถว แต่ละแถวมีสถานะ ☐/✓ ทั้งแถวเป็นที่แตะ (ไม่มีปุ่มวงกลมคำสั้น)
- [ ] **PREP-3** ข้อ 1 **นัดคนรับซื้อ**: เลือกจากรายชื่อคนรับซื้อ (ล่าสุดอยู่บน) หรือ + เพิ่มใหม่ · ✓ เมื่อเลือกแล้ว · บันทึกข้อความการคุยสั้น ๆ ได้ (ไม่บังคับ)
- [ ] **PREP-4** ข้อ 2 **วันที่**: ปฏิทินในแอป + เวลา (ไม่บังคับ) · ✓ เมื่อมีวันที่ · วันที่ผ่านไปแล้วยังไม่ขาย → การ์ดหน้าแรกบอก "เลยวันนัดแล้ว"
- [ ] **PREP-5** ข้อ 3 **ราคาที่ตกลง** ฿/กก. ด้วยแป้นตัวเลขในแอป (ทศนิยม 2 ตำแหน่ง) · ✓ เมื่อใส่แล้ว
- [ ] **PREP-6** ข้อ 4 **แบ่งปุ๋ยให้คนกรีด**: แอปนับการใส่ปุ๋ยที่ยังไม่แบ่ง (E16, ป้าย "ยังไม่แบ่ง"; แบ่งไม่ครบนับด้วยไหม ขึ้นกับ E16-S03 ประเด็นค้าง ข้อ 1) · มี → แถวบอก "ใส่ปุ๋ยยังไม่แบ่ง N ครั้ง" แตะ → รายการครั้งนั้น ๆ → หน้าแบ่ง (E16-S03 เดียวกัน) · ไม่มี → ✓ "แบ่งครบแล้ว" อัตโนมัติ · **ไม่มีการตั้งงวดผ่อนในข้อนี้** (D-91)
- [ ] **PREP-7** ข้อ 4 แสดงผลหลังแบ่งแบบสั้น: คนกรีดที่มีหนี้ปุ๋ยใหม่ (ตามกฎบรรทัดสรุป: เกิน 2 คนบรรทัดละ 2, Σ บรรทัดของตัวเอง, ย่อ k/m) — เพื่อให้รู้ว่าวันขายจะมีหนี้ให้หัก ไม่ใช่ตั้งยอดหัก
- [ ] **PREP-8** เตรียมได้ทีละ 1 การขาย (การขายครั้งถัดไป) · ยกเลิกการเตรียมได้ (กู้คืนได้)
- [ ] **PREP-9** ข้อไม่ครบก็เริ่มขายได้ (E15-S02) — เช็คลิสต์ช่วยเตรียม ไม่ใช่ประตูกั้น · ไม่มีข้อความกันลืม
