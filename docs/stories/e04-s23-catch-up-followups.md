## Description

1. ในรายการเข่ง เข่งที่เชื่อมจากหลายส่วน (เติมเข่งไม่เต็มจนเต็ม) อ่านออกทันที: คำว่า "เต็ม (เข่งเชื่อม)" · เลขเข่งอยู่ในวงกลมแดง · แท็ก "เข่งเชื่อม" สีต่างจากแท็ก "บันทึกย้อนหลัง"
2. หน้า "เปลี่ยนจุด" (ปัจจุบันซ่อนลิงก์ "มาช้า? บันทึกย้อนหลังของ …" กับเมนู ⋯ → "บันทึกย้อนหลัง") แสดงทั้งสองอย่างให้คนกรีดที่เลือก เหมือนหน้าเลือกจุดตอนเริ่ม
3. เมื่อบันทึกย้อนหลังของจุดแล้ว กดนับต่อที่จุดนั้นได้เลย ไม่ขึ้น "ตรวจตาชั่งก่อน" ไม่ว่าตั้งค่าตรวจไว้แบบไหน · การตั้งค่าตรวจยังใช้กับจุดถัดไปที่ยังไม่เคยชั่ง ตามเดิม

## Acceptance criteria

- [ ] **JB-1a** แถวเข่งในรายการเข่ง (`history-screen.tsx`): เข่งเชื่อม (มีหลายส่วน) ขึ้น "เต็ม (เข่งเชื่อม)" แทน "เต็ม" · เข่งไม่เชื่อมเหมือนเดิม
- [ ] **JB-1b** เลขเข่งของเข่งเชื่อมอยู่ในวงกลมสีแดง (ตัวเลขสีขาว คอนทราสต์ผ่าน) · เข่งที่ถูกยกเลิก/ลบ ไม่ใช้วงกลมแดง (ขีดฆ่าเหมือนเดิม) · วงกลมไม่ทำให้ตัวเลข 3 หลักเกินขอบ
- [ ] **JB-1c** แท็ก "เข่งเชื่อม" ใช้โทนเตือน (เหลืองอำพัน) ต่างจากแท็ก "บันทึกย้อนหลัง" (เทา) · ยังมีไอคอน+คำ ไม่ใช้สีอย่างเดียว
- [ ] **JB-2a** หน้า "เปลี่ยนจุด" (`?mode=switch`) มีลิงก์ "มาช้า? บันทึกย้อนหลังของ <คนกรีด>" ใต้จุดของคนกรีดที่เลือก · แตะแล้วเข้าหน้า "ชั่งจุดไหนก่อนหลัง" ของคนกรีดนั้น (BF-13)
- [ ] **JB-2b** เมนู ⋯ ของหน้า "เปลี่ยนจุด" มี "บันทึกย้อนหลัง" ของคนกรีดที่เลือก
- [ ] **JB-2c** ทำซ้ำได้: บันทึกย้อนหลังของแดงแล้ว เปลี่ยนจุด เลือกนัด → ลิงก์และเมนูขึ้น · นัดที่ยังไม่มีเข่งกรอกได้ · คนกรีดที่มีเข่งแล้วเข้าไปเจอข้อความ "กรอกไม่ได้" ของ BF-8 (ไม่ซ่อนลิงก์)
- [ ] **JB-3a** หลังบันทึกย้อนหลัง ทุกจุดที่กรอกพร้อมนับ (บันทึก event `ready` ของจุด) · หน้านับเปิดนับได้เลย ไม่ขึ้นการ์ด "ยังไม่พร้อม / ตรวจตาชั่ง"
- [ ] **JB-3b** เลือกจุดนั้นซ้ำจากหน้าเลือกจุด/เปลี่ยนจุด ไม่ขึ้นหน้าตรวจตาชั่ง (กฎเดิม: จุดที่มีเข่งแล้วข้ามการตรวจ) แม้การขายเคยมีค่าเอียงของเข็มตาชั่ง (skew)
- [ ] **JB-3c** การตั้งค่าตรวจตาชั่งยังใช้กับจุดถัดไป: โหมด "ตรวจจุดแรกของสวน" — จุดที่กรอกย้อนหลังอย่างเดียวไม่นับเป็น "จุดแรกที่ตรวจแล้ว" จุดอื่นในสวนเดียวกันที่ยังไม่เคยชั่งจึงยังถูกถาม · โหมด "ทุกจุด/ข้าม" ใช้ตามเดิม
