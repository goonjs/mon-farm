## Dev notes

- ติ๊กเก็บใน finance log: `payment_mark_set {saleId, payee, done, amountSatang}` targetId `payment-<saleId>-<payee>` (payee = personId หรือ `owner`) — additive ไม่แตะ sale log; ใคร/เมื่อไร/เครื่องไหน มาจาก envelope ของ event
- ยอดของเจ้าของ = ส่วนเจ้าของหลังปัดเศษ + หนี้ที่คนรับซื้อยางโอนรวมกับส่วนเจ้าของ (D-71 วิธี 3); ยอดคนกรีด = เงินสดหลังหัก/ปัดเศษ
- การ์ดการจ่ายขึ้นเมื่อยอดสุดท้ายแล้ว (ตอบคำถามปัดเศษแล้ว — ?B1)
- รอ FARM: `sale_status_set` (ปุ่มปิดการขาย/Completed) และ `money_edit` — จะต่อเมื่อ FARM push รูปแบบ
