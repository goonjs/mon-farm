## คำอธิบาย

หลังชั่งครบทุกจุด ใส่ กก. / ยอดเงิน (และจำนวนเข่งถ้ามี) ที่ผู้ซื้อแจ้ง แล้ววางเทียบกับ
ยอดของเรา ถ้าต่าง เจาะลงถึงเข่งเพื่อแก้ ถ้ายังต่าง ปิดเป็น Difference found + เหตุผล

## Acceptance criteria

- [ ] **ไม่มีช่องกรอกยอดผู้ซื้อวางเทียบข้าง** (D-72): แสดงยอดเรา (กก., ราคา/กก., ยอดเงิน, จำนวนเข่ง) แล้วมีปุ่ม **"ตรงกันทั้งหมด"** → บันทึกยอดผู้ซื้อ = ยอดเรา + สถานะ "ยอดผู้ขายและผู้ซื้อตรงกัน" ในกดเดียว
- [ ] ปุ่ม **"ไม่ตรงกัน"** → เจาะถึงเข่งเพื่อแก้ หรือปิดเป็น "พบส่วนต่าง" + เหตุผล (MVP); ตัวช่วยหาว่าผู้ซื้อคิดผิดตรงไหน (A/B ใน D-72) เป็นงานหลัง MVP ไม่อยู่ใน story นี้
- [ ] เจาะลึกได้: การขาย → จุดชั่ง → เข่ง → ส่วนของเข่งเชื่อม แล้วแก้เข่งจากตรงนั้น (SET-3)
- [ ] เงินคำนวณจากเข่งที่บันทึกเสมอ ไม่ใช้ยอดผู้ซื้อแทน (D-15)
- [ ] สถานะการตรวจ: Pending · Weight verified · Sale total verified · Difference found (SET-6); คำไทย: "รอตรวจสอบเทียบยอด" · "ยืนยันน้ำหนักรวมตรงกัน" · "ยอดผู้ขายและผู้ซื้อตรงกัน" · "พบส่วนต่าง" (คำตอบเจ้าของ 2026-10-03)
- [ ] เข้าหน้านี้จาก "ชั่งครบแล้ว → ตรวจยอด" (เมนู ⋯ ของหน้าชั่ง และหน้าเปลี่ยนจุดชั่งเมื่อทุกจุดชั่งมีบันทึก — E04-S05)
- [ ] Difference found ต้องมีเหตุผล; ส่วนต่างถูกบันทึกไว้ ไม่เกลี่ยเงียบ ๆ
- [ ] แก้เข่งหลังตรวจแล้ว → สถานะการตรวจกลับเป็น Pending (ติดธงให้ตรวจใหม่)
