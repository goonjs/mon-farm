## Dev notes

- เก็บผลตรวจใน finance log (`buyer_check_set`, targetId `buyer-check-<saleId>`) — แบบเดียวกับการปัดเศษ/บัญชีรับเงิน ไม่แตะ sale log (additive เท่านั้น ตามคำสั่ง lead)
- event จำ `basis` = ยอดเราตอนตรวจ; ถ้ายอดเราเปลี่ยนภายหลัง (void เข่ง, เข่ง sync เข้ามาช้า) → แสดงเป็น "รอตรวจสอบเทียบยอด" + ธง "ตรวจใหม่" เอง ไม่ต้องเขียน event (ใช้ได้ทั้งออนไลน์/ออฟไลน์). "น้ำหนักตรง" ยังคงอยู่ถ้าเปลี่ยนแค่ราคา; "ตรงกันทั้งหมด"/"พบส่วนต่าง" ไม่คงอยู่
- สองเครื่องบันทึกผลเดียวกัน → รวมได้; ผลต่างกัน → Conflict ค้างไว้ที่ Pending จนกว่าจะบันทึกใหม่ (บันทึกใหม่อิงทุก head)
