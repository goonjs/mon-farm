## คำอธิบาย

ตอนนี้บันทึกเข่งไปแล้วดูย้อนไม่ได้ ไม่รู้ว่าเข่งไหนเต็ม เข่งไหนไม่เต็ม บันทึกเมื่อไร และปุ่มย้อนกลับ (แตะครั้งเดียว) ลบเข่งล่าสุดโดยไม่บอกว่าเข่งไหน
story นี้เพิ่ม **ประวัติการบันทึกเข่ง** (อ่านอย่างเดียว) จัดแถบปุ่มล่างของหน้านับเข่งใหม่ และเปลี่ยน **ย้อนกลับเป็นกดค้าง** เท่ากับปุ่มนับเข่ง

คำตอบเจ้าของ (2026-10-11):
- แถบปุ่มล่างเรียงซ้าย→ขวา: **ย้อนกลับ · ประวัติ (ไอคอนนาฬิกา) · เข่งไม่เต็ม** (เข่งไม่เต็มอยู่ขวาสุด); **โหมดสาธารณะย้ายไปเมนู ⋯**; ใช้กับหน้านับเข่งทุกหน้า
- ไม่เพิ่มการ์ดหรือแถบใหม่บนหน้านับเข่ง
- ย้อนกลับต้องกดค้างเท่าเวลากดค้างนับเข่ง มีแถบ animate ให้เห็นเหมือนกัน
- ย้อนกลับ = ยกเลิกเข่งล่าสุดแล้วใช้เลขเดิมนับซ้ำ **ไม่มีการข้ามเลข**
- เวลาที่บันทึกแสดง **วินาที** (ชั่วโมง:นาที:วินาที)

คำตอบเจ้าของเพิ่ม (2026-10-11): ตัวกรองคนกรีดยางเริ่มที่ **ทุกคน**; ตกลงข้อเสนอ "ลดความผิดพลาด + ตรวจสอบได้"; ดูเฉพาะการขายที่เปิดอยู่ ไม่ข้ามการขาย (ค่าตั้งต้น)

เป้าหมายเพิ่ม (ลดความผิดพลาด + ผู้ใช้ตรวจสอบได้ว่าทำอะไรไปบ้าง): ปุ่มย้อนกลับบอกเลขเข่งที่จะลบ · คีย์บอร์ด/AT ต้องยืนยันก่อนย้อน · บรรทัดยืนยันหลังบันทึกเข่ง · ประวัติแสดงเข่งที่ถูกย้อนกลับพร้อมเวลา · สมการยอดรวม · ตรวจเลขเข่งขาด/ซ้ำ · ยอดสะสมต่อแถว

## Acceptance criteria

- [ ] แถบปุ่มล่างของหน้านับเข่งทุกหน้า (ปกติ, จุดที่ยังไม่มีคนกรีด, เข่งไม่เต็มเปิดอยู่/เติมเข่ง, มีค่าเบี้ยว) เรียงซ้าย→ขวา: ย้อนกลับ · ประวัติ · เข่งไม่เต็ม; ไม่มีปุ่มโหมดสาธารณะในแถบ
- [ ] เมนู ⋯ มี "โหมดสาธารณะ" (เปิดหน้าเดิม คงจุดและ `fill`); โหมดสาธารณะเองไม่เปลี่ยน
- [ ] ปุ่มย้อนกลับบอกเลขเข่งที่จะย้อน ("กดค้าง · เข่ง N"; ไม่มีเข่ง → "กดค้าง" และกดไม่ได้); กดแบบไม่มีการกดค้าง (คีย์บอร์ด Enter/Space, TalkBack activate) → ถาม "ย้อนกลับเข่ง N ไหม?" [ยกเลิก] [ย้อนกลับเข่ง N] ก่อนทำ
- [ ] หลังกดค้างนับเข่งสำเร็จ ขึ้นบรรทัดข้อความ 4 วินาที "บันทึกเข่ง N · X กก." (live region สำหรับโปรแกรมอ่านหน้าจอ; ไม่เพิ่มการ์ด)
- [ ] ปุ่มย้อนกลับ: แตะครั้งเดียวหรือปล่อยก่อนครบเวลา = ไม่ทำอะไร; กดค้างครบ `readHoldMs()` (เท่านับเข่ง, D-7/D-79) = ย้อนกลับเข่งล่าสุด; ระหว่างกดมีแถบ progress วิ่งตามเวลา (ใช้ตัวเดียวกับปุ่มนับ ไม่เขียนซ้ำ); ผู้ใช้โปรแกรมอ่านหน้าจอ/คีย์บอร์ดทำได้เท่ากัน
- [ ] ย้อนกลับแล้วเลขเข่งถัดไปเท่าเลขที่ถูกย้อน (ไม่ข้าม) และขึ้นข้อความสั้น "ย้อนกลับเข่ง N แล้ว — เข่งถัดไปคือ N"; ไม่มีเข่งให้ย้อน (หรือยังไม่พร้อมชั่ง) → ปุ่มกดไม่ได้
- [ ] ปุ่มประวัติเปิดหน้า "รายการเข่ง" ของการขายนั้น (`/v2/sale/<id>/history?point=`), เรียงใหม่สุดก่อน, ใช้ได้ออฟไลน์
- [ ] สรุปบนสุด: เต็ม · ไม่เต็ม · รวม กก. **ตามตัวกรองที่เลือก** (บวกกันได้เท่าแถวข้างล่างเสมอ); ตัวกรองเริ่มต้น "ทุกคน" ตรงกับยอดการขาย; เลือกคนกรีดแล้วตรงกับยอดของคนนั้นบนหน้านับเข่ง **ในโหมดนับต่อเนื่องตามคนกรีดยาง** (โหมดเริ่มนับ 1 ทุกจุด หน้านับเข่งนับต่อจุด ส่วนรายการนับต่อคน — ผลรวม กก. ยังเท่ากัน); เข่งเชื่อมที่ยังเปิดอยู่นับเป็น "ไม่เต็ม" (ใช้ `basketList` เดิม ไม่คำนวณเงินใหม่)
- [ ] ตัวกรองชนิด (ทั้งหมด/เต็ม/ไม่เต็ม) และคนกรีดยาง (เริ่มที่ "ทุกคน"); กรองแล้วไม่เจอขึ้นข้อความ + ล้างตัวกรอง; ยังไม่มีเข่งขึ้นข้อความว่าง
- [ ] ทุกแถวแสดง: เลขเข่ง · ชนิดเต็ม/ไม่เต็ม (ไอคอน + คำ) · น้ำหนักสุทธิ · จุดและคนกรีดยาง · **เวลา ชม:นาที:วินาที** (เวลาฟาร์ม UTC+7); เข่งไม่เต็มแสดง "ตาชั่งอ่าน − เข่ง = สุทธิ"; เข่งเชื่อมแสดงป้าย "เข่งเชื่อม" เพิ่มจากคำเต็ม/ไม่เต็ม และส่วน "(20 + 30)" (เข่งเชื่อมถูกนับที่คนกรีดของจุดแรกของเข่ง); เข่งบันทึกย้อนหลังติดป้าย "บันทึกย้อนหลัง"; เข่งที่ถูกยกเลิก (void) เดิมในข้อมูลเก่าแสดงขีดฆ่า + คำ "ยกเลิกแล้ว" ไม่นับในยอด
- [ ] เข่งที่ถูกย้อนกลับ **ยังอยู่ในรายการ** ขีดฆ่า + "ถูกย้อนกลับ ชม:นาที:วินาที" ไม่นับในสรุป/สมการ/ยอดสะสม/ตรวจเลข (เลขเดิมถูกใช้ซ้ำโดยเข่งถัดมา)

- [ ] ตรวจเลขเข่งอัตโนมัติ (ทั้งการขาย ไม่ตามตัวกรอง): ต่อเนื่อง 1…n ในแต่ละช่วงเลข (คนกรีดหรือจุด ตามโหมด) → "เลขเข่งต่อเนื่อง ไม่ขาด ไม่ซ้ำ"; ขาดหรือซ้ำ → แถบเตือนบอกคนกรีด/จุดและเลขที่ผิด

- [ ] เวลามีวินาทีในทุกที่ที่แสดงเวลาบันทึกเข่ง (ประวัติ; mockup ทุกหน้า)

## คำถามเจ้าของ (ตอบแล้ว 2026-10-11)

- ยกเลิกเข่งกลางทางจากรายการ → **ไม่ให้ทำ** (ขัดกฎไม่ข้ามเลข); ย้อนได้เฉพาะเข่งล่าสุด; แก้น้ำหนักพร้อมเหตุผลเป็นของ E04-S09 ขั้นถัดไป
- ตัวกรองคนกรีดยางเริ่มที่ → **ทุกคน**
- ย้อนกลับด้วยคีย์บอร์ด/AT → **ถามยืนยันก่อน**

## งานต่อ (story ถัดไป)

- "บันทึกการทำงาน": ไทม์ไลน์ทุกชนิดการกระทำ (บันทึกเข่ง เติมเข่ง ย้อนกลับ บันทึกย้อนหลัง เปลี่ยนจุด ตั้งราคา) พร้อมผู้บันทึกและเครื่อง (SYNC-9)
- ปุ่ม "ยกเลิกการย้อนกลับ" ภายในไม่กี่วินาที · ใบสรุปการชั่งเป็นรูป/ข้อความส่งคนรับซื้อ
