## ทำไม (เจ้าของ 2026-11-06)

แบบเดิมต้องกด "เพิ่มคนกรีด" ทีละคนทุกรายการ และคนแรกได้เลขเต็มไปก่อน ต้องมานั่งแก้ ให้ขึ้นคนกรีดทุกคนมาเลย เริ่มที่ 0 คนที่ไม่รับก็ไม่ต้องกรอก

## Acceptance criteria (ร่าง)

- [ ] **SP-1** เปิดจากแถว "แบ่งให้คนกรีด" ของการใส่ปุ๋ย (E16-S02) หรือจากเช็คลิสต์เตรียมขาย (E15-S01 PREP-6) — หน้าเดียวกัน
- [ ] **SP-2** ขึ้น **คนกรีดทุกคนที่ยังทำงาน** มาให้เลย ทุกคน **เริ่มที่ 0** · ไม่มีปุ่ม "เพิ่มคนกรีด" · ไม่มีใครได้เลขเต็มอัตโนมัติ
- [ ] **SP-3** หลายรายการในครั้งเดียว: แถบบนเลือกรายการ (ไอคอน FarmMate + ชื่อ + ราคาต่อถุง + จำนวนถุง + "ยังไม่แบ่ง" / "แบ่งไม่ครบ" / "ครบ") แบ่งทีละรายการ — ชนิดเดียวกันคนละราคาเป็นคนละรายการ (D-92)
- [ ] **SP-4** แตะช่องเลขของคน → แป้นตัวเลขในแอป (หัวข้อ "{ชื่อ} รับกี่ถุง" + "เหลือให้แบ่ง N ถุง") · ปุ่มลัด "ที่เหลือทั้งหมด N" และ "0 ไม่รับ" · กดเลขแรกแทนที่เลขเดิม · ไม่ใช้คีย์บอร์ดเครื่อง ไม่มีปุ่ม ± (กฎเจ้าของ)
- [ ] **SP-5** แถบสรุป "แบ่งแล้ว X / N ถุง · เหลือ Y" · ครบ = สีเขียว ✓ · เกิน = สีเหลือง "เกิน Z ถุง" และกดเสร็จไม่ได้
- [ ] **SP-6** ปุ่ม "เสร็จ" กดได้เมื่อมีอย่างน้อย 1 คน > 0 · ลิงก์รอง (ขีดเส้นใต้) **"ยังไม่แบ่ง"** ออกไปก่อนโดยไม่บันทึกการแบ่ง แสดงเฉพาะตอนยังไม่มีใครได้ถุง (D-89 Q5b) · แบ่งไม่ครบ ดู SP-6b
- [ ] **SP-6b** **แบ่งไม่ครบ** (D-92, D-93): แถบสรุปเป็นสีเหลือง มีคำ "แบ่งไม่ครบ X / N ถุง · เหลือ Y" · กด "เสร็จ" → sheet ยืนยัน "ยังแบ่งไม่ครบ · เหลือ Y ถุง ไม่มีใครรับ" มี 2 ปุ่ม: **"คืน Y ถุงเข้าสต็อก"** (ยังไม่ได้ใส่จริง — การใส่ครั้งนี้ลดเหลือ N−Y ถุง ถุงกลับเป็นปุ๋ยคงเหลือ E16-S04) และ **"สวนใส่เอง Y ถุง"** (ใส่ไปแล้ว ไม่มีใครเป็นหนี้ เป็นค่าใช้จ่ายสวนทั้งหมด; การใส่ครั้งนี้นับว่าแบ่งครบ เตรียมขายไม่เตือน) · ลิงก์รอง "กลับไปแบ่งต่อ" (mockup A4)
- [ ] **SP-7** ส่วนของคนกรีดตั้งต้น 50% (FERT-4, จากหมวด) แก้ได้รายคนใน sheet รายละเอียด · วิธีคืน: หักตอนขายยาง (ค่าเริ่มต้น) หรือจ่ายสดแล้ว
- [ ] **SP-8** **หนี้เกิดเมื่อบันทึกการแบ่ง** · **การใส่ปุ๋ย 1 ครั้ง = หนี้ 1 ก้อนต่อคน** (รวมทุกชนิดปุ๋ยในครั้งนั้น ไม่แยกตามใบซื้อ) · ในประวัติหนี้แสดง "ใส่ปุ๋ย {วันที่} · ดีเกลือ 40 ถุง · 15-15-15 5 ถุง" ยอด = Σ ค่าถุงที่ได้ × ส่วนของคนกรีด (D-89)
- [ ] **SP-9** ก้อนหนี้เป็นรายการในประวัติ — ยอดค้างรวมและแผนผ่อนยังเป็นชุดเดียวต่อคน (D-59, D-89 Q10; ผ่อนกี่งวด D-88 อยู่ใน PR #154 ยังไม่ merge) · **ประวัติหนี้บอกว่าก้อนไหนหักหมดแล้ว** (D-92): ป้ายเขียว "หักหมดแล้ว" มีคำ · ก้อนที่หักไปบางส่วนบอก "เหลือ ฿ X"
- [ ] **SP-10** แก้การแบ่ง/ราคาต้นทาง/ลบการใส่ปุ๋ยทีหลัง → ก้อนหนี้คำนวณใหม่ และมีบรรทัดในประวัติหนี้บอกว่าเปลี่ยน · ถ้าหักไปแล้วเกินยอดใหม่ ใช้กติกาหักเกิน (D-61)
- [ ] **SP-11** แถวคนกรีดไม่มีปุ่มวงกลมคำสั้น (กฎเจ้าของ 2026-11-06 ข้อ 11); ไม่มีข้อความกันลืม — ใช้ปุ่มที่กดไม่ได้แทน

## Offline / sync behavior

- การแบ่งเก็บใน event ของการใส่ปุ๋ย (`tappers[{worker, sacks, workerPct, settle}]` ต่อชนิดปุ๋ย) เป็นฟิลด์ที่ตรวจการขัดกัน (เงิน/จำนวน D-30)
- หนี้เป็น projection id `<fzId>:<workerId>` (ก้อนเดียวต่อคนต่อครั้ง) — ไม่เขียน `debt_added`
- ใบต้นทางยังไม่ได้ของ (เพราะ sync จากอีกเครื่อง) → ก้อนหนี้แสดง "รอของ" ไม่นับในยอดค้างจนได้ของ
