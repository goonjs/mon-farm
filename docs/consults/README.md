# Consults

Advice, not decisions.

Each file here is a written opinion from someone consulted about a question
the project had to answer — a domain practitioner, a bookkeeper, a reporting
designer. They are kept because the *reasoning* behind a scope decision is
worth more later than the decision alone, and because an opinion that was
overruled is part of the record too.

**Nothing in this directory is agreed scope.** A consult becomes scope only
when it is carried into `docs/prd.md`, an epic, or a story, and the owner has
said yes to it there. Where a consult and an agreed doc disagree, the agreed
doc wins and the consult stays as written — it is not edited to match a
decision that went the other way.

Consults are also allowed to say "I don't know". Each one here was asked to
flag uncertainty rather than guess, and the flagged questions are for the
owner to answer from their own farm, not for the project to assume.
