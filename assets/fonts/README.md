# Fonts

- **Noto Sans Thai** — weights 400, 500, 600, 700, 800 (only the weights
  `design/tokens.ts` `font.weight` uses). Shipped inside the app bundle from
  `@expo-google-fonts/noto-sans-thai` (loader MIT; font files SIL Open Font
  License 1.1 — full text in `OFL.txt`). Loaded in `src/theme/fonts.ts`;
  never fetched from the network (E01-S13).
- **Feather** line icons — via `@expo/vector-icons` (MIT), also bundled.
