# AGENTS.md

The rules for every agent working in this repo (Claude, Gemini, ChatGPT/Codex,
Copilot, Cursor or any other) are in [CLAUDE.md](./CLAUDE.md). Read it before
creating or changing anything. The file name is historical; the rules apply to
all agents, and the push, merge and branch gates in it are not optional.

Standard: dev-pose `standards/` (cross-agent rules, section 3.6).
